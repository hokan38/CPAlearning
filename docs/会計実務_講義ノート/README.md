## 記号の意味

**優先度バッジ**(テキスト目次のアイコンに準拠):

| バッジ | 意味 | やること |
|---|---|---|
| 🅰 最優先 | 過去の出題実績等から最優先に押さえる論点 | **暗記する** |
| 🅱 要習得 | 合格のために押さえる必要がある論点 | 説明できるレベルにする |
| 🅲 後回しOK | 費用対効果から優先度低 | 一読 or 飛ばす |
| 📖 知識整理 | ひと通り確認しておきたい部分 | 読んで理解(暗記不要) |

**本文中の記号**:

- 🖍 **ライン推奨** — 試験で書けるべき教科書の文言(マーカーを引く箇所)
- 🎤 **講師メモ** — 講義音声から拾った講師コメント(タイムスタンプ付き)
- 💡 **覚え方** — 記憶のコツ・整理の観点
- ✏️ **書けるようにする** — 記述問題を想定したQ&A
- ⏭ **スキップ指示** — 講師が「読むだけでよい/飛ばしてよい」とした箇所
