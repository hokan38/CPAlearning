### 2. 財務報告の目的 【📖 知識整理】(p.2-13)

> 🖍 財務報告の目的は、**投資家による企業成果の予測と企業価値の評価に役立つような、企業の財務状況の開示**にある。具体的には、投資家の意思決定に資するディスクロージャー制度の一環として、企業価値評価の基礎となる将来キャッシュ・フローの予測に必要とされる、**企業の投資のポジション(ストック)とその成果(フロー)を測定して開示すること(情報提供)**(p.2-13)

- 各当事者の役割と責任: **投資家**=開示情報を利用し**自己の責任で**将来の企業成果を予想・企業価値を評価(将来に関する予想の形成)/**経営者**=投資家がその役割を果たすのに必要な情報を開示(現在までの事実の開示)/**監査人**=経営者が適正に開示しているかを確かめる(情報の監査)。予測は投資家の自己責任、経営者が負うのは基本的に事実の開示。

🎤 講師メモ(1_2 0:21:50): 純資産会計基準(の結論の背景)も「財務報告における情報提供の中で**特に重要なのは投資の成果を表す利益の情報**」と言っている。投資家の意思決定プロセス——企業価値評価にはどの評価モデルを使うにせよ**将来のフローの予測**が必ず必要→その予測に必要な情報の筆頭が(過去の)利益情報→**だから我が国の会計基準は純利益を一番重要な数字と考えている**。情報提供機能を財務報告の目的とする点自体はIFRSも同じ(0:21:06)。

### 3. 会計情報の質的特性 【📖 知識整理】(p.2-14〜2-15)

階層構造で思い出す(全体像の図 p.2-15)。

- **意思決定有用性**(最も基本的な特性): 投資家が企業の不確実な成果を予測するのに有用であること。すべての会計情報・会計基準に要求される規範だが、具体性・操作性に欠けるため下位の特性で支える。
  - **意思決定との関連性**: 会計情報が将来の投資の成果についての予測に関連する内容を含み、企業価値の推定を通じた投資家の意思決定に積極的な影響を与えて貢献すること。
    - **情報価値の存在**(投資家の予測や行動が当該情報の入手によって改善される)
    - **情報ニーズの充足**(基準設定局面で情報価値が不確かでも、投資家の情報ニーズの存在が情報価値を期待させる)
  - **信頼性**: 会計情報が信頼に足る情報であること。
    - **中立性**(一部の関係者の利害だけを偏重しない)
    - **検証可能性**(測定者の主観に左右されない事実に基づく=見積りのノイズを小さく)
    - **表現の忠実性**(事実と会計上の分類項目との明確な対応関係)
  - **一般的制約となる特性**(3者の階層を基礎から支え、必要条件ないし閾限界として機能):
    - **内的整合性**(個別基準が会計基準全体を支える基本的な考え方と矛盾しない→その基準に従う会計情報は有用と推定)
    - **比較可能性**(時系列比較・企業間比較の障害とならない。同様の事実には同一の処理、異なる事実には異なる処理)

💡 第3章対比の伏線: IASBの概念フレームワークの質的特性(基本的な質的特性と補強的な質的特性)とは**用語も階層構成も異なる**。日本側は「意思決定有用性を頂点に、関連性・信頼性が直接支え、内的整合性・比較可能性が土台」という3層構造で覚えておくと、第3章で差分だけ載せられる。とりわけ**内的整合性は討議資料に特徴的な概念**。

### 4. 財務諸表の構成要素 【📖 知識整理】(p.2-16〜2-17)

**(1) 8つの構成要素と定義構造** — ここが本章のハイライト。

構成要素は**資産・負債・純資産・株主資本・包括利益・純利益・収益・費用**の8つ。定義構造(どれに独立定義があるか)がそのまま日本基準の性格を表す:

| 構成要素 | 定義(要旨) | 定義の独立性 |
|---|---|---|
| **資産** | **過去の取引または事象の結果として、報告主体が支配している経済的資源** | **○(独立)** |
| **負債** | **過去の取引または事象の結果として、報告主体が支配している経済的資源を放棄もしくは引き渡す義務、またはその同等物** | **○(独立)** |
| 純資産 | 資産と負債の差額 | 資産・負債に従属 |
| **株主資本** | **純資産のうち報告主体の所有者である株主(連結上は親会社株主)に帰属する部分** | 純資産の内訳として定義 |
| 包括利益 | 特定期間における純資産の変動額のうち、報告主体の所有者である株主、子会社の少数株主、及び将来それらになり得るオプションの所有者との直接的な取引によらない部分 | 資産・負債に従属 |
| **純利益** | **特定期間の期末までに生じた純資産の変動額(株主等との直接的な取引による部分を除く)のうち、その期間中にリスクから解放された投資の成果であって、報告主体の所有者に帰属する部分** | **○(独立)** |
| 収益 | 純利益または少数株主損益を増加させる項目(資産の増加や負債の減少に見合う額のうち、投資のリスクから解放された部分) | 純利益に関連させた定義 |
| 費用 | 純利益または少数株主損益を減少させる項目(資産の減少や負債の増加に見合う額のうち、投資のリスクから解放された部分) | 純利益に関連させた定義 |

- 資産・負債の定義からはじめるのは**財務報告の対象を確定し定義する作業が容易になるから**であって、有用性の比較でも特定の測定方法を導く意図でもない。**純利益にも独立定義を与えているから、討議資料は決して資産負債アプローチに立っているわけではない**。
- 財務報告の目的による制約: 定義を充足しても目的に適合しなければ構成要素にならない。代表例=**自己創設のれん**(経営者による企業価値の自己評価・自己申告となり財務報告の目的に反する)。

🎤 講師メモ(1_2 0:23:11): 資産負債の定義部分だけ見ればIFRSと同じ資産負債アプローチだが、日本の概念フレームワークは**損益計算書の純利益にも独立定義を与えた**——純利益(収益費用の差額)は単なる資産負債の増減ではなく**「投資のリスクからの解放」という要件を満たしたものに限られる**。純利益にまで独立定義を与えたためこのままではB/SとP/Lが連携せず(クリーン・サープラス不成立)、企業価値評価に役立たない。**そこで純資産の中に「株主資本」という項目を作り、純利益と株主資本を連携させた**。「資産負債とは別に純利益を独立に定義したことで、それを生み出す投資の正味のストックである株主資本も重視している」のが日本の会計基準の体系(0:24:43)。

🎤 講師メモ(1_2 0:25:09): 純利益重視は**実務対応報告第18号**(IFRS等を適用する在外子会社の財務諸表の修正の取扱い)でも「我が国の会計基準に共通する考え方」として紹介されている——①**期間利益を測定するうえでの費用配分**(配分は利益を算定するための技術。減価償却だけでなく固定資産の減損や棚卸資産の切下げもすべて配分=期間損益計算のための手続)、②**当期純利益と株主資本との連携**(B/Sとの結び付きは株主資本との間)、③**投資の性格に応じた資産・負債の評価**(本来の資産負債アプローチは公正価値評価に傾斜するが、我が国はあくまで期間損益計算の観点から資産・負債を評価する思考)。

🎤 講師メモ(1_2 0:30:38): **「なんと言っても見ておかなければいけないのは、この8つの構成要素」**。独立定義は資産・負債だけでなく純利益にも与えられている→純粋な資産負債アプローチではなく収益費用アプローチの考え方も加味されている、という構造を押さえる。

**(2) 包括利益と純利益** (p.2-17)

| | 包括利益 | 純利益 |
|---|---|---|
| 意義 | 特定期間における純資産の変動額(株主等との直接的取引を除く) | 左のうち**リスクから解放された投資の成果**+**報告主体の所有者に帰属する部分** |
| 共通点 | **一致の原則を満たす**(下記🖍) | 同左 → **両者は期間帰属が異なるだけ=その他の包括利益のリサイクリングが必ず行われる** |
| 相違点①(認識) | 投資のリスクからの解放を認識の条件と**しない** | リスクから解放されている部分**のみ**認識 |
| 相違点②(帰属主体) | 所有者に帰属する部分+子会社の少数株主に帰属する部分 | 所有者に帰属する部分**のみ** |
| B/Sとの関係 | 純資産の変動額(**包括利益と純資産のクリーン・サープラス関係**) | もっぱら株主資本だけを増減(**純利益と株主資本のクリーン・サープラス関係**) |
| 討議資料の立場 | 純利益に代替し得るとは考えていないが、純利益を超える有用性が見出される可能性もあるため独立した地位を与えた | 長期にわたり投資家に広く利用され、有用性を支持する経験的な証拠も確認されている→**純利益を重視** |

> 🖍 **企業の投資の成果は、最終的には、投下した資金と回収した資金の差額にあたるネット・キャッシュ・フロー(=全体利益)により計算される。各期の利益(期間利益)の合計がその額(全体利益)に等しくなることが利益の測定にとって基本的な制約になる(一致の原則)。包括利益と純利益はともにこの制約を満たす。**(p.2-17。講師いわく討議資料第3章第10項の「大事な一文」)

🎤 講師メモ(1_2 0:27:10〜0:28:37): 図解——設立から解散までの収入・支出の差額がネット・キャッシュ・フロー=全体利益。期間利益の合計は、包括利益であれ純利益であれこの全体利益に一致する。**「包括利益と純利益というのは単なる期ズレですよ」**。単なる期ズレだからこそ**その他の包括利益は必ずリサイクリングしなければならない**(0:29:24)。

🎤 講師メモ(1_2 0:28:42): **純利益の重視から導かれる日本基準の特徴の整理(この3つが本章の結論)**——
1. **計算構造は資産負債アプローチではない。収益費用アプローチの考え方も入ったハイブリッド構造**(純利益が独立定義されているから)
2. **クリーン・サープラス関係が2種類存在**(包括利益⇔純資産だけでなく、純利益⇔株主資本。むしろ後者を大事にしている)
3. **包括利益も純利益も期ズレにすぎない→その他の包括利益は必ずリサイクリング**

💡 **第3章対比の核心(1_2 0:29:37〜0:30:38)**: この3つをそのままIFRSと対比する——IFRSは**資産負債アプローチ**。純利益も表示はするが、**純利益と連携する財政状態計算書の項目はない(株主資本が定義されていない)**し、**その他の包括利益にリサイクリングを行わない部分がある**。したがって**IFRSの純利益は一致の原則を満たさない=「純利益にキャッシュの裏付けがない」(ネット・キャッシュ・フローと最終的に一致しない)**。「この日本基準の特徴とうまく対比させながらIFRSを押さえるようにしてください」。

### 5. 財務諸表における認識と測定 【📖 知識整理】(p.2-18〜2-24)

**(1) 認識に関する制約条件**(2つとも満たす必要あり)(p.2-18)

- **認識の契機**: 基礎となる契約の**原則として少なくとも一方の履行**(∵履行の見込みが不確実な契約から構成要素を認識すると誤解を招く。双務未履行の契約は原則として認識しない——ただし金融商品に属する契約の一部は双務未履行の段階で計上される)。
- **認識に求められる蓋然性**: 構成要素に関わる将来事象が**一定水準以上の確からしさ**で生じると見積られること(発生の可能性の判断は資産と負債との間で必ずしも対称的ではない=保守的思考)。

**(2) 構成要素の測定**(p.2-18〜2-24): 資産の測定値5つ(取得原価・市場価格・割引価値・入金予定額・被投資企業の純資産額に基づく額)、負債の測定値4つ(支払予定額・現金受入額・割引価値・市場価格)、収益・費用の測定(リスクからの解放形態別に4方法ずつ)が詳細な表で掲載されている。

⏭ スキップ指示 — 🎤 講師メモ(1_2 0:31:58): 測定値の一覧は**「アカデミックな内容で、修了考査で問われることはありませんので、載せているだけだと思ってください。太字にもなっていますけれども」「一昔前の論文式試験なら問われてもおかしくないが、修了考査には馴染まない内容」**。→ 表の暗記は不要。

💡 ただし p.2-22 の**「投資のリスクからの解放」の意義と事業投資/金融投資の区分**だけは、純利益の定義(上記4.)を支える概念なので読んで思い出しておく: リスクからの解放=**投資にあたって期待された成果が事実として確定すること**。**事業投資**は事業のリスクに拘束されない独立の資産を獲得したとき(CFに転換された時点)に解放→**原価評価**、**金融投資**(事業の目的に拘束されず値上りを期待)は**価値が変動した時点**でそのまま解放→**時価評価**。「投資の性格に応じた資産・負債の評価」(実務対応報告18号の考え方③)の中身がこれ。
