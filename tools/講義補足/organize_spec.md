# 講義補足の整理 + 講義スライド対応付け 仕様

2つの成果物を章ごとに作る。

## 成果物1: supp_comments_chNN.json (講義補足コメント)

既存の抽出結果 extra_chNN.json (講義から拾った教科書未記載の発言リスト) を素材に、
**発言の羅列ではなく、内容を論点ごとに整理・統合したコメント**を作る。
これは教科書ページ右側のコメント欄に赤字で直接印字される。

形式(JSONL、1行1オブジェクト):
```json
{"ref": "5-13", "search": "回収可能性", "text": "整理済みコメント本文"}
{"ref": "5-13", "text": "アンカーを特定できない場合はsearchを省略してよい"}
```

### 整理のルール
1. **網羅性を保つ**: extra_chNN.json にある情報内容はすべてどこかのコメントに反映する。
   落としてよいのは重複・言い回しの揺れだけ
2. **統合する**: 同じページ・同じ論点の複数発言は1つのコメントにまとめ、簡潔に書き直す。
   1ページあたりコメント1〜3個、1個は40〜220字、1ページ合計350字以内を目安
   (内容が多いページは450字まで可。それでも入らない場合は隣接する関連ページに振り分ける)
3. **refの見直し**: 元のrefが不自然なら、内容に最も対応する教科書ページに付け替えてよい。
   章の総論的な話(学習方針・出題傾向の総括など)は章の扉ページ(例 "5-1")にまとめる
4. **search(アンカー)**: コメントが教科書の特定の記述に対応する場合は、そのページの
   ダンプ(pNNN.txt)の1行内に実在する連続文字列(8〜25字)を指定する。ページ全体・
   節全体に関わるコメントなら省略してよい
5. 「講師メモ」等の前置き・タイムスタンプ・重要度ランク(A/B/C)表記は書かない。だ・である調

## 成果物2: slide_map_chNN.json (講義スライドの挿入位置)

画面集(講義投影資料)の各PDFページを、内容が対応する教科書ページの直後に挟むための対応表。

形式(JSONL、1行1オブジェクト):
```json
{"slide_page": 1, "after_ref": "10-1"}
{"slide_page": 2, "after_ref": "10-4"}
```
- slide_page = 画面集PDFのページ番号(1始まり)。slide_text/画面集_第NN章.txt の
  「--- スライドN ---」の N がそのままページ番号
- after_ref = そのスライドページの内容に最も対応する教科書ページ(印字ページ番号)。
  スライドはこのページの直後に挿入される
- **画面集の全ページを漏れなく割り当てる**こと。章の全体像・アジェンダ的なスライドは
  章の扉ページに割り当てる。1つの教科書ページに複数スライドを割り当ててもよい
  (slide_page順に挿入される)。対応先はスライド内容が説明している論点の掲載ページを
  ダンプから探して決める

## 検証
- 出力前に、searchを指定した全行についてダンプ(該当ページ)に実在するかgrepで確認
- slide_mapは「画面集のページ数 = 出力行数」を確認
