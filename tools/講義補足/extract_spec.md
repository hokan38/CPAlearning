# 講師発言の網羅抽出仕様(章末「講義補足」ページ用)

## 目的
講義の文字起こしから「教科書に記載のない講師の発言」を**網羅的に**抽出し、
教科書PDFの章末に追加する補足ページの原稿(JSONL)を作る。

## 出力形式
指定された extra_chNN.json に1行1オブジェクト:
```json
{"ref": "10-3", "text": "発言内容(教科書用語に正規化した要約。情報を落とさない)"}
```
- `ref` = 対応する教科書ページ番号(教科書に印字された「章-ページ」形式)。
  対応箇所が特定できない全体的な発言は章の先頭ページ(例 "10-1")にする
- `ref` の昇順(=講義の進行順)に並べる
- 1項目 40〜250字。長い発言は意味のまとまりで複数項目に分割してよい

## 含めるもの — 教科書に無い発言はすべて網羅する
- 出題予想・出題傾向のコメント(「ここが出そう」「そろそろ危ない」「今年は〜」)
- 勉強法の指示(「覚えて」「飛ばしていい」「眺める程度」「計算を回せ」「答練で〜」)
- 実務での扱い・実務経験談・監査現場の話
- 教科書より踏み込んだ理屈・別の言い回しの説明・追加の具体例や数値例
- 他の章・他科目・過去問・答練との関連付け
- 基準の制定経緯・改正の裏話・出題委員に関する言及
- 受験生が誤りやすい点への注意喚起
- 試験戦略に関わる雑談(内容のあるもの)

## 除外するもの
1. 教科書本文の読み上げ・単なる言い換え(ページダンプと突き合わせて判断)
2. 既存の注釈プラン(指定ファイル)の comment / margin に実質反映済みの発言
   (同趣旨なら除外。プランより情報が多い場合は「追加分だけ」を項目化)
3. 挨拶・つなぎ・言い直しなど情報価値のない発話
4. 文字起こしが壊れて意味が取れない箇所(無理に創作しない)

## 書き方のルール
- **重要度A/B/Cといった優先度ランクの説明は書かない**(バッジ・ランク表記は一切不要)
- whisper誤変換は教科書用語に正規化(終了交差=修了考査、イファース=IFRS、
  税孔化=税効果、幻村=減損、対処給付=退職給付 等、文脈で判断)
- 講師の口調は要約してよい。だ・である調。タイムスタンプは書かない
- 教科書・文字起こしにない内容を創作しない

## 作業手順
1. 既存プランを読み、反映済み内容を把握する
2. 文字起こしを頭から通読し、候補発言をすべて拾う
3. 各候補を教科書ページダンプと突き合わせ、教科書記載/反映済みを除外
4. ref を割り当てて JSONL 出力
