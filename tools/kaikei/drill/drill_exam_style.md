# 解答例を「答案にそのまま書ける文章」に書き直す仕様

## 目的
論述ドリル（frag/chNN.html）の解答例は「結論ラベル→番号付き箇条書き」になっていて、本番の答案用紙に
そのまま書けない。これを **修了考査の解答欄にそのまま書き写せる文章** に書き直す。
問題文（.q）・見出し（.th）・ランク・問の数・並び順・「入れる語」（.pt）は変えない。
変えるのは `<div class="a">` の中身だけ（補足を分ける場合は .nt を追加）。

## 書き方のルール
1. **である調の文章**で書く。答案用紙に上から順に書いていけば完成する形にする。
2. **見出しラベル・番号・箇条書きを使わない。**
   - 禁止：`<b>結論</b>`、`<ol>`、`<ul>`、`<li>`、「理由：」「ポイント：」などのラベル、①②③の理由番号。
   - 理由や処理は接続語でつなぐ：「〜である。なぜなら、〜からである。」「〜するためである。」
     「まず、〜。また、〜。さらに、〜。したがって、〜。」「〜であり、〜。そのため、〜。」
3. 問いに対する答え（判断・結論）から書き始めてよい。これは本番の答案として自然な書き方。
   ただしラベルは付けず、「〜は妥当ではない。〜だからである。」のように文章で書く。
4. **例外として番号・記号を使ってよいもの**（本番の答案でも同じ書き方をするもの）
   - 問題文に小問 (1)(2) や ①② があるとき → その記号で段落を分ける：`<p>(1) …</p><p>(2) …</p>`
   - 問題文が「〜を二つ（三つ）挙げなさい／答えなさい」と個数を指定して列挙を求めるとき → 1項目1段落で
     `<p>・…</p>` と「・」で始めて並べる（本番の解答欄でも行を分けて書くため）。
   - 仕訳を答える問題 → 仕訳は `<p>（借）科目 金額　（貸）科目 金額</p>` の1行形式で書いてよい。
5. **答案に書かない補足**（判定の手順の覚え方、他論点との比較、講師の注意など）は解答本文に混ぜない。
   残す価値があれば、`</div>`（.a の終わり）の直後、.pt の前に
   `<div class="nt"><b>補足</b>…</div>` として1〜2文で置く。不要なら削除してよい。
6. `<k>…</k>`（採点キーワードの赤字）は文章の中にそのまま残す。1文に0〜2箇所。
7. 長さの上限（タグを除く解答本文。.nt は数えない）。本番の解答欄（おおむね5〜12行）に収まる長さにする。
   | ランク | 上限 | 小問・事例で複数ケース・列挙がある場合 |
   |---|---|---|
   | A | 400字 | 520字 |
   | B | 300字 | 400字 |
   | C | 180字 | 250字 |
   今の解答例は長いので、**採点に効く要素（結論・要件・理由の核・数値・条件・例外・<k>の語）を残し**、
   言い換え、同じ内容の繰り返し、前置き、例示の2つ目以降、答案に不要な解説は削る（必要なら .nt へ）。
   要素を削らないと上限に収まらない場合に限り、上限の1.2倍まで認める。
8. **事実を変えない。** 今の解答例にある結論・要件・数値・条件・例外は落とさない（長さ調整で削るのは説明の重複部分だけ）。新しい論拠も足さない。
   用語は今の解答例の表記（教科書表記に統一済み）をそのまま使う。言い換えない。
9. 1文は長くても80字程度。読点で長くつながないで、文を切る。
10. HTML：`<div class="a"><span class="l">解答例</span>` で始め、本文は `<p>…</p>` の段落だけで書く。

## 見本
### 書き直し前
```html
<div class="a"><span class="l">解答例</span>
<p><b>結論</b>　のれんは20年以内のその効果の及ぶ期間にわたって規則的に償却する。</p>
<ol>
<li>のれん＝<k>超過収益力</k>。競争で減価する費用性資産のため償却。</li>
<li>規則的償却で、企業結合の成果である収益と<k>費用</k>が対応。</li>
<li>自己創設のれんの計上を防ぐ。</li>
</ol>
</div>
```
### 書き直し後
```html
<div class="a"><span class="l">解答例</span>
<p>のれんは、20年以内のその効果の及ぶ期間にわたって、定額法その他の合理的な方法により規則的に償却する。なぜなら、のれんは被取得企業の<k>超過収益力</k>を表すものであり、競争の進展によって価値が減価する費用性資産だからである。また、規則的に償却することで、企業結合の成果である収益と、その獲得に要した<k>費用</k>とを対応させることができる。さらに、償却を行わないと、自己創設のれんを実質的に資産計上することになるためである。</p>
</div>
```
（見本の内容は書き方の例。実際は各問の今の解答例の内容だけで書くこと。）

### 小問がある場合
```html
<div class="a"><span class="l">解答例</span>
<p>(1) 20X3年3月期は分類3に該当する。過去3年及び当期のいずれにも<k>重要な税務上の欠損金</k>は生じていないため、分類4・5には該当しない。…</p>
<p>(2) 20X4年3月期は分類4の要件を満たすが、分類3に該当するものとして取り扱う。…</p>
</div>
<div class="nt"><b>補足</b>判定は、重要な税務上の欠損金の有無（分類4・5）→将来減算一時差異を十分に上回る課税所得の有無（分類1）→課税所得の安定性（分類2か3）の順で行う。</div>
```

## 作業手順（1章ごと）
1. frag/chNN.html を読み、各 .item の .q（問題文）と今の .a を確認する。
2. .a の中身だけを上のルールで書き直す（Edit で1問ずつ、または章全体を書き換え）。
3. `python3 check_exam.py frag/chNN.html` を実行し、errors=0・長さ超過0 にする。
