# 解答例を「答練・本試験の模範解答の書き方」に書き直す仕様（第2版）

## 目的
論述ドリル（frag/chNN.html）の解答例を、**答練の模範解答としてそのまま載っていそうな文章**に書き直す。
今の版は講義の説明（趣旨の深掘り・背景・覚え方）まで含んでいて長く、説明調になっている。
問題文（.q）・見出し（.th）・入れる語（.pt）・問の数と順序は変えない。変えるのは `.a` の中身と `.nt`（補足）だけ。

## 最優先のルール：書かなければいけないことは削らない
1. **問題文が聞いていることは、すべて答える。** 「〜を含めて」「手順を述べよ」「理由を付して」「対比して」「それぞれ」
   などの指示を1つずつ確認し、全部に答えが入っていることを確かめる。
2. **入れる語（.pt）の語は、すべて解答本文に入れる。** 表記は入れる語のとおりにする（言い換えない）。
   例外：入れる語にあるが問題文が聞いていない論点だけは、補足（.nt）に移してよい。その場合は報告する。
3. 削ってよいのは、言い換え・同じことの繰り返し・2つ目以降の例示・講義の背景説明・覚え方・他論点との比較だけ。
   削ったもののうち残す価値があるものは `.nt` へ（不要なら削除）。
4. 事実（結論・要件・数値・条件・例外）を変えない。新しい論拠を足さない。用語は今の解答例の表記を使う。

## 模範解答の書き方（答練の模範解答の分析から）
- 判断とその根拠を言い切る。基本形：「〜であるため、〜に該当する。したがって、〜する。」
  「〜の場合、〜する。」「〜については、〜とされている。」
- 根拠は**基準の要件・文言**で書く。講義口調・比喩・「〜という発想」「〜がポイント」は使わない。
- 「なぜなら、〜からである」「まず・また・さらに・加えて」で理由を並べる書き方は避ける
  （理由を問われたら「〜からである。」「〜ためである。」で結ぶのはよい）。
- 1文を長くしすぎない（目安80字。模範解答は読点でつなぐ長めの文も使うが、120字は超えない）。
- 比較問題：「日本基準では〜するのに対し、国際財務報告基準では〜する。」を基本形にする。
- 事例問題：事例の事実を要件に当てはめる。「Ａ社は〜であるため、〜に該当する。」
- 要件・条件を挙げる問題：`<p>・〜こと。</p>` を並べる（個数指定がなくても、答えが要件の列挙そのものなら可）。
- 小問 (1)(2)・(a)(b)・①② がある問題：その記号で段落を分ける。
- 仕訳：`<p>（借）科目 金額　（貸）科目 金額</p>`。
- ラベル（「結論」「理由」等）・番号付き箇条書き（ol/ul/li）は使わない。
- `<k>…</k>`（赤字）は入れる語・採点の核の語に付ける。1文に0〜2箇所。

## 長さの目安（タグを除く本文。.nt は数えない）
| | 1つのことを聞く問題 | 小問・複数ケース・列挙・「〜を含めて」等で複数のことを聞く問題 |
|---|---|---|
| A | 300字 | 450字 |
| B | 250字 | 400字 |
| C | 200字 | 300字 |
上限は目安。**ルール1・2を守るためなら超えてよい**（超えた問は報告する）。逆に、上限より大幅に短くできるなら短くする。
