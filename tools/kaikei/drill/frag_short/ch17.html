第17章　資産除去債務重要度A 4問／B 2問／C 2問｜出題実績：平30・令2・令6

重要度A白紙に書けるレベルまで（記述で実際に問われた3論点＋IFRS対比）

A-1　割引率（無リスク・税引前）と退職給付会計との共通点令2・令6
問資産除去債務の算定に用いる割引率はどのような利率か。同様の考え方をとる会計基準を一つ挙げ、その理由とともに説明しなさい。
解答例

結論　無リスクの税引前利率（安全性の高い債券の利回り）。退職給付会計も同じ。

  1. 資産除去債務も退職給付会計の債務も金利キャッシュ・フローを含まない点が共通。
  2. 見積値からの乖離リスクは割引前キャッシュ・フローの見積りに反映し割引率に反映しない（二重カウント防止）。
  3. 自己の信用リスクを加味すると信用力が低いほど負債が小さくなる負債のパラドックス。
  4. 割引前キャッシュ・フローが税引前の数値のため、割引率も税引前で対応。
  5. 対比：減損はリスクを割引率に反映する方法も可、リースは信用リスクを含む利率。
入れる語無リスク／税引前／金利キャッシュ・フローを含まない／退職給付会計／見積りに反映し割引率に反映しない／負債のパラドックス。
A-2　見積りの変更（原状回復費用の大幅増加への対応）令6
問賃借している新宿店の内部造作について原状回復義務に係る資産除去債務を計上していたところ、当期に原状回復費用の見積額が大幅に増加することが判明した。考えられる対応を3つ挙げて説明しなさい。
解答例

結論　①見積り変更の会計処理②見積り変更の注記③減損の兆候の検討。

  1. ①増加額を見積変更時の割引率で割り引き、資産除去債務と関連する有形固定資産の帳簿価額に加算。
  2. 見積りの変更として将来にわたり処理（遡及なし）。以後は減価償却費と利息費用で費用配分。
  3. ②重要性が乏しい場合を除き、変更の概要と影響額の注記が必要。
  4. ③費用の大幅増は回収可能価額を著しく低下させる変化で減損の兆候に該当し得る。兆候があれば認識の判定・測定へ。
入れる語見積変更時の割引率／有形固定資産の帳簿価額に加算／将来にわたり処理／概要と影響額の注記／減損の兆候。
A-3　履行に係る支出のキャッシュ・フロー計算書上の区分平30
問資産除去債務の履行に係る支出をキャッシュ・フロー計算書のどの区分に表示すべきかについて、投資活動によるキャッシュ・フローとする考え方と営業活動によるキャッシュ・フローとする考え方をそれぞれ説明し、会計基準がいずれを採用しているか述べなさい。
解答例

結論　基準は投資活動によるキャッシュ・フローを採用。

①投資活動説　除去費用は負債計上時に有形固定資産の帳簿価額に加わり取得原価の一部。除去支出は取得の付随費用と同様の性格のため、取得による支出と同じ投資活動区分が整合的。

②営業活動説　有形固定資産の取得後の支出は営業費用（修繕費等）として営業活動区分。除去支出も取得後の支出だから他と整合的に営業活動区分。

重要な資産除去債務の計上は重要な非資金取引として注記。

入れる語取得原価の一部／付随費用と同様／取得後の支出は営業費用／投資活動によるキャッシュ・フローを採用／重要な非資金取引。
A-4　IFRSとの対比（事後測定と割引率の固定）
問資産除去債務の負債計上後の測定について、日本基準とIFRSの取扱いの違いを、その背景にある考え方とともに説明しなさい。
解答例

結論　IFRSは負債の評価の側面、日本基準は利息費用の配分の側面を重視。

  1. IFRSに独立基準なし。借方はIAS16で取得原価、貸方はIAS37の引当金。
  2. IFRSは毎期末の割引率で再測定（負債固有のリスク込み）。利息費用も独立計算せず負債の変動額として扱う。
  3. 日本基準に事後測定の発想なし。期首負債×当初負債計上時の割引率＝利息費用を配分した結果が負債残高で、逓増する。
  4. 敷金の簡便処理も費用配分重視の日本独特の規定。セットで押さえる。
入れる語負債の評価の側面／利息費用の配分の側面／毎期末の割引率で再測定／負債の変動額／当初負債計上時の割引率。

重要度B聞かれたら説明できるレベル（骨子が書ければよい2論点）

B-1　資産負債の両建処理と費用配分
問資産除去債務について引当金処理ではなく資産負債の両建処理が採用された理由を述べ、両建処理のもとで除去費用がどのように費用配分されるか説明しなさい。
解答例

結論　負債性の観点から両建処理し、費用は減価償却と利息費用で配分。

  1. 引当金処理は将来支出の一部のみ負債計上。両建処理は支払義務の全額を負債計上（コンバージェンスで導入）。
  2. 同額を資産に加算し、減価償却で配分。費用対応も確保。
  3. 時の経過による調整額＝期首負債×当初割引率を利息費用として配分。
  4. 税効果：負債→DTA、資産計上額→DTLでDTAとDTLの同時計上。
入れる語負債性／全額を負債計上／同額を資産に加算／減価償却で配分／利息費用／コンバージェンス／DTAとDTLの同時計上。
B-2　見積りの変更と適用する割引率
問割引前将来キャッシュ・フローの見積りが増加した場合と減少した場合とで、調整額の算定に用いる割引率が異なる理由を説明しなさい。
解答例

結論　増加分は変更時の割引率、減少分は負債計上時の割引率。

  1. 増加分＝新たな負債の発生と同様とみて、その時点の割引率。
  2. 減少分＝過去に計上した負債の取崩しのため、元の負債に紐付く当初の割引率。
  3. 対応部分を特定できないときは加重平均した割引率。
  4. 未計上分が見積可能となった計上も見積り変更に準じる。未計上でも注記は必要。
入れる語新たな負債の発生／変更時の割引率／取崩し／負債計上時の割引率／加重平均。

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　「法律上の義務に準ずるもの」と除去の範囲
問資産除去債務の対象となる「法律上の義務に準ずるもの」とは何か。また「除去」に含まれるもの・含まれないものを述べなさい。
解答例

準ずるもの＝履行を免れることがほぼ不可能で法律上の義務とほぼ同等の不可避性をもつ義務（自発的計画は除く）。除去＝用役提供から除外。売却・廃棄は含み、転用・用途変更は含まない。

C-2　履行差額の表示と敷金の簡便処理
問(1) 資産除去債務の履行時に生じる差額の損益計算書上の表示、(2) 賃借契約に関連する敷金が資産計上されている場合の簡便処理を説明しなさい。
解答例

(1)　履行差額は関連資産の減価償却費と同じ区分。異常な原因によるものだけ特別損益。

(2)　敷金のうち回収が最終的に見込めない金額の当期負担分を費用計上する簡便処理が可。
