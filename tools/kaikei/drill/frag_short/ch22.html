A-1　報告セグメントの区分方法の変更と前期情報の作り直し平26
問婦人服・紳士服等を報告セグメントとするアパレル企業が、フォーマルウェアを扱うＡ社を新たに連結し、報告セグメント「フォーマルウェア」を新設することとした。従来婦人服セグメントに含めていた婦人服フォーマルウェアについて、ａ：新設のフォーマルウェアセグメントへ移す方法、ｂ：婦人服セグメントに含めたままとし、フォーマルウェアセグメントはＡ社のみで構成する方法が検討されている。ａ・ｂの方法によって前連結会計年度のセグメント情報の取扱いにどのような相違が生じるか説明しなさい。
解答例

結論　ａは区分方法の変更で前期の作り直しが必要。ｂは変更に当たらず不要。

  1. ａ：婦人服フォーマルを新セグメントへ移すため区分方法の変更。変更した旨と前期を当期の区分で作り直した情報を開示。
  2. 作り直しが実務上困難なら、当期を前期の区分で作成した情報を開示できる。
  3. ｂ：既存区分は不変、新セグメントはＡ社のみ。変更に当たらず前期数値をそのまま比較情報に使える。
  4. 相違＝前期分の作り直しの要否。前期・当期を同じ区分で作り比較可能にする趣旨。
入れる語区分方法の変更／変更した旨の開示／前期を当期区分で作り直し／実務上困難なら当期を前期区分で／ｂは変更に当たらない／作り直しの要否。
A-2　量的基準を下回った報告セグメントの取扱い令6
問Ｌ社（3月決算）は前連結会計年度まで報告セグメントとしていたＬ事業について、20X4年3月期には量的基準を満たさない見込みである。経理部は「量的基準を下回るのでＬ事業は直ちに『その他』に含める」方針である。①この方針の当否を理由を付して述べなさい。②Ｌ事業をＭ事業とともに「その他」に含める場合、20X4年3月期のセグメント情報においてどのような開示が必要か述べなさい。
解答例

①　量的基準を下回っただけで直ちに「その他」に含めるのは適当でない。

  1. 量的基準の適用は相当期間継続性が維持されるよう配慮する。
  2. 前期の報告セグメントが基準を下回っても、引き続き重要なら区分して継続開示。
  3. 減少が一時的か、事業計画上の位置付けから利用者にとって重要かを検討。
  4. 除いた後も報告セグメントの外部売上高がP/L売上高の75％以上か（75％基準）も考慮。

②　重要性の変化による報告セグメントの範囲の変更に該当。その旨を開示し、前期（20X3年3月期）を当期の区分で作り直して比較開示。Ｌ・Ｍ事業は「その他」に一括し、「その他」に含まれる主要な事業の名称を開示。

入れる語継続性への配慮／引き続き重要なら継続開示／75％基準／範囲の変更／その旨の開示／前期を当期区分で作り直し／「その他」の主要な事業の名称。
A-3　関連当事者開示の趣旨と開示を要しない取引令2
問関連当事者との取引であっても開示を要しない取引の具体例を挙げ、なぜ開示が不要とされるのかを関連当事者の開示が求められる趣旨と関連付けて説明しなさい。
解答例

結論　一般競争入札、預金利息・配当の受取りなど取引条件が一般の取引と同様であることが明白な取引は開示不要。

  1. 趣旨：支配・重要な影響力により独立第三者間取引と異なる条件となり業績に影響するおそれを注意喚起。
  2. 上記取引は条件が一般と同様と明白で条件の歪みが生じ得ない。趣旨に照らし有用性なし。
  3. 役員への報酬・賞与・退職慰労金、連結上相殺消去された取引も対象外。
  4. 判定順：関連当事者か→連結上の対象か→条件が一般と同様か→重要性基準。
入れる語一般競争入札／預金利息・配当／条件が一般と同様であることが明白／支配・重要な影響／独立第三者間取引と異なるおそれ／注意喚起／条件の歪みが生じ得ない。
A-4　役員の範囲の実質判定（創業者が顧問に就任した場合）令6
問Ａ社の創業者である乙氏は当期に取締役を辞任し、保有株式もすべて売却して持株比率はゼロとなったが、引き続き顧問に就任している。Ａ社の経理担当者は「乙氏は取締役でも株主でもないため関連当事者に該当せず、乙氏との取引は開示不要」と判断した。この判断の留意点を述べなさい。
解答例

結論　取締役辞任・持株ゼロでも直ちに関連当事者から外れるとは限らない。

  1. 「役員」には相談役・顧問・執行役員等これに類する者で、実質的に経営に強い影響を及ぼす者を含む。
  2. 創業者等で役員を退任した者も役員該当性を実質的に判定。
  3. 乙氏が役員に該当すれば、乙氏・近親者（二親等以内）・これらが議決権過半数を所有する会社との取引が開示対象。
  4. 重要性は個人のため1,000万円超。役員報酬・賞与・退職慰労金は対象外。
入れる語相談役・顧問など類する者／経営に強い影響／創業者等の退任者は実質判定／近親者＝二親等以内／議決権過半数所有会社／個人＝1,000万円超。
A-5　修正後発事象と開示後発事象平28
問修正後発事象と開示後発事象の意義と財務諸表上の取扱いを説明しなさい。また、決算日後に主要な販売先が倒産した場合、いずれに該当するか理由とともに述べなさい。
解答例

結論　分かれ目は実質的な原因が決算日に既に存在していたか。

  1. 修正後発事象：決算日後に発生したが原因は決算日に存在し、決算日の見積りに追加的・より客観的な証拠を与える事象。重要なら財務諸表を修正。
  2. 開示後発事象：決算日後に発生し当期F/Sに影響しないが翌事業年度以降に影響する事象。重要なら注記。
  3. 販売先の倒産：回収可能性悪化の原因は期末に存在したはず。修正後発事象として貸倒引当金を追加計上。原因も決算日後なら開示後発事象。
  4. 発生時点：意思決定で進む事象は意思決定時、合意で進む事象は合意成立・公表時、災害等は発生日か知ったとき。
入れる語実質的な原因が決算日に存在／追加的・より客観的な証拠／財務諸表の修正／翌事業年度以降に影響／注記／倒産＝修正後発・貸倒引当金追加計上。
A-6　後発事象の事例判定（新株発行・販売先の破産申立て）平28
問甲社（3月決算、平成29年3月期）の会社法の会計監査人監査報告書日は平成29年5月25日、金融商品取引法の監査報告書日は同年6月20日である。次の各事象について、計算書類および金融商品取引法の財務諸表における取扱いを述べなさい。
(1) 平成29年3月20日の取締役会で新株発行を決議し、払込みが4月19日に行われた。
(2) 同じ決議に基づく払込みが5月29日に行われた。
(3) 販売先丙社が5月10日に破産手続開始の申立てを行った。丙社に対する債権について決算日現在計上済みの貸倒引当金は400百万円であり、破産更生債権等に分類した場合に必要な貸倒引当金は1,100百万円である。
(4) (3)の申立てが5月29日に行われた。
解答例

枠組み　基準日は会社法の会計監査人監査報告書日（5月25日）。基準日前の場合は修正・開示後発事象、後の場合は修正せず注記等。

(1)　決議は決算日以前で対象外。払込みが決算日後・基準日までにあるため開示後発事象として注記。

(2)　基準日まで払込なしのため開示対象なし。払込予定を追加情報で注記。

(3)　申立て＝回収可能性の客観的証拠で修正後発事象。基準日前のため計算書類を修正し破産更生債権等として貸倒引当金を1,100百万円に（700百万円追加）。金商法F/Sも修正。

(4)　修正後発事象だが基準日後のため計算書類は修正不可。開示後発事象に準じ監査役等の監査報告書に追記。金商法F/Sも計算書類との単一性から修正せず引当金700百万円増加を注記。

入れる語基準日＝会計監査人監査報告書日／決議は決算日以前だから対象外・払込みを開示／払込未了なら追加情報／申立て＝修正後発・700百万円追加／基準日後は開示後発に準じて注記／計算書類との単一性。
A-7　潜在株式の希薄化効果の判定平29
問甲社は新株予約権と2種類の転換社債型新株予約権付社債を発行している。潜在株式調整後1株当たり当期純利益の算定に当たり、各潜在株式が希薄化効果を有するか否かを判定する方法を、それぞれの算定方式を示して説明しなさい。複数の潜在株式が希薄化効果を有する場合の取扱いも述べなさい。
解答例

結論　行使を仮定した潜在株式調整後EPSがEPSを下回る潜在株式が希薄化効果を有する。

  1. 分子に当期純利益調整額、分母に普通株式増加数を加えて再計算（期首または発生時の行使を仮定）。
  2. 新株予約権＝自己株式方式。払込金で期中平均株価により自己株式を取得したと仮定。平均株価＞行使価格のときのみ増加数が正で希薄化。調整額なし。
  3. 転換社債＝転換仮定方式。社債利息×（1－実効税率）を調整額に加算。EPS＞調整額÷増加株式数なら希薄化。各社債ごとに判定。
  4. 希薄化ありのみ算入。複数なら1株当たり調整額が小さい順に算入し最大希薄化効果を反映。
入れる語EPSを下回る／当期純利益調整額・普通株式増加数／自己株式方式＝平均株価＞行使価格／転換仮定方式＝税効果控除後の利息を加算／EPS＞調整額÷増加株式数／小さい順・最大希薄化効果。

B-1　報告セグメントの決定手順（集約基準・量的基準）
問セグメント情報の開示において、事業セグメントの識別から報告セグメントの決定に至る手順を、集約基準と量的基準の内容を含めて説明しなさい。
解答例

結論　事業セグメントの識別→集約基準→量的基準の順で決定。

  1. 識別：収益を稼得し費用が発生する構成単位で、最高経営意思決定機関が分離された財務情報を入手できるもの。
  2. 集約：経済的特徴が概ね類似なら1つにまとめ可。
  3. 10％基準：売上高（内部含む）・利益（絶対値の大きい方）・資産のいずれか10％以上。
  4. 75％基準：外部売上高がP/L売上高の75％以上になるまで追加。
入れる語収益を稼得し費用が発生する構成単位／分離された財務情報／経済的特徴が概ね類似／10％基準（売上高・利益・資産のいずれか）／75％基準。
B-2　潜在株式調整後1株当たり当期純利益を開示しない場合
問潜在株式調整後1株当たり当期純利益の算定の考え方を述べ、これを開示しない場合を挙げなさい。1株当たり当期純損失の場合の取扱いにも触れなさい。
解答例

結論　開示しないのは①潜在株式なし、②希薄化効果なし、③1株当たり当期純損失の3ケース。

  1. 行使を仮定し分子に調整額・分母に増加株式数を加えて再計算。EPSを下回れば希薄化あり。複数なら最大希薄化効果を反映。
  2. 純損失時は損失が薄まって見えても希薄化効果なしと扱う。
  3. ②③はその旨と算定に含めなかった潜在株式の概要を注記。
入れる語潜在株式なし／希薄化効果なし／1株当たり当期純損失／EPSを下回れば希薄化／算定に含めなかった潜在株式の概要を注記。
B-3　1株当たり当期純利益の算定と遡及修正令元
問(1) 1株当たり当期純利益の分子の算定において、累積型と非累積型の配当優先株式に係る優先配当額はどのように控除するか。(2) 貸借対照表日後に株式分割が行われた場合、および会計方針の変更を遡及適用した場合、1株当たり情報はどのように取り扱うか述べなさい。
解答例

(1)　分子＝当期純利益－普通株主に帰属しない金額。累積型は当期の要支払額、非累積型は配当決議額を控除。

(2)

  • 株式分割・併合：表示する最も古い期間の期首に行われたと仮定し前期分も計算し直す。B/S日後でも遡及する開示後発事象の例外。
  • 会計方針の変更：遡及適用後の金額で各1株当たり情報を算定し直し、前期の影響額を注記。
入れる語普通株主に帰属しない金額／累積型＝当期要支払額／非累積型＝配当決議額／最も古い期間の期首に行われたと仮定／開示後発事象の例外／遡及適用後の金額で算定し直し・影響額を注記。

B-5　関連当事者取引の重要性の判断基準
問関連当事者との取引について開示の要否を判断する重要性の基準を、法人と個人に分けて述べなさい。また、関連当事者に対して資産を無償で貸与している場合、取引金額がゼロであることを理由に開示不要と判断してよいか。
解答例

結論　無償でも金額ゼロで重要性なしとせず、独立第三者間取引を仮定した金額で判定。

  3. 無償・低廉な取引こそ条件が歪み開示趣旨（注意喚起）に当たる。仮定金額で重要なら開示。
