A-1　有価証券の減損処理と回復可能性の判定平27・令5
問甲社は、その他有価証券である上場株式X、市場価格のない子会社株式Y、市場価格のない取引先Z社株式（持分5%）を保有している。有価証券の減損処理が必要となる要件を「著しい下落」「著しい低下」の判定基準を含めて述べなさい。また、Z社株式について回復可能性の判定を行う必要があるか、Y株式と対比して理由を付して説明しなさい。
解答例

結論　時価ありは著しい下落、市場価格なしは実質価額の著しい低下で減損。Zは回復可能性の判定不要。

  1. X：取得原価比50%程度以上下落＝著しい下落。回復する見込みがなければ時価評価し特別損失。30〜50%は社内基準。
  2. 評価は決算日の時価。期末前1か月平均は下落率判定のみ。
  3. Y・Z：実質価額が50%程度以上低下で減額。
  4. Y：事業計画等を入手できおおむね5年以内に回復と裏付けられれば減額不要→判定要。
  5. Z：財政悪化は短期間で回復しないのが通常で証拠も困難→判定せず減損。

減損後は切放方式。

入れる語50%程度以上／回復する見込み／決算日の時価／実質価額／事業計画等を入手／おおむね5年以内／短期間で回復しない／切放方式
A-2　債務超過会社への第三者割当増資と減損平27
問L社は、債務超過にある取引先M社の経営再建のため、M社から詳細な事業計画を受領したうえで第三者割当増資を引き受けた。引受直後のM社株式の実質価額は払込金額の50%を下回っている。L社はM社株式を直ちに減損処理してゼロ評価とすべきか、理由を付して述べなさい。
解答例

結論　直ちにゼロ評価する必要はない。

  1. 再建目的の第三者割当では引受時に実質価額50%以下は当然に生じ得る。機械的に減損しない。
  2. 実行可能な事業計画が合理的なら一定期間は業績を見守る。実績が計画を大幅に下回らなければ減損不要。
  3. 計画は毎期見直し。回復が進まなければその期末に減損。一定期間後も債務超過が解消されなければゼロ評価。
入れる語当然に生じ得る／機械的に減損しない／実行可能な事業計画／大幅に下回らなければ／毎期見直し／債務超過が解消されなければゼロ

問市場価格のない株式の減損判定に用いる「実質価額」と、発行会社の貸借対照表上の純資産額に持分比率を乗じた「簿価純資産持分額」とが乖離する要因を2つ挙げ、それぞれ説明しなさい。
解答例

結論　①資産・負債の含み損益、②未計上の超過収益力等の価値。

  1. 含み損益　実質価額は時価評価に基づく評価差額等を加味した1株当たり純資産。簿価純資産持分額は帳簿価額のまま。土地等の含み損益分だけ乖離。
  2. 超過収益力等　実質価額には超過収益力（自己創設のれん）や経営権を織り込むことがあるが、これらは財務諸表に計上されないため乖離。
入れる語時価評価に基づく評価差額／帳簿価額のまま／含み損益／超過収益力／自己創設のれん／財務諸表に計上されない
A-4　満期保有目的の債券の要件と一部売却平27
問甲社は当期にD社社債を取得した。D社社債を満期保有目的の債券に区分するための要件を示しなさい。また、甲社が当期中に資金運用方針の変更により満期保有目的の債券の一部を売却した場合、残りの債券の取扱いを理由とともに述べなさい。
解答例

結論　①額面償還予定の債券で、②満期まで保有する積極的な意思と能力がある場合。一部売却なら残り全部を他区分へ。

  1. 属性　償還日の定めがあり額面償還が予定される債券（永久債は不可）。
  2. 意思と能力　満期まで保有する積極的な意思と能力。資金繰り・法律上の障害があれば不可。時価評価を免れる区分ゆえ高いハードル。
  3. 判定は取得時。他区分から満期保有への振替は不可。
  4. 一部売却　売却・振替があれば残りすべてを他区分（その他有価証券）へ振替、一定期間は分類不可。約束を破ったペナルティ。
  5. よって当期の一部売却で意思・能力が否定されたD社社債はその他有価証券。
入れる語額面償還が予定／積極的な意思と能力／判定は取得時／満期保有への振替は不可／残りすべてを他区分へ／一定期間は分類不可
A-5　ヘッジ会計の意義と方法（繰延ヘッジ・時価ヘッジ）
問ヘッジ会計が必要となる理由を「損益のミスマッチ」の観点から説明し、日本基準におけるヘッジ会計の方法を述べなさい。また、時価ヘッジの対象がその他有価証券に限られる理由を説明しなさい。
解答例

結論　対象と手段の損益を同一期間に認識しヘッジ効果を反映する処理。原則繰延ヘッジ、容認時価ヘッジ。

  1. 必要性　デリバティブは時価評価で損益、対象は損益未認識→損益のミスマッチ。ヘッジの実態が映らない。
  2. 繰延ヘッジ　手段の損益を対象の損益認識まで純資産に繰延（税効果適用）。手段を対象に合わせる。
  3. 時価ヘッジ　対象の評価差額を損益にし、対象を手段に合わせる。対象は時価評価するが差額が損益にならないもの＝その他有価証券のみ。借入金は時価評価できず対象外。
  4. 公正価値ヘッジ・CFヘッジは取引の分類。日本は処理と直結せず、IFRSは直結。
入れる語同一期間に認識／損益のミスマッチ／繰延ヘッジ＝原則・純資産に繰延／時価ヘッジ＝容認／その他有価証券のみ／公正価値ヘッジ・CFヘッジ
A-6　予定取引のヘッジ対象適格平27・平29
問D社は今後数年間の月々の輸入取引（個別の契約は未締結）に充てる目的で、円売りドル買いの為替予約を包括的に締結した。この為替予約にヘッジ会計を適用できるか、予定取引がヘッジ対象となる要件を示して述べなさい。また、未履行の確定契約をヘッジ対象とする場合の留意点を述べなさい。
解答例

結論　要件を満たす範囲で、予定取引の包括ヘッジとしてヘッジ会計を適用できる。

  1. 予定取引＝①未履行の確定契約、②契約未締結でも主要な取引条件が合理的に予測可能で実行される可能性が極めて高い取引。
  2. ②は過去の頻度・取引を行う能力・行わない不利益、代替取引の有無、期間・数量の妥当性を総合的に吟味。
  3. D社の反復的な輸入は要件を満たす範囲で適用可。包括ヘッジゆえ手段の損益は個々の取引に合理的に配分。遠い将来分は対象外。
  4. 確定契約　形式でなく契約の拘束力に留意。解除対価が軽微なら未締結と同じで②の検討要。不実行が明らかになればヘッジ会計終了、繰延損益を当期損益。
入れる語主要な取引条件が合理的に予測可能／実行される可能性が極めて高い／頻度・能力・不利益／包括ヘッジ＝合理的に配分／契約の拘束力／解除対価が軽微
A-7　ヘッジ会計の要件と有効性の評価令元・令6
問ヘッジ会計を適用するための要件を、ヘッジ取引時の要件（事前テスト）とヘッジ取引時以降の要件（事後テスト）に分けて説明しなさい。あわせて、ヘッジ有効性の評価の頻度と方法を述べなさい。
解答例

結論　事前テスト（リスク管理方針に従うことの客観的確認）と事後テスト（効果の定期的確認）の2要件。

  1. 事前　①取引がリスク管理方針に従うことを文書で確認できる、または②明確な内部規定・内部統制組織があり従って処理されると期待できる。文書には手段・対象・有効性評価方法を明記。
  2. 事後　対象と手段の損益が高い程度で相殺（公正価値ヘッジ）またはCFが固定（CFヘッジ）される状態が継続し、効果が定期的に確認されていること。
  3. 有効性評価　決算日には必ず、少なくとも6か月に1回。開始時からの変動累計を比較し80%〜125%なら有効。
  4. 趣旨　評価差額を損益にしない特殊処理ゆえ利益操作を防止。IFRSに数値基準なし。振当処理も同じ2要件。
入れる語リスク管理方針／文書で確認・内部規定・内部統制組織／高い程度で相殺／決算日には必ず・6か月に1回／80%〜125%／利益操作を防止
A-8　ヘッジ会計の中止と終了（ロールオーバーとキャンセル）平27
問N社は商品仕入（予定取引）の価格変動リスクをヘッジするため商品スワップを締結し、繰延ヘッジを適用している。(1) 当初の商品スワップが満期を迎え決済されたが予定取引はまだ実行されておらず、N社は新たな商品スワップを締結した。(2) その後、当該仕入取引がキャンセルされ実行されないことが明らかになった。それぞれの会計処理を理由とともに述べなさい。
解答例

(1) 中止　手段の満期消滅で要件不充足→中止。対象の予定取引は存続し損益未認識のため、決済損益は繰延ヘッジ損益として繰延継続。予定取引実行時に商品の取得価額に加減。中止後に重要な損失のおそれがあれば見積り当期損失。

(2) 終了　予定取引の不実行が明らか→対応させる対象の損益が生じないため終了。繰延ヘッジ損益を直ちに当期の損益へ。以後のスワップは通常のデリバティブとして時価評価。

考え方　中止＝対象が残るから繰延継続。終了＝合わせる相手が消えるから即損益。

入れる語中止＝手段の消滅・要件不充足／繰延継続／取得価額に加減／重要な損失のおそれ＝見積り計上／終了＝対象の不実行／直ちに当期の損益
A-9　在外子会社株式を外貨建借入金でヘッジする場合令元
問I社は在外子会社J社の株式（子会社株式）に係る為替変動リスクをヘッジするため、外貨建長期借入金をヘッジ手段に指定した。I社は少数のヘッジ取引しか行っていない。(1) ヘッジ会計の適用にあたり明確にすべき事項、(2) 有効性の評価の要否と方法、(3) 借入金から生じた為替換算差額の個別・連結財務諸表上の表示を、理由とともに述べなさい。
解答例

(1) 文書化　開始時に正式な文書で①手段と対象（J社株式の為替リスク／外貨建借入金）、②有効性の評価方法を明確化。少数のヘッジ取引なら個々の取引ごとの文書による。手段はデリバティブに限らず外貨建金銭債務も可。

(2) 有効性　決算日に必ず、6か月に1回以上、変動累計の比率80〜125%で判定。対象と手段の通貨が異なる場合は事後テストを省略不可。

(3) 表示　個別：純資産の繰延ヘッジ損益。J社株式は原価評価で換算差額が生じないため、借入金の換算差額を対象の損益認識まで繰延。連結：為替換算調整勘定に含めて表示。J社の換算から生じる為替換算調整勘定と同一科目で相殺され、ヘッジ効果が反映される。

入れる語正式な文書／手段と対象・有効性の評価方法／個々の取引ごと／通貨が異なれば省略不可／個別＝繰延ヘッジ損益／連結＝為替換算調整勘定に含めて相殺
A-10　金融資産の消滅の認識（財務構成要素アプローチとIFRSとの対比）
問金融資産の譲渡において消滅を認識する考え方である「リスク・経済価値アプローチ」と「財務構成要素アプローチ」を説明し、日本基準が採用する立場と支配の移転の要件を述べなさい。あわせてIFRSの判定構造との違いを説明しなさい。
解答例

結論　日本基準は財務構成要素アプローチ、支配の移転時に消滅認識。IFRSはリスク・経済価値の移転度合いが基本、中間ケースのみ支配で判定。

  1. 消滅＝権利の行使・喪失・支配の移転。譲渡は権利が移るだけで消えないため認識単位が問題。
  2. リスク・経済価値　資産を一体とみてほぼ全ての移転で判定するオール・オア・ナッシング。
  3. 財務構成要素　要素ごとに分解し消滅・存続を判定（日本基準）。回収サービス留保も要素別に処理。
  4. 支配移転の要件　①譲受人の権利が倒産隔離、②譲受人が利益を享受、③譲渡人に買戻す権利・義務なし（担保付貸借の売買処理を防止）。
  5. IFRS　リスク・経済価値をほとんどすべて移転→消滅、保持→継続、中間→支配で判定。日本は要素別ゆえ中間ケースなし。
入れる語権利の行使・喪失・支配の移転／一体・オール・オア・ナッシング／要素ごとに分解／倒産隔離・利益を享受・買戻す権利・義務なし／IFRS＝移転度合い→中間ケースは支配
A-11　IFRSの金融資産の分類とOCIオプション
問IFRS第9号における金融資産の分類の判定手順を説明しなさい。また、資本性金融商品に認められるOCIオプションの内容とリサイクリングが禁止される趣旨を述べ、減損に関する日本基準との差異を説明しなさい。
解答例

結論　SPPIテストと事業モデルでAC・FVOCI・FVPLに分類。

  1. SPPI：CFが元本と利息の支払のみか。株式・デリバティブは不合格→FVPL。
  2. 事業モデル：回収のみ→AC、回収と売却→FVOCI（リサイクリングあり）、他→FVPL。
  3. 公正価値オプション：会計上のミスマッチ解消のためFVPL指定可。
  4. OCIオプション：売買目的以外の株式を取消不能でFVOCI指定可。代償にリサイクリング禁止＝下落をOCIに残し売却益だけ出す利益操作の防止。
  5. 減損：IFRSは予想信用損失（12か月／全期間）で戻入あり。日本は切放しで戻入なし。
入れる語SPPIテスト／事業モデル＝回収のみ・回収と売却／AC・FVOCI・FVPL／OCIオプション＝取消不能／リサイクリング禁止＝利益操作の防止／予想信用損失・戻入あり

B-1　有価証券の保有目的別評価の理由
問有価証券の貸借対照表価額と評価差額の処理を保有目的区分ごとに示し、「時価の変動を投資の成果とみるか」という観点からそれぞれの理由を説明しなさい。
解答例

結論　時価の変動を投資の成果とみるかで評価と差額処理を分ける。

  1. 売買目的：時価・損益。時価変動そのものが成果。
  2. 満期保有：償却原価。元利CFの受取が目的で時価変動は無関係。
  3. 子会社・関連会社：取得原価。事業投資で売却を想定しない。
  4. その他：時価だが売却未確定で成果と言えず純資産直入（税効果適用）。部分直入法は容認。
  5. 市場価格なし株式：取得原価。金融負債は債務額。
入れる語時価変動＝投資の成果／償却原価＝元利CFが目的／事業投資＝取得原価／売却未確定＝純資産直入／税効果／金融負債は債務額
B-2　保有目的区分の変更
問有価証券の保有目的区分の変更が認められる場合を挙げなさい。また、その他有価証券から売買目的有価証券へ、およびその他有価証券から子会社株式へ変更する場合の振替価額と評価差額の処理を、理由とともに述べなさい。
解答例

結論　正当な理由なく変更不可。原則は変更前区分で最後の評価をして振替。

  1. 認められる場面：運用方針の変更、追加取得・売却で子会社等に該当・非該当、法令改正。満期保有への振替は不可。
  2. その他→売買目的：時価で振替、差額は当期損益。評価差額金を残せないため。
  3. その他→子会社・関連会社：帳簿価額で振替。投資継続中に損益を出せないため。
入れる語正当な理由／変更前区分で最後の評価／売買目的へ＝時価・当期損益／子会社株式へ＝帳簿価額／満期保有への振替は不可
B-3　有価証券売却損益の表示区分平27
問甲社はその他有価証券であるF社株式を売却した。売却損益の損益計算書上の表示区分を、F社株式が取引関係維持を目的とする政策保有株式である場合と、純投資目的で反復的に売買している場合に分けて述べなさい。子会社株式・満期保有目的の債券を売却した場合の表示にも触れなさい。
解答例

結論　その他有価証券の売却損益は臨時的なら特別損益、それ以外は営業外損益。

  1. 政策保有株式の売却や運用方針変更による売却は臨時→特別損益。F社株式はこれ。
  2. 純投資で反復売買→経常性あり→営業外損益。
  3. 子会社・関連会社株式：特別損益、売却益と売却損を総額表示。
  4. 満期保有目的の債券：合理的理由の売却は営業外、それ以外は特別損益。
入れる語臨時的＝特別損益／政策保有株式／純投資＝経常性＝営業外／子会社株式＝特別損益・総額表示
B-4　その他資本剰余金を原資とする配当の受領令6
問保有するその他有価証券の発行会社から、その他資本剰余金を原資とする配当を受領した。配当受領額を受取配当金として収益計上せず、有価証券の帳簿価額から減額する理由を述べなさい。また、売買目的有価証券がこの取扱いの対象外とされる理由を説明しなさい。
解答例

結論　払込資本の払戻し（投資の一部回収）のため、原則帳簿価額から減額。

  1. 発行会社の払込資本が減り、株式の価値も同額低下。収益計上すると投資原価の回収計算が歪む。
  2. よって受領額を帳簿価額から減額し、投資の払戻しとして処理。
  3. 売買目的：収益計上しても同額の下落が時価評価の評価差額で損益に反映され結果が同じ→対象外。
入れる語払込資本の払戻し／投資の一部回収／投資原価の回収計算／帳簿価額から減額／売買目的＝時価評価で結果が同じ
B-5　貸倒見積高の算定とIFRSの減損モデル
問債権を債務者の財政状態および経営成績等に応じて区分し、それぞれの貸倒見積高の算定方法を説明しなさい。あわせてIFRSの減損モデルとの相違を述べなさい。
解答例

結論　一般債権・貸倒懸念債権・破産更生債権等に区分し、悪化するほど個別・厳格に見積る。

  1. 一般債権：貸倒実績率等で算定（貸倒実績率法）。
  2. 懸念債権：担保・保証の回収見込額を控除した残額を個別に見積る（財務内容評価法）。
  3. 破産更生債権等：控除後の残額の全額。
  4. 未収利息は計上せず、計上済みも取消。
  5. IFRS：予想信用損失モデル。著しい増大なければ12か月分、あれば全期間分。
入れる語一般債権＝貸倒実績率／懸念債権＝担保・保証控除後の残額を個別／破産更生債権等＝残額の全額／未収利息は計上せず／予想信用損失＝12か月・全期間
B-6　減損処理を行った有価証券の注記令5
問A社は当年度、その他有価証券に分類される上場株式であるL株式について減損処理を行った。A社の連結財務諸表の「有価証券関係」注記において記載すべき事項を述べなさい。
解答例

結論　減損処理を行った旨と減損処理額を注記し、L株式は減損後の金額を取得原価として記載。

  1. 当期に減損した場合、減損処理を行った旨および減損処理額を注記。
  2. 減損後の金額が翌期首の取得原価（切放方式）となるため、その他有価証券の注記ではL株式を減損後の金額で記載。
  3. 連結B/S計上額が取得原価を超えるもの・超えないものに区分し、種類ごとに取得原価・計上額・差額を記載。
入れる語減損処理を行った旨／減損処理額／切放方式／超えるもの・超えないもの／種類ごとに取得原価・計上額・差額

C-1　金利スワップの特例処理
問変動金利の借入金に固定払いの金利スワップを付した場合に認められる特例処理の内容と要件を述べ、これが認められる理由を説明しなさい。
解答例

想定元本・受払条件・契約期間がほぼ同一なら、時価評価せず受払純額を利息に加減できる。実態は固定借入と同じで、繰延ヘッジでも繰延ヘッジ損益はゼロに収束し区分の実益がないため。

C-2　金融資産・金融負債の発生の認識
問有価証券の売買契約について約定日基準が採用される理由を、商品売買に係る金銭債権債務の認識時点と対比して述べなさい。
解答例

有価証券・デリバティブは契約締結時から時価変動リスクを負うため約定日に認識。商品売買の金銭債権債務は受渡し・役務提供の完了で認識。当初認識は時価。

C-3　ローン・パーティシペーションとデット・アサンプション
問ローン・パーティシペーションおよびデット・アサンプションについて、本来は消滅の認識が認められない理由と、経過措置として消滅の認識が認められる要件を述べなさい。
解答例

ローン・パーティシペーション：倒産隔離を欠くがリスク・経済的利益がほぼ全て移転なら経過措置で消滅可。デット・アサンプション：第一次債務者のままだが遡求可能性が極めて低いなら消滅可。
