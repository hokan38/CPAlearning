第21章　期中財務諸表重要度A 2問／B 3問／C 3問｜出題実績：平26

重要度A白紙に書けるレベルまで（記述で実際に問われた論点・新基準で唯一の実質改正論点）

A-1　原価差異の繰延処理平26
問標準原価計算を採用するT社では、上半期の操業度が季節的に低いため中間会計期間に不利な原価差異が生じている。T社が期中財務諸表においてこの原価差異を売上原価に賦課せず繰り延べることができる要件を示し、そのような処理が認められる理由を述べなさい。
解答例

結論　次の2要件をいずれも満たす場合に、継続適用を条件として、原価差異を流動資産または流動負債として繰り延べることができる。

  1. 標準原価計算等を採用している企業において、予定価格または標準原価が年間を基礎として設定されているため、当該原価差異が操業度等の季節的な変動に起因して発生したものであること。
  2. 当該原価差異が原価計算期間末（年度末）までにほぼ解消が見込まれること。
  3. 理由：年間を基礎に予定価格等を設定している場合、季節的変動による差異は年度を通じて相殺され年度末にはほぼ解消する。これを期中会計期間の売上原価に賦課すると、期中の損益が年度の実態を表さない。そこで、例外的に認めた方が経済的実態をより適切に表し将来の業績予測に資する情報を提供できる期中特有の会計処理として繰延処理が認められている。
  4. 期中会計期間を年度の一構成部分と位置付けて年度の業績予測に資する情報を提供する予測主義的な処理であり、要件が厳しく実務での適用はほとんどないが、要件2つは書けるようにしておく。
入れる語年間を基礎として設定／季節的な変動に起因／年度末までにほぼ解消／継続適用／流動資産・流動負債／期中特有の会計処理／期中損益が年度の実態を表さない。
A-2　有価証券の減損処理と期中洗替え法への統一
問U社（3月決算）は取得原価40,000の有価証券について、中間会計期間末に時価が17,000に著しく下落し回復可能性がないと判断して減損処理を行った。年度末の時価は28,000であった。期中洗替え法と期中切放し法のそれぞれによる年度の損益への影響を示し、期中財務諸表に関する会計基準が期中洗替え法に統一した理由を述べなさい。
解答例

結論　新基準では従来の選択適用が認められなくなり、期中洗替え法に統一された（従来から期中切放し法を採用していた会社のみ継続適用可）。

  1. 期中洗替え法　中間会計期間末に評価損23,000（40,000－17,000）を計上するが、年度末には取得原価40,000に戻して改めて判定する。年度末に時価が28,000へ回復していれば、年度の損益計算書に評価損は計上されない。期末までに回復すれば減損がなかったことになる。
  2. 期中切放し法　中間会計期間末の時価17,000が新たな取得原価となり、評価損23,000は年度末まで残る。年度末の回復は反映されない。
  3. 統一の理由　切放し法では、中間財務諸表のみを作成する会社と取引所規則に基づく四半期に係る財務情報も作成する会社とで年度の評価損が変わり得る（第3四半期末時価が15,000なら作成会社は25,000、非作成会社は23,000）。企業の報告の頻度（年次・半期・四半期）によって年次の経営成績の測定が左右されてはならないという原則から、選択適用は認められなくなった。
  4. 期中財務諸表に関する会計基準で会計処理が実質的に変わったのはこの点だけであり、新基準の出題論点として最優先で押さえる。
入れる語期中洗替え法に統一／取得原価に戻す／切放し法＝新たな取得原価／報告の頻度／年次の経営成績の測定が左右されてはならない／継続適用のみ可。

重要度B聞かれたら説明できるレベル（骨子が書ければよい3論点）

B-1　実績主義と予測主義
問期中財務諸表の作成に関する「実績主義」と「予測主義」の考え方をそれぞれ説明し、期中財務諸表に関する会計基準がどちらの立場を採用しているかを、その例外とともに述べなさい。
解答例

結論　制度会計上は実績主義を基本としつつ、期中特有の会計処理という予測主義的な例外を認めている。

  1. 対比の軸は、期中会計期間を年度と並ぶ一会計期間とみるか、年度の一構成部分と位置付けるかの一点である。
  2. 実績主義は年度と並ぶ一会計期間とみる。原則として年度の財務諸表と同じ会計処理の原則及び手続を適用し、当該期中会計期間に係る財政状態、経営成績及びキャッシュ・フローの状況に関する情報を提供することを目的とする。
  3. 予測主義は年度の一構成部分と位置付ける。当該期中会計期間を含む年度の業績予測に資する情報の提供を目的とし、年度の財務諸表と部分的に異なる会計処理の原則及び手続を適用する。
  4. 沿革：1977年に中間財務諸表の開示が始まった当初は予測主義、2000年の中間連結財務諸表の制度化に伴う基準見直し以降は一貫して実績主義。ただし四半期制度（2008年）以降は原価差異の繰延処理と税金費用の計算という期中特有の会計処理を認めており、純粋な実績主義ではない。
入れる語年度と並ぶ一会計期間か年度の一構成部分か／年度と同じ会計処理の原則及び手続・財政状態等の状況に関する情報／業績予測に資する情報／実績主義＋例外（期中特有の会計処理）。
B-2　会計方針の基本的な考え方と簡便的な会計処理
問期中財務諸表の作成にあたって適用する会計方針の基本的な考え方を、原則・容認・例外に分けて説明しなさい。また、収益の認識基準を検収基準から出荷基準へ、棚卸資産の評価方法を先入先出法から総平均法へ変更することは、期中財務諸表における簡便的な会計処理として認められるか述べなさい。
解答例

結論　原則・容認・例外の三段構えである。検収基準→出荷基準、先入先出法→総平均法の変更は簡便的な会計処理として認められない。

  1. 原則　実績主義を基本に据えるため、期中特有の会計処理を除き、原則として年度の財務諸表の作成にあたって採用する会計方針に準拠しなければならない。
  2. 容認　開示の迅速性が求められ、中間財務諸表には45日以内の開示という適時性に係る強い制約があるため、利用者の判断を誤らせない限り簡便的な会計処理によることができる。
  3. 例外　期中特有の会計処理は原価差異の繰延処理と税金費用の計算の2つのみである。
  4. 収益及び費用の認識及び測定は財務諸表の信頼性の根幹をなすため、年度と同一の会計処理が適用されなければならず簡便な会計処理は認められない。検収基準から出荷基準へ、先入先出法から総平均法へといった変更は簡便化ではなく会計方針の変更にあたる。

簡便的な会計処理の一覧を網羅的に暗記する必要はなく、この線引きを押さえれば足りる。

入れる語年度の会計方針に準拠／適時性・45日／簡便的な会計処理／期中特有の会計処理は2つのみ／認識及び測定は簡便化不可／会計方針の変更。
B-3　税金費用の計算
問期中財務諸表における税金費用の計算について、原則的な方法と期中特有の会計処理として認められる方法を対比して説明しなさい。あわせて、繰延税金資産の回収可能性の判断において前年度末の検討を利用できる要件、および重要性が乏しい連結会社に認められる簡便法を述べなさい。
解答例

原則　年度決算と同様の方法により計算し、繰延税金資産及び繰延税金負債は回収可能性等を検討した上で期中貸借対照表に計上する。中間であれば半年経過時点の数字で税額を算定し、税効果会計も正しく適用する。

容認（期中特有の会計処理）

  1. 年度の税引前当期純利益に対する税効果会計適用後の実効税率を着地見込みで合理的に見積り、この見積実効税率を税引前期中純利益に乗じる。当年度の予測を使う点が予測主義的である。
  2. この方法では繰延税金資産及び繰延税金負債を前年度末の額のまま期中貸借対照表に計上し（回収可能性や適用税率の変更は検討）、損益計算書上も法人税等と法人税等調整額を区分しない。

回収可能性判断の簡便法　①重要な企業結合・事業分離や業績の著しい好転・悪化など経営環境の著しい変化が生じていない（会社全体の観点）、かつ②一時差異等の発生状況に前年度末から大幅な変動がない（税効果の観点）の2要件を満たせば、前年度末の検討で使用した将来の業績予測やタックス・プランニングを利用でき、通常は企業の分類も前年度末と同じになる。

重要性が乏しい連結会社　税金費用＝税引前期中純利益×前年度の税効果会計適用後の法人税等負担率。前年度の実績を使う簡便的な会計処理であり、当年度の予測を使う見積実効税率を乗じる方法とは別物なので混同しない。

入れる語年度決算と同様が原則／見積実効税率×税引前期中純利益／繰延税金は前年度末のまま・区分しない／経営環境の著しい変化なし＋一時差異の大幅変動なし／前年度の負担率（実績）。

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　期中財務諸表の範囲と開示対象期間
問期中財務諸表として作成される計算書類の範囲と、比較情報として開示される期間について述べなさい。
解答例

期中株主資本等変動計算書の開示は行わず、株主資本の金額に著しい変動があった場合は主な変動事由を注記する。期中連結財務諸表を開示する場合には期中個別財務諸表の開示は要しない。開示対象期間は、貸借対照表が期中会計期間の末日と前年度の末日（要約貸借対照表）、損益計算書・キャッシュ・フロー計算書は期首からの累計期間と前年度における対応する期間である。四半期開示制度の見直しにより2024年から半期報告書・中間財務諸表の開示に一本化され、四半期基準と中間基準を統合したのが企業会計基準第37号である。

C-2　期中財務諸表の開示
問期中財務諸表の表示および注記の基本的な方向性を述べなさい。
解答例

表示は年度の財務諸表に準じるが、利用者の判断を誤らせない限り科目の集約記載ができる。注記は年度より簡略化したうえで、株主資本の金額の著しい変動や営業収益または営業費用の著しい季節的変動など、前年度と比較して著しい変動がある項目は注記で補う。細かな注記一覧の暗記は不要である。

C-3　IFRS（IAS第34号）との対比
問期中財務諸表に関する日本基準とIFRSの主な差異を3点挙げなさい。
解答例

①IFRSは持分変動計算書の作成が求められるが、日本は期中株主資本等変動計算書を開示しない。②原価差異の繰延処理はIFRSでは認められないが、日本は期中特有の会計処理として容認する。③税金費用はIFRSでは年度の予想加重平均税率による見積計算（日本の期中特有の処理と同様の方法）によるが、日本は年度決算と同様の方法が原則で、見積実効税率を乗じる方法は期中特有の会計処理（容認）にとどまる。
