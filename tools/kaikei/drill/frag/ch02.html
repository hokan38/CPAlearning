B-1　純利益の重視と日本基準の3つの特徴
問我が国の討議資料『財務会計の概念フレームワーク』は純利益を重視しているといわれる。その理由を示したうえで、純利益の重視から導かれる日本基準の計算構造上の特徴を3点挙げ、IFRSと対比して説明しなさい。
解答例

結論　投資家の企業価値評価に必要な将来キャッシュ・フローの予測にとって利益情報が最も重要であるため純利益を重視し、①ハイブリッド構造、②2種類のクリーン・サープラス関係、③その他の包括利益の必然的なリサイクリング、という特徴が導かれる。

  1. 財務報告の目的は、投資家による企業成果の予測と企業価値の評価に役立つ企業の財務状況の開示にある。企業価値の評価にはいずれの評価モデルによっても将来キャッシュ・フローの予測が必要であり、その予測に最も有用な情報が過去の投資の成果を表す利益情報であるから、我が国の会計基準は純利益を最も重要な数値と位置づける。
  2. 特徴①　資産・負債だけでなく純利益にも独立した定義を与えているため、計算構造は純粋な資産負債アプローチではなく、収益費用アプローチの考え方も加味したハイブリッド構造である。
  3. 特徴②　包括利益と純資産の間のクリーン・サープラス関係に加え、純利益と株主資本の間のクリーン・サープラス関係が存在し、むしろ後者を重視する。純利益を独立に定義したままでは貸借対照表と損益計算書が連携しないため、純資産の中に株主資本という区分を設けて純利益と連携させた。
  4. 特徴③　包括利益も純利益も一致の原則を満たすので、両者の差は期間帰属の違い（期ズレ）にすぎない。ゆえにその他の包括利益は必ずリサイクリングされる。

IFRSとの対比　IFRSは資産負債アプローチであり、株主資本が定義されず、純利益と連携する財政状態計算書の項目がない。またその他の包括利益にリサイクリングを行わない部分があるため、IFRSの純利益は一致の原則を満たさず、最終的にネット・キャッシュ・フローと一致しない。

入れる語将来キャッシュ・フローの予測／純利益の重視／ハイブリッド構造／クリーン・サープラス関係が2種類／一致の原則・期ズレ／必ずリサイクリング／IFRS＝資産負債アプローチ・株主資本の定義なし。
B-2　財務諸表の構成要素（8要素）と定義構造
問討議資料における財務諸表の構成要素を挙げ、そのうち独立した定義が与えられているものを示しなさい。また、その定義構造から読み取れる日本基準の性格を説明しなさい。
解答例

結論　構成要素は資産・負債・純資産・株主資本・包括利益・純利益・収益・費用の8つであり、独立した定義をもつのは資産・負債・純利益の3つである。討議資料は資産負債アプローチ一辺倒ではない。

  1. 資産は過去の取引または事象の結果として報告主体が支配している経済的資源、負債はその経済的資源を放棄もしくは引き渡す義務またはその同等物であり、いずれも独立に定義される。
  2. 純資産は資産と負債の差額、包括利益は特定期間の純資産の変動額のうち株主等との直接的な取引によらない部分であり、資産・負債に従属して定義される。株主資本は純資産のうち報告主体の所有者である株主（連結上は親会社株主）に帰属する部分として、純資産の内訳として定義される。
  3. 純利益は、特定期間の期末までに生じた純資産の変動額（株主等との直接的な取引による部分を除く）のうち、その期間中にリスクから解放された投資の成果であって報告主体の所有者に帰属する部分と独立に定義される。収益・費用は純利益を増減させる項目として純利益に関連づけて定義される。
  4. 資産・負債の定義から始めるのは財務報告の対象を確定する作業が容易になるからであって、特定の測定方法を導く意図ではない。純利益にも独立の定義がある以上、討議資料は資産負債アプローチに立つものではなく、純利益を生み出す投資の正味のストックである株主資本も重視する体系である。
  5. 定義を充足しても財務報告の目的に適合しなければ構成要素とはならない。代表例が自己創設のれんであり、経営者による企業価値の自己評価・自己申告となるため計上されない。
入れる語8つの構成要素／独立定義は資産・負債・純利益／リスクからの解放／所有者に帰属／株主資本は純資産の内訳／資産負債アプローチではない／自己創設のれん。
B-3　純利益と包括利益の関係（一致の原則）
問討議資料における純利益と包括利益の共通点と相違点を説明し、両者の関係からその他の包括利益のリサイクリングが必要とされる理由を述べなさい。
解答例

結論　共通点はいずれも一致の原則を満たすこと、相違点は認識の条件と帰属主体である。両者は期間帰属が異なるだけなので、その他の包括利益は必ずリサイクリングされる。

  1. 企業の投資の成果は最終的に投下した資金と回収した資金の差額であるネット・キャッシュ・フロー（全体利益）により計算され、各期の期間利益の合計が全体利益に等しくなることが利益測定の基本的な制約となる（一致の原則）。包括利益と純利益はともにこの制約を満たす。
  2. 相違①認識　包括利益は投資のリスクからの解放を認識の条件としないが、純利益はリスクから解放された部分のみを認識する。
  3. 相違②帰属主体　包括利益は所有者に帰属する部分に子会社の少数株主に帰属する部分を加えたものだが、純利益は所有者に帰属する部分のみである。
  4. 貸借対照表との関係　包括利益は純資産と、純利益はもっぱら株主資本とクリーン・サープラス関係にある。
  5. 両者とも全体利益に一致する以上、その差は期間帰属の違いにすぎない。その他の包括利益に計上した項目がいずれ純利益として認識されなければ純利益の合計が全体利益に一致しなくなるため、その他の包括利益は必ずリサイクリングされなければならない。
  6. 討議資料は、長期にわたり投資家に利用され有用性を支持する経験的証拠もある純利益を重視しつつ、純利益を超える有用性が見出される可能性もあるため包括利益にも独立した地位を与えている。
入れる語全体利益＝ネット・キャッシュ・フロー／一致の原則／リスクからの解放／所有者に帰属／期間帰属の違いのみ／必ずリサイクリング。
B-4　投資のリスクからの解放と事業投資・金融投資
問「投資のリスクからの解放」の意義を説明し、事業投資と金融投資とで資産の評価がどのように異なるかを述べなさい。
解答例

結論　リスクからの解放とは投資にあたって期待された成果が事実として確定することであり、事業投資は原価評価、金融投資は時価評価となる。

  1. 投資のリスクからの解放とは、投資にあたって期待された成果が事実として確定することをいう。純利益はリスクから解放された投資の成果のみで構成され、収益・費用も資産・負債の増減のうちリスクから解放された部分に限られる。
  2. 事業投資は事業の遂行に拘束されており、事業のリスクに拘束されない独立の資産（キャッシュ・フロー）を獲得した時点で解放される。それまでは成果が確定していないため原価評価する。
  3. 金融投資は事業の目的に拘束されず値上がりを期待して保有するものであり、価値が変動した時点でそのまま成果が確定し解放される。したがって時価評価し、評価差額を純利益に含める。
  4. これが「投資の性格に応じた資産・負債の評価」であり、我が国の会計基準に共通する考え方（期間利益測定上の費用配分、当期純利益と株主資本との連携、投資の性格に応じた評価）の一つである。本来の資産負債アプローチが公正価値評価に傾斜するのに対し、我が国はあくまで期間損益計算の観点から資産・負債を評価する。
入れる語期待された成果が事実として確定／事業投資＝独立の資産の獲得時・原価評価／金融投資＝価値変動時・時価評価／投資の性格に応じた評価／期間損益計算の観点。

C-1　2つの制度会計と比較情報の有無
問会社法会計と金融商品取引法会計の報告体系の主な違いを述べ、比較情報の有無が過去の誤謬の訂正の取扱いにどのように影響するか説明しなさい。
解答例

会社法会計では計算書類（貸借対照表・損益計算書・株主資本等変動計算書・個別注記表）を会社計算規則に従って作成し招集通知等で開示するのに対し、金融商品取引法会計では財務諸表（貸借対照表・損益計算書・株主資本等変動計算書・キャッシュ・フロー計算書・附属明細表）を財務諸表等規則・連結財務諸表規則に従って作成し有価証券報告書「経理の状況」で開示する。処理基準はいずれもGAAPであり、会社法431条は「一般に公正妥当と認められる企業会計の慣行に従う」、財務諸表等規則・連結財務諸表規則は各1条で「規則に定めのない事項はGAAPに従う」と定めるため、会計基準が会計処理のよりどころとなる。

最大の違いは会社法会計では比較情報が示されないことである。このため過去の誤謬について修正再表示を行うといっても、会社法では過去の計算書類を修正して並べるのではなく、前期末までの累積的影響額を当期の期首残高に反映させる取扱いになる（金融商品取引法の実務では訂正報告書で対応する。詳細は第4章）。

C-2　会計基準の設定主体と「係る」「関する」
問我が国の会計基準の設定主体の変遷を述べ、『〜に係る会計基準』と『〜に関する会計基準』の違いを説明しなさい。
解答例

かつては金融庁の諮問機関である企業会計審議会（パブリック・セクター）が会計基準を設定していたが、現在は2001年に設立された民間組織である企業会計基準委員会（ASBJ）が企業会計基準・会計基準適用指針・実務対応報告を開発している。審議会の公表した基準もなお有効であるため、審議会のまま残っているものが『〜に係る会計基準』（意見書・会計基準・注解のセット）、ASBJが開発・改廃したものが『〜に関する会計基準』（本文＋結論の背景）である。日本公認会計士協会の実務指針はASBJに移管され移管指針として再公表された。『企業会計原則』は昭和57年最終改正のまま、その後の会計基準等が優先適用されるため死文化している規定が少なくない。

C-3　指定国際会計基準と修正国際基準
問指定国際会計基準と修正国際基準の違いを述べ、修正国際基準において「削除または修正」の対象とされた項目を挙げなさい。
解答例

我が国では日本基準・米国基準・指定国際会計基準・修正国際基準の4つが並存する。指定国際会計基準はIFRSのうち金融庁長官が指定したもので、一部を指定しない余地のある枠組みだが、実際にはIASBの基準がすべて指定されているため実態はピュアなIFRSのアドプションであり、2010年3月期から任意適用されている。修正国際基準（JMIS）はIFRSの個別基準を検討し、当期純利益の有用性など我が国の基本的な考え方と合わない部分を「削除または修正」して採択するエンドースメントの仕組みである。削除または修正の対象は①のれんの非償却、②その他の包括利益に計上した後に当期純利益に組替調整しない処理（ノンリサイクリング処理）の2項目であり、日本がIFRSに対して基本的な考え方に重要な差異があると意見発信したポイントそのものである。連結財務諸表はいずれも日本基準に代えて作成できるが、個別財務諸表は指定国際会計基準では連結財務諸表を作成していない場合に限り日本基準の個別財務諸表と併せて作成でき、修正国際基準では作成が認められない。

C-4　討議資料の位置づけ（IASBの概念フレームワークとの対比）
問我が国の概念フレームワークの位置づけを、IASBの概念フレームワークと対比して述べなさい。
解答例

我が国の概念フレームワークはASBJが2004年に公表した討議資料であり、デュー・プロセスを踏んだものではないため、我が国には正式な概念フレームワークが存在しない格好となっている。討議資料に準拠した基準開発は行われておらず、IFRSの基準書をそのまま取り入れる形の開発（IFRS第15号→収益認識会計基準、IFRS第13号→時価算定会計基準）が目立ち、概念フレームワークはほぼ機能していない。これに対しIASBの概念フレームワークは正式なプロセスを経て公表・改訂され、実際に基準開発を支えている。それでも討議資料は、①基準開発の指針として機能してきた事実があり、②IASBの概念フレームワークとの対比により日本基準の性格（純利益の重視）を浮かび上がらせる材料となるため確認する価値がある。構成は財務報告の目的・会計情報の質的特性・財務諸表の構成要素・財務諸表における認識と測定の4章である。

C-5　会計情報の質的特性の階層
問討議資料における会計情報の質的特性の階層構造を説明しなさい。
解答例

最も基本的な特性は意思決定有用性であり、投資家が企業の不確実な成果を予測するのに有用であることを求める。これを直接支えるのが意思決定との関連性（情報価値の存在・情報ニーズの充足）と信頼性（中立性・検証可能性・表現の忠実性）であり、さらに基礎から支える一般的制約となる特性として内的整合性（個別基準が会計基準全体を支える基本的な考え方と矛盾しなければ、その基準に従う情報は有用と推定される）と比較可能性がある。内的整合性は討議資料に特徴的な概念である。IASBの概念フレームワークでは「信頼性」は質的特性として識別されておらず、「忠実な表現」が基本的な質的特性とされる点で用語・階層が異なる（第3章参照）。
