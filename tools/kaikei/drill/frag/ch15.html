第15章　外貨建取引重要度A 4問／B 3問／C 3問｜出題実績：平29・令6

重要度A白紙に書けるレベルまで（記述で実際に問われた論点・講師が「復元できるように」と言った論点）

A-1　為替換算調整勘定の各財務諸表における表示令6
問P社は在外子会社S社（持分80%）を連結している。S社の外貨表示財務諸表の換算から生じる為替換算調整勘定は、①連結貸借対照表、②連結損益計算書、③連結包括利益計算書のそれぞれにおいてどのように表示されるか、理由とともに述べなさい。
解答例

結論　①純資産の部に表示、②P/Lには表示されない、③その他の包括利益に表示。

  1. ①B/S　純資産のその他の包括利益累計額に為替換算調整勘定として表示。資産負債CR・資本HRの換算差額で未実現・処分時まで確定しないため損益としない。非支配株主分は振替え、親会社持分相当額のみ。
  2. ②P/L　表示されない。未実現の換算差額で当期損益を構成しないため。ただし支配喪失時は持分減少割合分が株式売却損益になる（支配継続なら資本剰余金）。
  3. ③包括利益計算書　当期変動額は純利益に含まれない純資産変動のためその他の包括利益に表示。支配喪失で実現した分は組替調整額（リサイクリング）。
入れる語その他の包括利益累計額／未実現・処分時まで確定しない／親会社持分相当額／P/Lには表示されない／支配喪失時に株式売却損益／その他の包括利益・組替調整額
A-2　独立処理から振当処理への変更の可否平29
問為替予約について原則的処理（独立処理）を採用してきた甲社が、翌期から振当処理への変更を検討している。この変更は認められるか、両処理の関係を示したうえで理由を付して述べなさい。また、逆に振当処理から独立処理への変更は認められるか。
解答例

結論　独立処理→振当処理は認められない。逆は認められる。

  1. ヘッジ対象と手段を区分して処理する独立処理が原則。
  2. 振当処理は時価評価導入前の実務を当分の間認める経過的特例。財務構成要素アプローチと相容れない。
  3. 原則から特例への変更はより適切な処理への変更ではなく、正当な理由ある会計方針の変更にならない。
  4. 禁止は一方向のみ。振当→独立は可。振当処理はIFRSでは認められない。
入れる語独立処理が原則／経過的特例・当分の間／より適切な処理への変更ではない／正当な理由なし／逆方向は可／IFRSでは認められない
A-3　決算時の換算と為替差損益の処理
問外貨建資産・負債の決算時の換算方法を、貨幣性項目と非貨幣性項目に分けて理由とともに説明しなさい。外貨建有価証券の換算の考え方にも触れること。また、換算差額および決済差額の損益計算書上の処理と表示を理由とともに述べなさい。
解答例

結論　貨幣性＝CR、非貨幣性＝HRで換算。換算差額・決済差額は当期の為替差損益として純額表示。

  1. 貨幣性　外国通貨・金銭債権債務・債券は決算時の為替相場。将来の円貨額が為替変動を受けるため。
  2. 非貨幣性　前渡金・前受金、子会社・関連会社株式は取得時・発生時の相場。円貨の授受済み、または事業投資で売却を想定しないため。
  3. 有価証券　評価方法と整合。時価評価するものは外貨建時価をCRで換算、子会社・関連会社株式はHR。
  4. 差額　換算・決済差額とも為替差損益。単一原因（相場変動）ゆえ区別せず純額で営業外損益に表示。
入れる語貨幣性＝CR／非貨幣性＝HR／時価評価するものはCR／為替差損益／換算・決済差額を区別しない／純額・営業外
A-4　在外支店と在外子会社の換算方法の相違
問在外支店と在外子会社の外貨表示財務諸表の換算方法の相違を、その根拠となる考え方（テンポラル法・決算日レート法）とともに説明しなさい。換算差額の処理の違いにも触れること。
解答例

結論　支店はテンポラル法、子会社は決算日レート法。差額は為替差損益と為替換算調整勘定。

  1. 支店　同一法人で独立性低→本国主義。本店が逐一円換算したのと同じ結果になる測定時点の相場で換算（テンポラル法）。
  2. 子会社　別法人で独立性高→現地主義。現地F/Sの項目比率を保つ決算時の相場で換算（決算日レート法）。
  3. 日本基準は法形式で機械的に判定（IFRSは在外営業活動体の単一概念）。
  4. 差額　支店は為替差損益。子会社は資産負債CRと純資産HRのズレ＝為替換算調整勘定。純資産をHRとするのは親会社投資額と相殺し資本連結を保つため。
入れる語本国主義＝テンポラル法／測定時点の相場／現地主義＝決算日レート法／法形式で判定／支店＝為替差損益／子会社＝為替換算調整勘定／純資産はHR＝資本連結のため

重要度B聞かれたら説明できるレベル（骨子が書ければよい）

B-1　振当処理の適用範囲と為替予約差額の処理
問振当処理の意義と適用できる範囲を述べなさい。また、振当処理において為替予約差額を直々差額と直先差額に区分して処理する理由を、それぞれの差額の性格から説明しなさい。
解答例

結論　予約で円貨CFが固定されることを根拠に対象と手段を一体処理する経過的特例。

  1. 満期保有以外の外貨建有価証券は円貨額が固定されず振当不可。
  2. 手段は為替予約と、通貨スワップのうち為替予約型・直先フラット型のみ。
  3. 直々差額＝予約までの過去の相場変動→即時損益。
  4. 直先差額＝直物と先物の差＝金利差（利息）→期間配分。
  5. 取引以前の予約は事実上の円建取引→予約レートで換算可。
入れる語円貨CFが固定／為替予約型・直先フラット型／直々差額＝過去の変動＝即時損益／直先差額＝金利差＝期間配分／事実上の円建取引
B-2　在外子会社ののれんの換算と子会社持分投資のヘッジ
問在外子会社の連結において、①のれんはどの為替相場で換算されるか、②在外子会社に対する持分投資をヘッジ対象とし同一通貨建ての外貨建借入金をヘッジ手段とした場合、ヘッジ手段から生じた為替換算差額はどのように処理されるか、理由とともに述べなさい。
解答例

結論　①のれんはCR換算、②手段の換算差額は為替換算調整勘定に含めて処理できる。

  1. のれん＝子会社に帰属する資産とみて決算時の為替相場で換算。為替換算調整勘定が発生。
  2. 個別は子会社株式HRで差額なし。連結は持分が資産負債に置き換わり為替換算調整勘定が生じる。
  3. 同一通貨の借入金で資産負債が見合い。借入金の換算差額を為替換算調整勘定でネットしヘッジ効果を反映。
入れる語子会社に帰属する資産＝CR／為替換算調整勘定が発生／個別は子会社株式HR／同一通貨の借入金で見合い／為替換算調整勘定に含めてネット
B-3　IFRSとの主な差異（機能通貨・在外営業活動体・換算差額）
問外貨換算に関する日本基準とIFRSの主な差異を、①機能通貨、②在外営業活動体の財務諸表の換算、③換算差額の処理の3点について説明しなさい。
解答例
  1. 機能通貨　IFRSは主たる経済環境の通貨＝機能通貨を決めて換算。日本基準は円前提で規定なし。
  2. 在外営業活動体　IFRSは支店・子会社を分けず単一概念。資産負債CR、差額はすべてOCI。日本は法形式で支店と子会社に分ける。
  3. 換算差額　貨幣性は両者とも純損益。IFRSは非貨幣性項目の損益がOCIなら換算差額もOCI。
  4. 振当処理はIFRSでは認められない。
入れる語機能通貨＝主たる経済環境の通貨／日本基準は規定なし／在外営業活動体＝単一概念／すべてOCI／非貨幣性項目はOCI／振当処理なし

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　前渡金・前受金および外貨建新株予約権の換算
問外貨建取引のうち前渡金・前受金が充当される部分、および外貨建新株予約権が、取引発生時・決算時のいずれも発生時の為替相場（HR）のまま据え置かれる理由を述べなさい。
解答例

前渡金・前受金は円貨の授受が済んだ非貨幣性項目で為替変動の影響を受けないためHR据置。新株予約権は負債でなく将来資本に振り替える勘定のためHR据置。

C-2　外貨建その他有価証券（債券）の換算差額と減損判定
問外貨建のその他有価証券である債券について、為替変動による差額を評価差額から分離して処理する方法を説明しなさい。また、外貨建有価証券の減損における「著しい下落」の判定はどの通貨ベースで行うか述べなさい。
解答例

その他有価証券の債券は為替変動に起因する差額を評価差額から分離し為替差損益として処理できる。減損の著しい下落判定は外貨建の時価と取得原価を比較し外貨ベースで行う。

C-3　換算のパラドックス
問「換算のパラドックス」とは何か。テンポラル法と決算日レート法のいずれで生じ得るかを理由とともに述べなさい。
解答例

外貨F/Sでは利益なのに円換算後は損失となる（逆も）現象。項目ごとに異なる相場を使うテンポラル法で生じ得る。決算日レート法は項目比率が保持され生じない。
