A-1　為替換算調整勘定の各財務諸表における表示令6
問P社は在外子会社S社（持分80%）を連結している。S社の外貨表示財務諸表の換算から生じる為替換算調整勘定は、①連結貸借対照表、②連結損益計算書、③連結包括利益計算書のそれぞれにおいてどのように表示されるか、理由とともに述べなさい。
解答例

結論　①純資産の部に為替換算調整勘定として表示され、②連結損益計算書には表示されず、③その他の包括利益の内訳項目として表示される。

  1. ①連結貸借対照表　純資産の部の「その他の包括利益累計額」の区分に為替換算調整勘定として表示する。資産・負債は決算時の為替相場、資本項目は株式取得時等の為替相場で換算するために生じる換算差額であり、いまだ実現しておらず処分時まで確定しないため、損益とせず純資産の部に直接計上する。非支配株主持分割合に相当する額は非支配株主持分に振り替えるため、為替換算調整勘定として表示されるのは親会社持分相当額である。
  2. ②連結損益計算書　表示されない。換算手続から生じた未実現の換算差額であり当期の損益を構成しないため、当期純利益に影響を与えない。ただし在外子会社株式の売却等により支配を喪失した場合には、親会社の持分比率の減少割合に相当する額が株式売却損益を構成し、その時点で連結損益計算書に計上される（支配が継続する場合は資本剰余金に振り替え、損益には含めない）。
  3. ③連結包括利益計算書　包括利益は当期純利益にその他の包括利益を加減して算定され、為替換算調整勘定の当期変動額は当期純利益に含まれない純資産の変動額であるから、その他の包括利益の区分に当期発生額として表示する。支配喪失に伴い当期の損益として実現した場合は組替調整額（リサイクリング）として同区分に表示する。
入れる語その他の包括利益累計額／未実現・処分時まで確定しない／親会社持分相当額／P/Lには表示されない／支配喪失時に株式売却損益／その他の包括利益・組替調整額
A-2　独立処理から振当処理への変更の可否平29
問為替予約について原則的処理（独立処理）を採用してきた甲社が、翌期から振当処理への変更を検討している。この変更は認められるか、両処理の関係を示したうえで理由を付して述べなさい。また、逆に振当処理から独立処理への変更は認められるか。
解答例

結論　原則的処理（独立処理）から振当処理への変更は認められない。逆の変更は認められる。

  1. 為替予約等の会計処理は、ヘッジ対象である外貨建金銭債権債務等とヘッジ手段である為替予約等とを区分して処理する独立処理が原則である。
  2. 振当処理は、金融商品会計基準によりデリバティブの時価評価が導入される以前から実務に定着していた処理を当分の間認めることとした経過的な特例にすぎない。本来別々のものをまとめて処理する点で財務構成要素アプローチの発想と相容れないからである。
  3. したがって、いったん原則的処理を採用した企業が経過的特例である振当処理へ変更することは、より適切な会計処理への変更とはいえず、正当な理由に基づく会計方針の変更とは認められない。
  4. 禁止されるのは独立処理から振当処理への一方向のみであり、振当処理を採用していた企業が原則的処理へ変更することは認められる。なお振当処理はIFRSでは認められない。
入れる語独立処理＝原則／振当処理＝経過的特例・当分の間／より適切な処理への変更ではない／正当な理由なし／逆方向は可／IFRSは振当処理を認めない
A-3　決算時の換算と為替差損益の処理
問外貨建資産・負債の決算時の換算方法を、貨幣性項目と非貨幣性項目に分けて理由とともに説明しなさい。外貨建有価証券の換算の考え方にも触れること。また、換算差額および決済差額の損益計算書上の処理と表示を理由とともに述べなさい。
解答例

結論　貨幣性項目は決算時の為替相場（CR）、非貨幣性項目は取得時・発生時の為替相場（HR）で換算し、換算差額・決済差額はいずれも当期の為替差損益として純額で表示する。

  1. 貨幣性項目　外国通貨・外貨建金銭債権債務・債券は決算時の為替相場で換算する。将来の円貨額が為替変動の影響を受けるからである。
  2. 非貨幣性項目　前渡金・前受金、子会社株式・関連会社株式等は取得時または発生時の為替相場で換算する。すでに円貨の授受が済んでいる、または事業投資として売却を想定しないため、為替変動の影響を受けさせない。
  3. 有価証券　金融商品会計基準の評価方法と整合させる。売買目的有価証券・その他有価証券のように時価評価するものは外貨建時価をCRで換算し、子会社株式・関連会社株式はHRで換算する。
  4. 換算差額・決済差額　いずれも当期の為替差損益として処理し、決済差損益と換算差損益を区別しない。差益も差損も為替相場の変動という単一の原因から生じるため総額表示に意味がなく、純額で営業外損益の一項目として表示する。
入れる語貨幣性＝CR／非貨幣性＝HR／時価評価するものはCR／為替差損益／決済差額と換算差額を区別しない／純額・営業外
A-4　在外支店と在外子会社の換算方法の相違
問在外支店と在外子会社の外貨表示財務諸表の換算方法の相違を、その根拠となる考え方（テンポラル法・決算日レート法）とともに説明しなさい。換算差額の処理の違いにも触れること。
解答例

結論　在外支店は本国主義によりテンポラル法（本店と同様の処理）、在外子会社は現地主義により決算日レート法で換算し、換算差額は支店では為替差損益、子会社では為替換算調整勘定とする。

  1. 在外支店　本店と同一法人であり個別財務諸表の構成要素であるため独立性が低く、本国主義による。本店が支店の取引を逐一円換算して処理した場合と同じ結果になるよう、測定時点と同じ時点の為替相場で換算して属性を維持する（テンポラル法）。収益性の低下した棚卸資産のように決算日の数値が付されたものはCRで換算する。
  2. 在外子会社　別法人であり独立性が高いため現地主義による。現地通貨の財務諸表自体を重視し、項目相互の比率を保持するよう資産・負債を決算時の為替相場で換算する（決算日レート法）。
  3. 日本基準は実質ではなく法形式で機械的に判定する。IFRSが在外営業活動体という単一概念を用いる点との違いになる。
  4. 換算差額　支店では特例換算により生じた差額も含め当期の為替差損益として処理する。子会社では資産・負債のCR換算と純資産項目の支配獲得時の為替相場（HR）固定とのズレが為替換算調整勘定として純資産の部に計上される。純資産項目のみHRとするのは、資本をCRで換算すると親会社の投資額（取得時の円貨額）と相殺できず資本連結が壊れるためである。

在外支店に収益・費用のAR換算や貸借対照表項目のCR換算といった簡便な特例処理が認められるのは、支店の重要性が乏しいためである。

入れる語本国主義＝テンポラル法／測定時点のレート／現地主義＝決算日レート法／法形式で判定／支店＝為替差損益／子会社＝為替換算調整勘定／純資産はHR＝資本連結のため

重要度B聞かれたら説明できるレベル（骨子が書ければよい）

B-1　振当処理の適用範囲と為替予約差額の処理
問振当処理の意義と適用できる範囲を述べなさい。また、振当処理において為替予約差額を直々差額と直先差額に区分して処理する理由を、それぞれの差額の性格から説明しなさい。
解答例

結論　振当処理は、為替予約により将来の円貨キャッシュ・フローが固定されることを根拠にヘッジ対象と手段を一体処理する経過的特例であり、為替予約差額はその性格に応じて直々差額は即時、直先差額は期間配分する。

  1. 意義　予約により将来の円貨キャッシュ・フローが固定されるからこそ対象と手段を一体処理できる。したがって円貨額が固定されないもの（満期保有目的以外の外貨建有価証券）は、ヘッジ会計の要件を満たしても振当処理はできない。
  2. 手段の範囲　先物為替予約は基本的に振当処理できるが、通貨スワップはスワップレートが先物為替相場と同じ為替予約型と、借入時と償還時のレートを同じにし円で資金調達した場合と同じレート設定にする直先フラット型の2つに限られる。それ以外の通貨スワップや通貨オプションは為替予約と同視できないため認められない。
  3. 直々差額　予約締結時までにすでに生じていた為替相場の変動による差額であり、過去の期間に属するため予約日の属する期の損益として即時処理する。
  4. 直先差額　直物相場と先物相場の差であり、二通貨の金利差＝利息の性格を持つため、予約日の属する期から決済日の属する期までの期間にわたって配分する（償却原価法に準じて利息の調整として処理することも可）。
  5. 仕入・売上と同時またはそれ以前に予約を締結した場合は当初から円貨額が確定しており事実上の円建取引であるため、取引自体に予約レートによる円換算額を付す方法が認められる。
入れる語円貨CFの固定／為替予約型・直先フラット型／直々差額＝過去の変動＝即時損益／直先差額＝金利差＝期間配分／事実上の円建取引
B-2　在外子会社ののれんの換算と子会社持分投資のヘッジ
問在外子会社の連結において、①のれんはどの為替相場で換算されるか、②在外子会社に対する持分投資をヘッジ対象とし同一通貨建ての外貨建借入金をヘッジ手段とした場合、ヘッジ手段から生じた為替換算差額はどのように処理されるか、理由とともに述べなさい。
解答例

結論　①のれんは子会社の他の資産と同様に決算時の為替相場で換算し、②ヘッジ手段の為替換算差額は為替換算調整勘定に含めて処理できる。

  1. のれんの換算　制度上、のれんは子会社に存在する超過収益力＝子会社に帰属する資産とみて、子会社の他の資産と同様に決算時の為替相場で換算する。期末残高の換算と償却額（原則AR）の換算の両方から為替換算調整勘定が発生する。
  2. 持分投資のヘッジ　個別上、子会社株式はHRで換算され換算差額が生じないが、連結では持分が子会社の資産・負債に置き換わり為替換算調整勘定が生じる。同一通貨の外貨建借入金をヘッジ手段とすれば貸借対照表上で資産と負債のポジションが見合いになる。
  3. そこでヘッジ手段の借入金から生じた為替換算差額を為替差損益とせず為替換算調整勘定に含めてネットする方法が認められ、ヘッジの効果を連結財務諸表に反映できる。円安基調では子会社持分の為替換算調整勘定がプラス、借入金からは為替差損（繰延ヘッジ損益はマイナス）となり、両者が打ち消し合う。
入れる語のれん＝子会社に帰属する資産＝CR／為替換算調整勘定が発生／個別は子会社株式HR／同一通貨の借入で見合い／為替換算調整勘定に含めてネット
B-3　IFRSとの主な差異（機能通貨・在外営業活動体・換算差額）
問外貨換算に関する日本基準とIFRSの主な差異を、①機能通貨、②在外営業活動体の財務諸表の換算、③換算差額の処理の3点について説明しなさい。
解答例
  1. 機能通貨　IFRSは複数の通貨が入り混じる環境も想定するグローバル基準であるため、企業が営業活動を行う主たる経済環境の通貨＝機能通貨をまず決定し、外貨建項目を機能通貨に換算する構成をとる。日本基準は通貨といえば円という単純な世界を前提としており、機能通貨の規定は存在しない。
  2. 在外営業活動体　IFRSは支店・子会社を分けず在外営業活動体という単一の概念で規定し、資産・負債は決算時の為替相場、収益・費用は取引時の為替相場（実務上は期中平均相場で近似）で換算し、換算差額はすべてその他の包括利益とする。日本基準は法形式により在外支店（テンポラル法）と在外子会社等（決算日レート法）に分けて規定する。
  3. 換算差額　IFRSでは貨幣性項目の換算差額は原則として純損益であり日本基準と同じだが、非貨幣性項目に係る損益がその他の包括利益に認識される場合は換算差額もその他の包括利益となる。日本基準ではその他有価証券が該当するものの、為替変動部分を為替差損益とする方法が認められるため完全に同じではない。
  4. 為替予約の振当処理はIFRSでは認められない。
入れる語機能通貨＝主たる経済環境の通貨／日本基準に規定なし／在外営業活動体＝単一概念／換算差額はすべてOCI／非貨幣性項目のOCI／振当処理なし

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　前渡金・前受金および外貨建新株予約権の換算
問外貨建取引のうち前渡金・前受金が充当される部分、および外貨建新株予約権が、取引発生時・決算時のいずれも発生時の為替相場（HR）のまま据え置かれる理由を述べなさい。
解答例

前渡金・前受金の充当部分はすでに円貨の授受が済んでおり、その後の為替変動の影響を受けない非貨幣性項目であるため、金銭授受時の為替相場のままとし、決算時もHRで据え置く。外貨建新株予約権は負債ではなく払込額を将来資本に振り替えるための勘定であり、為替変動の影響を受けさせないためHRで据え置く。これに対し区分法における社債対価部分は金銭債務であるためCRで換算する。

C-2　外貨建その他有価証券（債券）の換算差額と減損判定
問外貨建のその他有価証券である債券について、為替変動による差額を評価差額から分離して処理する方法を説明しなさい。また、外貨建有価証券の減損における「著しい下落」の判定はどの通貨ベースで行うか述べなさい。
解答例

その他有価証券のうち債券については、外貨ベースの時価変動（価格変動リスク）による差額と為替変動に起因する差額とを区分し、後者を為替差損益として処理することが認められる。為替差損益を評価差額から分離できる点がポイントである。減損の著しい下落の判定は外貨建の時価と外貨建の取得原価とを比較して外貨ベースで行う。円安局面では円換算では50%未満の下落でも外貨ベースでは50%以上下落していることがあり得るため、判定結果が変わる点に注意する。

C-3　換算のパラドックス
問「換算のパラドックス」とは何か。テンポラル法と決算日レート法のいずれで生じ得るかを理由とともに述べなさい。
解答例

換算のパラドックスとは、外貨表示財務諸表上は当期純利益であるのに円換算後は損失となる（またはその逆の）現象をいう。項目ごとに異なる為替相場を用いるテンポラル法では起こり得るが、全項目を決算時の為替相場で換算する決算日レート法では項目相互の比率が保持されるため生じない。
