A-1　在外子会社の会計方針の統一（実務対応報告第18号）平27・令5
問G社の在外子会社H社はIFRSに準拠して財務諸表を作成している。G社は連結決算手続上H社の財務諸表をそのまま利用できるか。利用できる場合に修正が求められる項目を挙げ、それらに限定される理由を述べなさい。また、H社が市場価格のない株式を公正価値で測定している場合、この差異について連結決算手続上の修正が必要か、理由を付して答えなさい。
解答例

結論　当面の間そのまま利用できる。ただし5項目は修正。市場価格のない株式の評価差異は修正する必要はない。

  1. 原則は会計方針を統一。ただし作り直しは不可能で差異も縮小したため当面の取扱いとして容認。
  2. 修正5項目：①のれんの償却②数理計算上の差異③研究開発費の支出時費用④投資不動産の時価評価・固定資産の再評価⑤資本性金融商品OCIの組替調整。
  3. 5項目は限定列挙。いずれも当期純利益が適切に計上されるための修正（費用配分・リサイクリング）。
  4. 当該株式はIFRS＝公正価値、日本＝取得原価。差異は5項目外で純利益にも影響しないため修正不要。
  5. 重要性が乏しければ修正不要。
入れる語当面の取扱い／5項目の限定列挙／当期純利益が適切に計上されるための修正／のれんの償却・数理計算上の差異・研究開発費・投資不動産・組替調整／公正価値と取得原価／修正不要。
A-2　のれんの非償却と開発費の資産計上の修正平27・令5
問A社の在外子会社D社はIFRSに準拠して財務諸表を作成しており、のれんを償却せず、また開発費を無形資産に計上している。A社が連結決算手続上行うべき修正を述べなさい。なお、のれんについて減損処理が行われている場合の取扱いにも触れること。
解答例

結論　のれんは規則的に償却、開発費は支出時の費用とするよう修正する。

  1. のれん　20年以内のその効果の及ぶ期間で定額法等により規則的に償却。非償却は費用配分の考え方と乖離。
  2. 減損済みの場合　減損後簿価が規則的な償却を行った場合の金額を下回るなら修正不要。以後は減損処理後の帳簿価額に基づいて償却。
  3. 開発費　研究開発費に該当する支出は支出時の費用に修正。資産計上額を費用に振り替え、償却費も併せて取り消す。
  4. 重要性が乏しい場合を除く。
入れる語20年以内・規則的償却／費用配分の考え方と乖離／減損後簿価が規則償却後の額を下回れば修正不要／以後は減損後簿価で償却／支出時の費用・償却費も取消。
A-3　子会社の判定（議決権40％の場合の要件）平28・令4
問D社は乙社の議決権の40％を自己の計算において所有しており、乙社を関連会社として扱ってきた。乙社がD社の子会社に該当することとなる要件を3つ挙げなさい。あわせて、子会社判定の原則的な取扱いの全体像を説明しなさい。
解答例

結論　自己の計算で40％以上50％以下を所有するため、次のいずれかに該当すれば子会社。

  1. 緊密な者・同意している者の議決権と合わせて過半数。
  2. 役員・使用人（元を含む）が取締役会等の構成員の過半数。
  3. 重要な方針の決定を支配する契約等の存在。
  4. 資金調達額の総額の過半を融資（債務保証・担保含む）。その他支配が推測される事実。

全体像　支配力基準。①過半数を自己の計算で所有→直ちに子会社。②40％以上50％以下→上記いずれか。③40％未満→緊密な者・同意している者と合わせ過半数を必要条件に、他の要件のいずれか。相互保有株式は議決権算定から除く。

入れる語支配力基準／自己の計算で40％以上／緊密な者・同意している者と合わせ過半数／構成員の過半数／方針の決定を支配する契約／資金調達額の総額の過半／推測される事実。
A-4　議決権のみによる判定とIFRS第10号との相違令4
問(1) 議決権の所有割合のみから、他の企業の意思決定機関を支配していないと判断できるのはどのような場合か、理由とともに述べなさい。
(2) IFRS第10号における支配の判定が日本基準と異なる点を2つ述べなさい。
解答例

(1)　自己の計算で40％未満、かつ緊密な者及び同意している者と合わせても過半数を占めない場合。

  • 議決権以外の事実（役員・契約・融資等）を検討するのは、40％以上か、40％未満でも合算で過半数の場合に限る。
  • よって上記の場合は議決権以外の事実関係を考慮するまでもなく支配なし。

(2)　IFRS第10号はパワー・変動リターンに対するエクスポージャー・両者のリンクの3要素で判定。相違点は2つ。

  1. 40％以上50％以下のような議決権の所有割合に関する数値基準を定めていない。
  2. 現に行使可能な潜在的議決権を考慮する。日本基準に規定なし。
入れる語40％未満かつ合算で過半数未満／議決権以外の事実関係を考慮するまでもなく／パワー・変動リターン・リンク／数値基準を定めていない／潜在的議決権。
A-5　支配継続中の子会社株式の一部売却平27
問P社は子会社S社株式の一部を売却したが、売却後も支配は継続している。連結財務諸表上の会計処理を、のれんの未償却額、売却に関連する法人税等、および資本剰余金が負の値となる場合の取扱いを含めて説明しなさい。
解答例

結論　支配継続中の一部売却は非支配株主との資本取引として処理する。

  1. 売却持分を親会社持分から減額し、非支配株主持分に増額。
  2. 売却持分と売却価額の差額は売却損益とせず資本剰余金。個別上の売却損益は連結上修正。
  3. 関連する法人税等は資本剰余金から控除。
  4. のれんの未償却額は減額せず、償却をそのまま継続。
  5. 資本剰余金が負になれば連結会計年度末に零とし、利益剰余金から減額。
入れる語非支配株主との資本取引／売却損益ではなく資本剰余金／法人税等は資本剰余金から控除／のれんの未償却額は減額しない／負なら零として利益剰余金から減額。
A-6　一部売却時にのれんの未償却額を減額すべきか平30
問支配が継続する子会社株式の一部売却において、売却した持分に対応するのれんの未償却額を減額すべきか否か、あなたの考えを理由とともに述べなさい。
解答例

結論　減額すべきではない。

  1. 支配継続中の一部売却は非支配株主との資本取引。投資と資本の相殺消去をやり直す取引ではないため、のれんを取り崩す理由なし。
  2. 追加取得でのれんを追加計上しないことと整合。

反対説　売却持分に対応するのれんの償却が継続すると、親会社株主に帰属する当期純利益の期間計算が歪む。

入れる語資本取引／相殺消去のやり直しではない／追加取得でのれんを追加計上しないことと整合／（反対説）償却が継続し親会社株主に帰属する当期純利益が歪む。
A-7　非支配株主持分が「純資産×非支配株主持分比率」と一致しない原因平28
問連結貸借対照表上の非支配株主持分の金額が、子会社の個別貸借対照表上の純資産額に非支配株主の持分比率を乗じた金額と一致しない原因として考えられる事由を挙げなさい。
解答例

結論　主な事由は次の4つ。

  1. 評価差額　全面時価評価法の評価差額は連結上の子会社資本を構成するが、個別の純資産には含まれない。
  2. アップ・ストリームの未実現損益　全額消去・持分按分負担方式で非支配株主持分にも負担。
  3. 子会社の新株予約権　個別の純資産だが子会社の資本に含まれず、非支配株主持分の算定基礎とならない。
  4. 子会社の欠損　出資額を超える欠損は親会社の持分に負担させ、非支配株主持分は零を下限。
入れる語評価差額は個別にない／アップ・ストリームの持分按分負担／新株予約権は子会社の資本でない／欠損は零を下限・親会社の持分に負担。
A-8　のれんの計上範囲（購入のれん方式と全部のれん方式）平28
問我が国の連結会計基準はのれんの計上について購入のれん方式と全部のれん方式のいずれを採用しているか。両方式の違いを非支配株主持分の測定と関連付けて説明し、それぞれが整合する連結基礎概念を述べなさい。
解答例

結論　日本基準は購入のれん（部分のれん）方式。

  1. 購入のれん　対価と識別可能純資産時価の親会社が取得した持分割合に見合う額との差額。非支配株主持分は識別可能純資産時価の持分額。
  2. 非支配株主持分相当のれんは計上しない。非支配株主を外部者とみる親会社説に整合。
  3. 全部のれん　子会社全体の時価と識別可能純資産時価の差額。非支配株主持分に相当するのれんも計上し、非支配株主持分はのれん込みで測定。経済的単一体説に整合。
  4. 差は非支配株主持分相当のれんの有無と非支配株主持分の測定方法。IFRSは結合ごとに選択可。
入れる語日本＝購入のれん／親会社が取得した持分割合に見合う額／全部のれん＝子会社全体の時価・非支配株主持分に相当するのれんも計上／非支配株主持分の測定方法／親会社説と経済的単一体説／IFRSは選択可。

重要度B聞かれたら説明できるレベル（骨子が書ければよい8論点）

B-1　子会社の決算日が異なる場合（日本基準とIFRS）平29
問子会社の決算日が連結決算日と異なる場合の取扱いについて、日本基準を示したうえで、IFRS第10号の原則的な取扱いと例外的な取扱いを説明し、日本基準と異なる点を述べなさい。
解答例

日本基準　原則は連結決算日に正規の決算に準ずる合理的な手続で決算。差異3か月以内なら子会社の正規の決算を基礎とし、連結会社間取引の重要な不一致を整理。

IFRS　原則は同日現在の追加的な財務情報を連結。実務上不可能な場合に限り直近の決算を使用可（重要な事象の調整・3か月以内・毎期同一）。

相違点　実務上不可能な場合に限定、調整が企業集団外部との取引にも及ぶ。

入れる語正規の決算に準ずる合理的な手続／3か月以内／連結会社間取引の重要な不一致／同日現在の追加的な財務情報／実務上不可能な場合に限定／毎期同一／企業集団外部との取引にも及ぶ。
B-2　リサイクリングと当期純利益の位置づけ令2
問日本基準は、その他の包括利益に計上した退職給付に係る調整額などをその後必ず当期純利益に組み替える。日本基準がリサイクリングを求める理由を、IFRSの考え方と対比して述べなさい。
解答例

結論　当期純利益を最重要指標と位置づけ、その全体性と株主資本との連繋を確保するため。

  1. 投資のリスクから解放された時点で組み替えると、純利益の累計がCFと一致する全体性（完全性）を保てる。
  2. 純利益と株主資本の連繋（クリーン・サープラス関係）でPLとBSが結びつく。
  3. IFRSは包括利益を重視し組替えを行わない項目を認めるため、全体性は確保されない。
入れる語当期純利益が最重要指標／投資のリスクから解放／全体性（完全性）／クリーン・サープラス／IFRSは組替えを行わない項目を認める。
B-3　連結の範囲と小規模子会社の任意除外
問P社は、資産・売上高とも小規模であることを理由に子会社T社を連結の範囲から除外している。T社は多額の含み損失を抱えている。この処理の当否を、連結の範囲の決定に関する原則と重要性の判断基準を示して述べなさい。
解答例

結論　多額の含み損失を抱えるT社は量的に小さくても除外できず、不適切。

  1. 原則はすべての子会社を連結。除外は支配が一時的等の強制除外と、重要性の乏しい小規模子会社の任意除外のみ。
  2. 量的基準は資産・売上高・利益・利益剰余金の4項目。数値規定なし。
  3. 質的基準：経営戦略上重要、セグメント情報に影響、多額の含み損失等を抱える子会社は除外不可。
  4. IFRSは例外規定なし。
入れる語すべての子会社を連結／支配が一時的／小規模子会社の任意除外／資産・売上高・利益・利益剰余金／質的に重要なら除外不可／IFRSは例外規定なし。
B-4　子会社の判定の例外的な取扱い
問次の各社は自社の子会社に該当するか、理由を付して判定しなさい。
(a) 議決権の60％を所有するが、更生手続が開始され管財人が経営権を握っている会社
(b) ベンチャーキャピタルである自社が投資育成目的で議決権の55％を保有し、上場後に大部分を売却する合理的な計画がある会社
(c) 自社が資産の流動化のために設立し、適正な価額で資産を譲渡した特別目的会社
(d) 自社が議決権の40％を所有し役員も派遣しているが、他に議決権の過半数を自己の計算で所有する株主がいる会社
解答例

結論　いずれも子会社に該当しない。有効な支配従属関係が存在しないため。

  1. (a)　管財人等が権限を握り支配なし。
  2. (b)　投資育成目的で、売却する合理的な計画があれば該当しない。
  3. (c)　連結すると譲渡資産の売却がなかったことになる。適正価額譲渡・目的どおり遂行なら子会社に該当しないものと推定。
  4. (d)　複数の企業が同時に支配することはない。他に過半数所有者がいれば支配なし。
入れる語有効な支配従属関係が存在しない／管財人／投資育成・売却する合理的な計画／譲渡資産の売却がなかったことになる／該当しないものと推定／他に過半数所有者がいれば支配なし。
B-5　段階取得に係る損益と支配喪失時の処理
問(1) 段階的に株式を取得して支配を獲得した場合の連結上の子会社株式の取得原価と、段階取得に係る損益の考え方を説明しなさい。
(2) 子会社株式の売却により支配を喪失した場合の残存投資の評価を述べ、(1)との整合性についてIFRSと対比して論じなさい。
解答例

(1)　連結上の取得原価は支配獲得日の時価。個々の取引ごとの原価の合計額との差額が段階取得に係る損益。従来の投資をいったん時価で清算した（投資の清算）とみるため。持分法適用なら持分法評価額との差額。

(2)　支配喪失は損益取引。残存投資は持分法評価額または個別簿価で評価し投資の継続とみる。獲得時の清算擬制と整合していない。IFRSは残存持分を公正価値で再評価。

入れる語支配獲得日の時価／原価の合計額との差額＝段階取得に係る損益／投資の清算／持分法評価額との差額／喪失時は持分法評価額または個別簿価（継続）／整合していない／IFRSは公正価値で再評価。
B-6　債務超過の子会社と非支配株主持分
問子会社に欠損が生じ、非支配株主持分に割り当てられる欠損の額が非支配株主の出資額を超えた。連結上の処理とその理由を述べ、例外的な取扱いおよびIFRSとの相違にも触れなさい。
解答例

結論　非支配株主の負担は原則出資額まで。超過額は親会社の持分に負担させ、非支配株主持分は零が下限。

  1. 株主有限責任により株主の負担は出資額までのため。
  2. 例外　出資を超えた負担が合意されていればその額まで負担させ、マイナスになり得る。
  3. その後の利益は親会社負担分が回収されるまで親会社に加算。
  4. 親会社説に整合。IFRSは単一体説で非支配持分が負の残高でも按分。
入れる語零が下限／出資額まで／超過額は親会社の持分に負担／株主有限責任／合意があれば負担／回収されるまで親会社に加算／IFRSは負の残高でも按分。
B-7　持分法適用関連会社が債務超過に陥った場合
問持分法を適用している関連会社が債務超過に陥った。投資会社が負担すべき損失の範囲と、その連結財務諸表への反映方法を説明しなさい。
解答例

結論　負担の範囲は3段階、持分法評価額は原則零が下限。

  1. 原則　支配していないため負担は投資額の範囲。
  2. 損失分担契約・貸付金・債務保証等で負担割合が定まればその割合まで、投資会社しか資力がなければ債務超過額の全額。
  3. 反映順序　①投資有価証券を零まで減額②貸付金等を減額③超過分は持分法適用に伴う負債。

B-8　連結基礎概念と日本基準・IFRSの対比
問親会社説と経済的単一体説の違いを説明し、連結会計における日本基準とIFRSの主な差異をこの視点から説明しなさい。
解答例

連結基礎概念　親会社説は非支配株主を外部者、経済的単一体説は内部構成員とみる。日本基準は平成25年改正で単一体説に接近。

  1. のれん　日本は購入のれんのみ、IFRSは全部のれんも選択可。
  2. 償却　日本は20年以内で規則的償却、IFRSは非償却＋毎期減損テスト。
  3. 子会社の欠損　日本は零を下限、IFRSは負の残高も按分。
  4. 支配喪失時　日本は投資の継続、IFRSは公正価値で再評価。
入れる語非支配株主＝外部者か内部構成員か／平成25年改正／購入のれんと全部のれん／規則的償却と毎期減損テスト／零を下限と負の残高／投資の継続と公正価値で再評価。

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　子会社株式の減損とのれんの一時償却
問親会社が個別財務諸表上子会社株式を減損処理した場合、連結上ののれんはどのように取り扱うか述べなさい。
解答例

子会社株式の減損は親会社持分の減少の裏返しで、連結上のれんが過大。減損後簿価が「連結上の親会社持分＋のれん未償却額」を下回るなら差額をのれん未償却額に達するまで一時償却。

C-2　支配喪失後も残る資本剰余金
問支配継続中の追加取得・一部売却により生じた資本剰余金は、その子会社が連結の範囲から外れた後どうなるか、理由とともに述べなさい。
解答例

連結除外後も連結上引き続き資本剰余金として引き継がれる。株主（内部者）との資本取引から生じた項目のため、支配を喪失しても消えない。

C-3　親子会社間の会計方針の統一
問買収により子会社化した会社の会計方針が親会社と異なる場合、どのように統一すべきか述べなさい。
解答例

同一環境下で行われた同一の性質の取引等について統一する。親会社に合わせるとは限らずより合理的な会計方針を選択。統一のための変更は正当な理由による会計方針の変更。

C-4　連結と持分法の相違点
問持分法は「一行連結」と呼ばれるが、連結と持分法の会計処理の相違点を4つ挙げなさい。
解答例

一行連結で親会社株主に帰属する当期純利益と純資産への影響が同じ。相違は①部分時価評価②段階取得も投資日ごとの原価③付随費用は投資原価に算入④追加取得・一部売却は損益取引。
