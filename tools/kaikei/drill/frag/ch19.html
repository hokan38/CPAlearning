A-1　費用認識の根拠と各期の費用計上額令3
問自社の株式またはストック・オプションを報酬として付与した場合、付与日から権利確定日までの各会計期間の費用計上額はどのように算定するか。費用として認識する理由と併せて説明しなさい。
解答例

結論　各期の費用計上額＝公正な評価額×（対象勤務期間のうち当期末までの期間÷対象勤務期間）－前期までの費用計上額。

  1. 費用認識の理由　ストック・オプションを付与し、これに応じて従業員等から取得したサービスをその取得に応じて消費したから、その対価を費用として計上する。サービスの価値は信頼性をもって測定することができないため、付与日に等価で交換されたストック・オプションの公正な評価額で算定し、相手勘定は貸借対照表の純資産の部に新株予約権として計上する。
  2. 公正な評価額＝公正な評価単価×ストック・オプション数（株式数）。
  3. 単価は付与日現在で算定しその後は見直さない（条件変更の場合を除く）。
  4. 数は付与数から権利不確定による失効の見積数を控除して算定し、権利確定まで見積りを見直す。「単価は固定・数は見積り」の対比で覚える。
  5. 対象勤務期間は付与日から権利確定日までであり、株価上昇の利益を期待して追加的な労働サービスが提供される期間である。

算定技法の変更は、異なる特性のストック・オプションを付与した場合や、より優れた算定技法が開発された場合に認められる。

入れる語取得に応じて費用／サービスの消費／公正な評価単価×数／付与日で固定・見直さない／失効見積数／対象勤務期間で按分。
A-2　失効見積数の見直しと権利確定日の処理令3
問(1) 付与日から権利確定日の直前までの間に権利不確定による失効の見積数に重要な変動が生じた場合、(2) 権利確定日における会計処理を、それぞれ説明しなさい。
解答例

(1) 見直し時

  1. 権利確定条件の達成見込みを見直し、株式数（ストック・オプション数）を見直す。会計上の見積りの変更として扱い遡及処理はしない。
  2. 見直し後の数に基づく公正な評価額により、その期までに費用計上すべき額とこれまでの計上額との差額を見直しを行った期の損益として一括計上する。公正な評価単価は見直さない。

(2) 権利確定日

  1. 株式数を権利の確定した実際の数（権利確定数）と一致させる。
  2. 修正後の数に基づく公正な評価額により、権利確定日までに計上すべき額とこれまでの計上額との差額を権利確定日の属する期の損益とする。これにより費用計上額の累計は権利確定数に基づく公正な評価額と一致する。
入れる語重要な変動／見積りの変更・遡及なし／差額を見直した期の損益／権利確定数に一致／累計＝確定数ベースの評価額。
A-3　取締役への株式無償交付（事前交付型・事後交付型）令3
問取締役の報酬等として株式を無償交付する取引について、事前交付型と事後交付型それぞれの対価の会計処理を説明しなさい。また、権利確定条件が達成されず企業が譲渡制限付株式を無償取得した場合の処理を述べなさい。
解答例

結論　取得したサービスをその取得に応じて費用計上する点は共通だが、貸方の処理が異なる。

事前交付型　対象勤務期間の開始後速やかに譲渡制限付株式を発行済みで、既に株式が交付されているため新株予約権や株式引受権は計上しない。新株発行の場合、費用に対応する金額を資本金または資本準備金に計上し、年度通算で過年度費用を戻し入れるときは対応額をその他資本剰余金から減額する。自己株式処分の場合はその他資本剰余金とする。

事後交付型　条件達成後に株式が発行されるため、発行までの間、費用に対応する金額を純資産の部に株式引受権として計上し、割当日に資本金または資本準備金に振り替える（自己株式処分なら自己株式の取得原価と株式引受権の帳簿価額との差額を自己株式処分差額として処理）。新株予約権は行使時の払込みを伴う権利であるため無償交付には使えず、別個の純資産科目を設けた。行使価格ゼロのオプションのイメージである。

無償取得（没収）　新株発行で交付していた場合、無償取得した株式を自己株式の数のみの増加として処理し、帳簿価額は増加させない。無償で発行され企業が対価を支払わずに取得したためである。過年度費用の戻入れはその他資本剰余金から減額する。自己株式処分で交付していた場合は、割当日に減額した自己株式の帳簿価額のうち無償取得した部分に相当する額の自己株式を増額し、同額のその他資本剰余金を増額する。

入れる語事前交付型＝株式交付済み／資本金または資本準備金／戻入れはその他資本剰余金／事後交付型＝株式引受権／割当日に振替／自己株式の数のみの増加。
A-4　従業員持株会型ESOPと総額法令6・令7
問従業員持株会に信託を通じて自社の株式を交付する取引において、企業が期末に適用する会計処理の名称と内容、およびその適用要件を説明しなさい。
解答例

結論　総額法を適用する。

  1. 総額法とは、信託の資産及び負債を企業の資産及び負債として貸借対照表に計上し、信託の損益を企業の損益として損益計算書に計上する処理である。
  2. 要件は、委託者である企業が信託の変更をする権限を有しており、かつ企業に信託財産の経済的効果が帰属しないことが明らかであるとは認められない場合（要するに経済的効果が企業に帰属する可能性がある場合）。
  3. この場合、信託が子会社または関連会社に該当するか否かの判定を行うことなく、期末において総額法を適用する。連結でもそのまま引き継ぐ。
  4. 趣旨は、企業が信託の変更権限を持ち、借入金に債務保証を付し資金不足が生じれば債務保証の履行等により不足額を負担する以上、信託を企業から切り離せないことにある。
  5. ただし完全一体ではない。信託に残存する自社の株式は信託における帳簿価額により株主資本において自己株式として計上し（企業の当初の帳簿価額と異なり得る）、企業が保有する自己株式と帳簿価額を通算せず、企業・信託間の配当等も相殺消去しない。
入れる語総額法／信託の資産・負債・損益を企業のものとして計上／信託の変更をする権限／経済的効果が帰属しないことが明らかとは認められない／子会社等の判定不要／信託における帳簿価額。
A-5　IFRS第2号との対比
問ストック・オプション等の会計処理について、日本基準とIFRS第2号の主な相違点を述べなさい。
解答例
  1. 範囲　IFRS第2号は持分決済型のほか現金決済型等も含むすべての株式に基づく報酬取引に適用される包括基準。日本基準は持分決済型の株式に基づく報酬取引のみを規定する。
  2. 付与日　IFRSの付与日は株式に基づく報酬契約に合意した日（株主総会の承認等を条件とする場合はその承認が得られた日）、日本基準の付与日は会社法上の募集新株予約権の割当日であり、付与日が異なるため測定の基準が相違し、費用計上額が変わる。
  3. 株式市場条件（株価条件）　IFRSでは目標株価などの株式市場条件を付与した資本性金融商品の公正価値を見積る際に考慮に入れるため、日本基準のような付与日の一時の費用計上は求められない。
  4. 条件変更　日本基準は条件変更日の公正な評価単価と付与日の公正な評価単価を比較し、下回れば追加費用なし。IFRSは条件変更の直前と直後で測定した公正価値を比較するため、行使価格の引下げなら公正価値は必ず上がり増加分を必ず反映する。
  5. 失効（最大の差異）　日本基準は権利不行使による失効に対応する部分を新株予約権戻入益として利益計上する。IFRSは権利確定日後の資本合計に事後的な修正を行ってはならないとして戻入れによる利益計上を行わない（資本の中での振替は可）。
入れる語持分決済型のみ／付与日の定義／株式市場条件は公正価値の見積りに考慮／条件変更の直前と直後の比較／戻入れによる利益計上なし。

重要度B聞かれたら説明できるレベル（骨子が書ければよい5論点）

B-1　条件変更（行使価格の引下げ）
問株価の著しい下落によりインセンティブ効果が大幅に失われたため、これを回復する目的で付与済みストック・オプションの行使価格を引き下げた。この条件変更の会計処理を理由とともに説明しなさい。
解答例

結論　条件変更日の公正な評価単価が付与日の単価を上回る場合、その増加分を残存期間にわたり追加的に費用計上する。下回る場合は付与日単価に基づく費用計上を継続する。

  1. 行使価格を引き下げれば本源的価値が増えるため、変更の直前直後で比べれば評価単価は必ず上がる（引上げは不利益変更で通常行われない）。
  2. 本来は条件変更日の公正な評価単価で測り直したいが、付与日の公正な評価単価を下回る場合にそれを行うと費用総額が減ってしまい妥当でない。そこで付与日の公正な評価単価に基づく公正な評価額による費用計上を継続し、総額は減らさない。
  3. 上回る場合だけ、上回る部分に見合う公正な評価額の増加額を残存期間にわたり追加的に費用計上する。
  4. ストック・オプション数を変動させる条件変更・費用の合理的な計上期間を変動させる条件変更は、計算問題で処理を確認しておけば足りる。
入れる語条件変更日の公正な評価単価＞付与日の公正な評価単価／増加額を残存期間にわたり追加的に費用計上／下回っても減額しない／総額は減らさない。
B-2　権利確定日後の処理と有償ストック・オプション令5
問(1) 権利確定日後に権利不行使による失効が生じた場合の処理、(2) 権利確定条件付き有償新株予約権の会計処理を説明しなさい。
解答例

(1)　失効に対応する新株予約権を新株予約権戻入益として特別利益に、失効が確定した期に計上する。権利行使時は新株発行・自己株式処分とも通常の新株予約権と同じ処理である。

(2)　払込みがあっても権利確定条件（勤務条件及び業績条件、または業績条件）が付されていれば労働や業務執行等のサービスの対価であるからストック・オプションに該当し費用認識する（サービスの対価として用いられていないことを立証できる場合のみ払込資本を増加させる可能性のある部分を含む複合金融商品の会計処理に従う）。通常のストック・オプションとの差は払込みがある点だけで、①払込金額を純資産の部に新株予約権として計上する、②費用計上額＝公正な評価額－払込金額、③権利不確定の場合は新株予約権として計上した払込金額のうち失効に対応する部分を利益として計上する。

入れる語新株予約権戻入益／特別利益／確定した期／労働や業務執行等のサービスの対価／公正な評価額－払込金額。
B-3　株式給付型ESOP令6
問株式給付型ESOPの仕組みと、企業における費用および引当金の算定方法を説明しなさい。
解答例
  1. 企業が金銭の信託を行い、信託がその資金で自社の株式を取得する（新株発行・自己株式処分なら資金は企業に戻る）。取引を通算すると「会社が従業員に株式を報酬として渡した」だけが残るため、企業側で費用計上する。
  2. 費用およびこれに対応する引当金＝従業員に割り当てられたポイントに応じた株式数×信託が自社の株式を取得したときの株価を基礎として計上する。信託による取得が複数回にわたる場合は平均法または先入先出法により算定する。
  3. 信託から従業員に株式が交付される場合はポイントの割当時に計上した引当金を取り崩す（取崩額＝信託が自社の株式を取得したときの株価×交付された株式数）。
  4. 退職給付の一環として最後に株式を交付するイメージで、仕組みは持株会型よりシンプル。その他は持株会型と同じく総額法による。
入れる語企業側で費用計上／ポイントに応じた株式数×信託が取得したときの株価／平均法・先入先出法／引当金の取崩し。
B-4　基準の適用範囲（親会社が子会社の従業員等に付与）
問親会社が子会社の従業員等に対して親会社株式を対象とするストック・オプションを付与した場合の会計処理を、ストック・オプション等会計基準の適用範囲に触れて説明しなさい。
解答例

結論　定義上のストック・オプションではないが、財貨またはサービスの取得の対価として自社株式オプションを付与する取引に該当し、親会社の個別財務諸表において費用として計上する。

  1. 基準の範囲は①企業がその従業員等に対しストック・オプションを付与する取引、②財貨またはサービスの取得において対価として自社株式オプションを付与する取引（①以外）、③財貨またはサービスの取得において対価として自社の株式を交付する取引であり、②は①と、③は②と整合的に処理する。基準名の「等」がこれを示す。
  2. 親会社が子会社において享受したサービスの消費であるから、親会社の個別財務諸表において費用として計上する。
  3. 子会社の報酬体系に組み入れられている等、子会社においても報酬として位置付けられている場合は子会社の個別財務諸表においても費用として計上し、同時に報酬の負担を免れたことによる利益を特別利益として計上する。
入れる語自社株式オプションを付与する取引／①と整合的に処理／親会社の個別財務諸表で費用／子会社は費用＋特別利益。
B-5　従業員持株会型ESOPの仕組み
問従業員持株会型ESOPの取引の流れを説明し、これが従業員の福利厚生として機能する理由を述べなさい。
解答例
  1. 企業が金銭の信託を行い（設定費用等）、受託者は企業による債務保証が付された金融機関等からの借入金により企業の株式をまとめて取得し、従業員持株会へ毎月一定額を時価により売却する。
  2. 株価上昇局面では売却株式数が取得株式数より少なくなり、株式の売却代金と配当金を原資として借入金及び借入利息を返済してもなお信託に資金の余剰が生じる。この余剰金は従業員に分配され、企業に帰属することはない。
  3. 株価下落局面では信託において資金に不足が生じるが、企業が債務保証の履行等により不足額を負担するため従業員は損失を負わない。だから福利厚生として機能する。
  4. 日本の上場企業は持株会を備える会社が多いため持株会型が主流で、株式給付型が本来の米国ESOPに近い。
入れる語債務保証付き借入／持株会へ時価で売却／余剰は従業員へ／不足は企業が負担。

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　未公開企業における本源的価値
問未公開企業がストック・オプションを付与した場合の会計処理の特例を述べなさい。
解答例

公正な評価単価に代えて本源的価値（自社の株式の評価額－行使価格）の見積りに基づいて処理できる。原資産である自社の株式の評価額が行使価格を上回る状態で付与された場合を除き価値はゼロとなり事実上費用が計上されないこととなる。その手当てとして付与日以後の本源的価値を注記によって開示する。一般投資家の存在する公開企業は、公開直後の企業であってもこの方法によることはできない。

C-2　権利確定条件が付されていない場合
問権利確定条件が付されていないストック・オプションの費用計上時期を述べなさい。
解答例

付与日以前のサービス提供に対する対価とみて、付与日に一時に費用計上する。株価条件等が付されているなど権利確定日を合理的に予測することが困難なため予測を行わないときも、権利確定条件がないものとみなして同じく付与日に一時に費用を計上する。
