A-1　費用認識の根拠と各期の費用計上額令3
問自社の株式またはストック・オプションを報酬として付与した場合、付与日から権利確定日までの各会計期間の費用計上額はどのように算定するか。費用として認識する理由と併せて説明しなさい。
解答例

結論　各期の費用＝公正な評価額×経過期間÷対象勤務期間－前期までの計上額。

  1. 理由：引換えに取得したサービスの消費に応じて費用化（取得に応じて費用）。相手勘定は新株予約権。
  2. 価値は直接測れないため、等価交換されたオプションの公正な評価額で測定。
  3. 公正な評価額＝公正な評価単価×数（株式数）。単価は付与日で固定・見直さない（条件変更を除く）。
  4. 数＝付与数－権利不確定による失効見積数。権利確定まで見直す。「単価は固定・数は見積り」。
  5. 対象勤務期間で按分。付与日から権利確定日まで＝追加的サービスが提供される期間。
入れる語取得に応じて費用／サービスの消費／公正な評価単価×数／付与日で固定・見直さない／失効見積数／対象勤務期間で按分。
A-2　失効見積数の見直しと権利確定日の処理令3
問(1) 付与日から権利確定日の直前までの間に権利不確定による失効の見積数に重要な変動が生じた場合、(2) 権利確定日における会計処理を、それぞれ説明しなさい。
解答例

(1) 見直し時

  1. 達成見込みに重要な変動があれば数を見直す。見積りの変更・遡及なし。
  2. 見直し後の数による評価額で、その期までに計上すべき額との差額を見直した期の損益に一括計上。単価は見直さない。

(2) 権利確定日

  1. 数を実際の権利確定数に一致させる。
  2. 修正後の評価額との差額を権利確定日の属する期の損益とし、費用累計＝確定数ベースの評価額となる。
入れる語重要な変動／見積りの変更・遡及なし／差額を見直した期の損益／権利確定数に一致／累計＝確定数ベースの評価額。
A-3　取締役への株式無償交付（事前交付型・事後交付型）令3
問取締役の報酬等として株式を無償交付する取引について、事前交付型と事後交付型それぞれの対価の会計処理を説明しなさい。また、権利確定条件が達成されず企業が譲渡制限付株式を無償取得した場合の処理を述べなさい。
解答例

結論　サービスの取得に応じて費用計上する点は共通。貸方処理が異なる。

  1. 事前交付型：譲渡制限付株式を発行済み（株式交付済み）のため新株予約権・株式引受権は不要。
  2. 新株発行の場合は資本金または資本準備金へ、自己株式処分の場合はその他資本剰余金へ。過年度費用の戻入れはその他資本剰余金から減額。
  3. 事後交付型：発行まで費用対応額を純資産の株式引受権に計上し、割当日に振替（資本金等。自己株式処分なら処分差額）。
  4. 無償取得：新株発行の場合、自己株式の数のみの増加とし簿価は増やさない（対価を支払っていないため）。戻入れはその他資本剰余金から減額。
  5. 自己株式処分の場合、無償取得部分の簿価を自己株式に戻し、同額のその他資本剰余金を増額。
入れる語株式交付済み／資本金または資本準備金／戻入れはその他資本剰余金／株式引受権／割当日に振替／自己株式の数のみの増加。
A-4　従業員持株会型ESOPと総額法令6・令7
問従業員持株会に信託を通じて自社の株式を交付する取引において、企業が期末に適用する会計処理の名称と内容、およびその適用要件を説明しなさい。
解答例

結論　総額法を適用する。

  1. 総額法＝信託の資産・負債を企業の資産・負債としてB/Sに、信託の損益を企業の損益としてP/Lに計上。
  2. 要件：企業が信託の変更をする権限を有し、かつ信託財産の経済的効果が帰属しないことが明らかとは認められない。
  3. 該当すれば信託が子会社等か判定不要で期末に総額法。連結もそのまま。
  4. 趣旨：変更権限と債務保証による補填がある以上、信託を企業から切り離せない。
  5. ただし信託の自社株は信託における帳簿価額で自己株式計上し、企業保有分と通算せず、配当等も相殺しない。
入れる語総額法／信託の損益を企業の損益として／信託の変更をする権限／経済的効果が帰属しないことが明らかとは認められない／子会社等か判定不要／信託における帳簿価額。
A-5　IFRS第2号との対比
問ストック・オプション等の会計処理について、日本基準とIFRS第2号の主な相違点を述べなさい。
解答例
  1. 範囲：IFRS2は現金決済型等も含む包括基準。日本は持分決済型のみ。
  2. 付与日の定義が異なり、測定基準日・費用額が変わる。
  3. 株価条件：IFRSは公正価値の見積りに織り込む（株価条件の織込み）ため、付与日の一時費用計上は不要。
  4. 条件変更：日本は変更日単価と付与日単価を比較し下回れば追加費用なし。IFRSは直前直後の比較で増加分を必ず反映。
  5. 失効（最大の差異）：日本は新株予約権戻入益で利益計上。IFRSは資本の事後修正を禁じ戻入れ禁止（資本内振替のみ）。
入れる語持分決済型のみ／付与日の定義／株価条件の織込み／直前直後の比較／戻入れ禁止。

重要度B聞かれたら説明できるレベル（骨子が書ければよい5論点）

B-1　条件変更（行使価格の引下げ）
問株価下落によりインセンティブ効果が失われたため、付与済みストック・オプションの行使価格を引き下げた。この条件変更の会計処理を理由とともに説明しなさい。
解答例

結論　変更日単価＞付与日単価なら増加分を追加費用、下回れば付与日単価で継続。

  1. 行使価格引下げで本源的価値が増え、直前直後で比べれば単価は必ず上がる。
  2. 変更日単価で測り直すと、付与日単価を下回る場合に費用総額が減り妥当でない。よって下回っても減額しない（総額は減らさない）。
  3. 上回る場合のみ増加分を残存期間で追加費用計上。
入れる語変更日単価＞付与日単価／増加分を残存期間で追加／下回っても減額しない／総額は減らさない／付与日単価で継続。
B-2　権利確定日後の処理と有償ストック・オプション令5
問(1) 権利確定日後に権利不行使による失効が生じた場合の処理、(2) 権利確定条件付き有償新株予約権の会計処理を説明しなさい。
解答例

(1)　失効分の新株予約権を新株予約権戻入益として特別利益に、失効が確定した期に計上。権利行使時は通常の新株予約権と同じ。

(2)　払込みがあっても勤務・業績条件付きならサービスの対価でストック・オプションに該当し費用認識（対価でないと立証できる場合を除く）。払込金額も新株予約権に計上し、費用＝公正な評価額－払込金額。権利不確定失効時は払込分も利益へ振替。

入れる語新株予約権戻入益／特別利益／確定した期／サービスの対価／公正な評価額－払込金額。
B-3　株式給付型ESOP令6
問株式給付型ESOPの仕組みと、企業における費用および引当金の算定方法を説明しなさい。
解答例
  1. 企業が金銭を信託し、信託が自社株を取得。通算すると「会社が従業員に株式を報酬として渡した」だけが残り、企業側で費用計上。
  2. 費用・引当金＝ポイント相当株式数×信託の取得時株価。複数回取得なら平均法・先入先出法。
  3. 株式交付時は同じ単価で引当金の取崩し。
  4. 退職時に株式を交付するイメージで、その他は持株会型と同じく総額法。
入れる語企業側で費用計上／ポイント相当株式数×信託の取得時株価／平均法・先入先出法／引当金の取崩し／総額法。
B-4　基準の適用範囲（親会社が子会社の従業員等に付与）
問親会社が子会社の従業員等に対して親会社株式を対象とするストック・オプションを付与した場合の会計処理を、ストック・オプション等会計基準の適用範囲に触れて説明しなさい。
解答例

結論　ストック・オプションの定義外だが自社株式オプションを用いる取引として親会社の個別で費用計上。

  1. 範囲は①ストック・オプション②対価に自社株式オプションを用いる取引③自社株式を用いる取引。②は①と整合的に処理。
  2. 子会社で享受したサービスの対価のため親会社の個別財務諸表で費用。
  3. 子会社の報酬体系に組み込まれていれば子会社は費用＋特別利益（負担を免れた利益）。
入れる語自社株式オプションを用いる取引／①と整合的に処理／親会社の個別で費用／子会社は費用＋特別利益／負担を免れた利益。
B-5　従業員持株会型ESOPの仕組み
問従業員持株会型ESOPの取引の流れを説明し、これが従業員の福利厚生として機能する理由を述べなさい。
解答例
  1. 企業が金銭を信託。信託は企業の債務保証付き借入で自社株を一括取得し、持株会へ時価で売却（毎月一定額）。
  2. 株価上昇時は売却株数が減り、借入返済後も株式が残る。余剰は従業員へ分配。
  3. 株価下落時の不足は企業が負担（債務保証で補填）し従業員は損失を負わない。だから福利厚生。
  4. 持株会を備える日本企業が多く持株会型が主流。株式給付型が米国ESOPに近い。
入れる語債務保証付き借入／持株会へ時価で売却／余剰は従業員へ／不足は企業が負担／福利厚生。

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　未公開企業における本源的価値
問未公開企業がストック・オプションを付与した場合の会計処理の特例を述べなさい。
解答例

公正な評価単価に代え本源的価値（株式評価額－行使価格）で処理可。行使価格は通常評価額以上で価値ゼロ→事実上費用計上なし。手当てとして本源的価値を注記。公開直後は不可。

C-2　権利確定条件が付されていない場合
問権利確定条件が付されていないストック・オプションの費用計上時期を述べなさい。
解答例

付与日以前のサービス提供に対する対価とみて付与日に一時に費用計上。株価条件のみで権利確定日を予測しない場合も同じ。
