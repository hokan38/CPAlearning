重要度A白紙に書けるレベルまで（記述で実際に問われた論点＋債務算定の骨格。計算を仕上げてから読む）

A-1　遅延認識の趣旨令4
問過去勤務費用および数理計算上の差異について、発生時に一時の費用とせず一定の期間にわたって規則的に費用処理する（遅延認識）考え方の根拠を、それぞれ説明しなさい。
解答例

結論　いずれも平均残存勤務期間以内の一定の年数で規則的に費用処理する。

  1. 過去勤務費用：給付水準の改訂等は勤労意欲の向上を期待して行われ、効果は将来にわたって発現。
  2. よって一時の費用とせず、効果の及ぶ期間に配分するのが費用と効果の対応上合理的。
  3. 数理計算上の差異：計算基礎を用いた長期的な見積計算で、見積数値の修正の影響も含む。
  4. よって直ちに全額費用処理するのは合理的でなく、差異は長期的に相殺される可能性もある。
入れる語勤労意欲の向上／効果は将来にわたって発現／費用と効果の対応／長期的な見積計算／見積数値の修正／長期的に相殺／平均残存勤務期間以内。
A-2　費用処理年数の短縮＝会計上の見積りの変更令2
問P社グループは数理計算上の差異を平均残存勤務期間以内の一定の年数（従来15年）で費用処理してきたが、当連結会計年度に中途採用活動を積極的に行った結果、従業員の平均年齢が上昇し平均残存勤務期間が14年に減少したため、費用処理年数を14年に変更した。この変更は会計方針の変更と会計上の見積りの変更のいずれに該当するか理由とともに述べ、影響額の算定方法と注記の記載例を示しなさい。
解答例

結論　会計上の見積りの変更に該当し、遡及しない。

  1. 費用処理年数は発生年度の平均残存勤務期間以内の一定年数が必須。
  2. 期間が14年に減少し、従来の15年がこれを超えることとなったため短縮せざるを得ない。
  3. 決定方法という方針自体の変更でなく、平均残存勤務期間という会計事実の変更に伴うもの。
  4. 影響額：未認識差異の期首残高÷（14年－既経過年数）を費用処理、当期発生額は14年で按分。15年との差額が費用増加額。
  5. 注記例「数理計算上の差異の費用処理年数を、平均残存勤務期間が14年に減少したため当連結会計年度より15年から14年に変更。従来の方法に比べ営業利益、経常利益及び税金等調整前当期純利益は各◯◯百万円減少」。
入れる語平均残存勤務期間以内／超えることとなった／会計事実の変更／会計上の見積りの変更／遡及しない／既経過年数／◯◯百万円減少。
A-3　連結財務諸表における未認識項目の取扱い平27
問数理計算上の差異および過去勤務費用の未認識部分について、連結財務諸表における会計処理を個別財務諸表と対比して説明し、費用処理された部分について組替調整を必ず行う理由を述べなさい。
解答例

結論　連結B/Sは即時認識、P/Lは遅延認識のまま。ズレはOCIで埋め組替調整。

  1. 個別：引当金＝債務－年金資産±未認識差異で、積立状況とズレる。
  2. 連結B/S：積立状況を示す額を退職給付に係る負債（資産）として計上。
  3. 未費用処理分は税効果調整後、その他の包括利益を通じて純資産の退職給付に係る調整累計額に計上。
  4. 連結P/L：個別と同じ按分額を退職給付費用とし、費用処理分をOCIから組替調整（リサイクリング）。
  5. 組替調整必須の理由：株主資本と純利益の連繋（クリーン・サープラス）の維持。P/Lを通さず利益剰余金へ振り替えるIFRS型は不可。
入れる語積立状況を示す額／即時認識／退職給付に係る負債／その他の包括利益を通じて／退職給付に係る調整累計額／P/Lは遅延認識のまま／組替調整／クリーン・サープラス。
A-4　IFRS（IAS第19号）との主な相違点平27・令7
問確定給付制度の会計処理について、日本基準とIFRS（IAS第19号）の主な相違点を4点挙げて説明しなさい。
解答例
  1. 期間帰属　日本：給付算定式基準と期間定額基準の選択。IFRS：給付算定式基準のみ。
  2. 割引率　日本：安全性の高い債券（国債・政府機関債・優良社債）の利回り。IFRS：優良社債の市場利回り（厚みある市場がなければ国債）。
  3. 利息純額　IFRSは確定給付負債（資産）の純額×割引率で利息純額を算定し期待運用収益なし。日本は利息費用と期待運用収益を別計算。
  4. 差異の処理　数理差異のOCI認識は共通だが、IFRSは純損益へのリサイクリング禁止、日本は組替調整必須。IFRSは過去勤務費用は即時費用、日本は遅延認識。
入れる語給付算定式基準のみ／優良社債／利息純額／期待運用収益なし／リサイクリング禁止／過去勤務費用は即時費用。
A-5　制度改訂時の再測定（重要性基準との対比）令7
問退職給付制度の改訂が行われた場合における制度資産および負債の評価（計算基礎の見直し）について、IFRSと日本基準の取扱いの違いを述べなさい。
解答例

結論　IFRSは再測定を義務付け、日本基準は重要性基準で見直さないことができる。

  1. IFRS：制度改訂・縮小時、過去勤務費用・清算損益の算定前に最新の数理計算上の仮定で制度資産と債務を再測定。
  2. 基礎率を見直さない例外規定なし。資産負債アプローチ的。
  3. 日本：計算基礎に重要な変動がなければ見直さなくてよい（重要性基準）。割引率は債務が10％以上変動する場合のみ再計算。
  4. よって改訂時に最新基礎率で再測定することは求められない。回廊アプローチは不採用、IFRSに重要性基準なし。
入れる語最新の数理計算上の仮定／再測定／例外規定なし／重要性基準／10％以上。
A-6　退職給付債務の計算手順と割引率
問退職給付債務はどのような手順で算定されるか。割引率の決定方法と併せて説明しなさい。
解答例

結論　①予測→配分→割引の3プロセス。割引率は安全性の高い債券の利回り。

  1. 予測：退職給付見込額を予測。日本基準はPBO・昇給考慮で、受給権未取得者も含む。
  2. 配分：期末までの発生額を給付算定式基準または期間定額基準で配分。後期に著しく高い算定式は均等発生とみなして補正。
  3. 割引：国債・政府機関債・優良社債の利回りを基礎。確実に支払われる債務のため無リスク近似。単一の加重平均率でも期間別の複数率でも可。
  4. 性格は賃金の後払い。労働提供に伴い発生するので発生主義で費用認識し、一時金・年金を統一処理。
入れる語予測→配分→割引／PBO・昇給考慮／給付算定式基準／期間定額基準／安全性の高い債券の利回り／賃金の後払い。
A-7　退職給付制度の終了（確定拠出年金制度への移行）平27・平29
問P社は確定給付企業年金制度から確定拠出年金制度へ移行し資産を移換した。消滅する退職給付債務1,500百万円、支払等の額1,440百万円、未認識数理計算上の差異225百万円、未認識過去勤務費用75百万円である。連結財務諸表上の処理を日本基準とIFRSとで対比して説明しなさい。
解答例

結論　日本基準は純額240の損失を特別損益に、IFRSは差額60の利得のみ認識。

  1. 確定拠出への資産移換は退職給付制度の終了。消滅債務と支払額の差額（1,500－1,440＝60）が利益。
  2. 加えて未認識数理差異225＋未認識過去勤務費用75＝未認識項目300を損益認識。純額240の損失を特別損益に純額表示。
  3. 連結では300は既にOCI累計額に計上済みのため、認識はリサイクリング（組替調整）として行う。
  4. IFRSは差額60のみ。数理差異はOCIから純損益への振替禁止、過去勤務費用は発生時に純損益処理済みで残高なし。
入れる語退職給付制度の終了／消滅債務と支払額の差額／未認識項目300を損益認識／特別損益に純額／リサイクリング／IFRSは差額60のみ。

B-1　個別貸借対照表の計上額と年金資産
問個別貸借対照表における退職給付引当金の計上額の算定式を示し、年金資産を退職給付債務から控除して表示する理由を述べなさい。
解答例

結論　退職給付引当金＝債務－年金資産±未認識差異。

  1. 積立超過なら前払年金費用（固定資産）。
  2. 年金資産＝退職給付以外に使用不可・事業主から法的分離等の4要件を満たす資産。時価評価。
  3. 使途が退職給付に限定されるため両建てせず債務から控除する純額表示。
  4. 個別は未認識分だけ積立状況とズレる。連結との対比の起点。
入れる語債務－年金資産±未認識差異／前払年金費用／時価評価／退職給付以外に使用不可／純額表示。
B-2　退職給付費用の構成要素
問退職給付費用を構成する要素を挙げ、期待運用収益を期首の年金資産に基づいて計算する理由を述べなさい。
解答例
  1. 勤務費用＝当期の労働の対価として発生した債務の増加。
  2. 利息費用＝期首債務×割引率（時の経過による増加）。
  3. 期待運用収益＝期首年金資産×長期期待運用収益率を控除。実績は期末まで不明のため期首の見込みで計算し、実績とのズレは数理差異へ。
  4. 数理差異・過去勤務費用の当期処理額を加減し、当期純利益の構成項目として計上。
  5. IFRSは純額×割引率の利息純額で、期待運用収益を別建てしない。
入れる語勤務費用／利息費用＝期首債務×割引率／期待運用収益＝期首年金資産×長期期待運用収益率／実績とのズレは数理差異／利息純額。
B-3　数理計算上の差異と過去勤務費用の相違点
問数理計算上の差異と過去勤務費用の意義を示し、費用処理に関する取扱いの相違点を説明しなさい。
解答例
  1. 数理計算上の差異＝年金資産の期待と実績の差異、債務計算の見積と実績の差異・見積数値の変更による差異。
  2. 過去勤務費用＝給付水準の改訂等に起因する債務の増減。ベースアップは除く。
  3. 数理差異のみ翌期からの費用処理が容認（実務の便宜）。過去勤務費用は発生年度から。
  4. いずれも平均残存勤務期間以内で按分。発生原因・頻度が異なり年数は別個に設定可、連結会社間の統一も不要。
入れる語期待と実績の差異／水準の改訂等／ベースアップは除く／翌期からの費用処理／年数は別個に設定可。
B-4　表示科目の対比
問退職給付に関する個別財務諸表、連結財務諸表および連結包括利益計算書上の表示科目をそれぞれ述べなさい。
解答例
  1. 個別B/S：退職給付引当金（固定負債）／前払年金費用（固定資産）。
  2. 連結B/S：退職給付に係る負債（固定負債）／退職給付に係る資産。純資産に退職給付に係る調整累計額（税効果後）。
  3. 連結包括利益計算書：OCIとして退職給付に係る調整額（当期発生額＋組替調整額）。
  4. B/Sは「累計額」、OCIは「調整額」と語尾で区別。
入れる語退職給付引当金／前払年金費用／退職給付に係る負債／退職給付に係る調整累計額／退職給付に係る調整額。
B-5　退職給付信託
問事業主が保有する有価証券を退職給付信託に拠出した場合の会計処理と、その留意点を述べなさい。
解答例

結論　保有資産を時価で拠出したのと同様に処理する。

  1. 信託設定時に簿価と時価の差額の評価損益が実現し、拠出した資産は年金資産となる。その結果、年金資産が増えて退職給付引当金が減る。
  2. 母体企業の積立不足解消の救済策として広まった制度であるため、信託設定によって資産超過に逆転する場合はその部分を年金資産と認めない。
入れる語時価で拠出／評価損益の実現／年金資産の増加・引当金の減少／積立超過部分は年金資産としない。

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　確定給付制度と確定拠出制度
問確定給付制度と確定拠出制度の区分基準を示し、確定拠出制度の会計処理を述べなさい。
解答例

区分基準は運用リスクをどちらが負うか。確定拠出制度は掛金拠出以外に義務がなく、要拠出額をもって費用処理し、未拠出分は未払金（引当金ではない）。費用額の注記が必要。

C-2　簡便法と複数事業主制度
問(1) 小規模企業における簡便法の適用と変更の可否、(2) 複数事業主制度において自社の持分が把握できない場合の処理を述べなさい。
解答例

(1)　300人未満等の小規模企業は簡便法可。簡便法→原則法は自由、原則法→簡便法は原則不可。

(2)　自社持分を計算できなければ確定拠出制度に準じた処理し、制度全体の積立状況を注記。

C-3　リスク分担型企業年金
問リスク分担型企業年金はどのように分類され、どのように会計処理されるか述べなさい。
解答例

運用リスクを企業と従業員が分担する制度。規約の掛金以外に実質的な拠出義務がなければ確定拠出制度に分類し掛金を費用処理。確定給付からの移行は退職給付制度の終了。

C-4　個別と連結で取扱いが異なる旨の注記平26
問個別財務諸表において、未認識数理計算上の差異および未認識過去勤務費用の取扱いが連結財務諸表と異なる旨を注記する理由を述べなさい。
解答例

平成24年改正は連結B/Sで未認識項目を即時認識する一方、個別B/Sは当面の間遅延認識を継続。両者の取扱いの相違を利用者に明らかにするため注記を求める。
