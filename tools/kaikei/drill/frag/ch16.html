重要度A白紙に書けるレベルまで（記述で実際に問われた4論点。IFRSの認識要件と日本基準の4要件が軸）

A-1　IFRSにおける引当金の認識要件平30
問IFRS（IAS第37号）における引当金の認識要件を述べなさい。
解答例

結論　次の3つの要件をすべて満たす場合に引当金を認識し、満たされない場合には認識してはならない。

  1. (a) 企業が過去の事象の結果として現在の義務（法的または推定的義務）を有していること。
  2. (b) 当該義務を決済するために経済的便益を有する資源の流出が必要となる可能性が高いこと。
  3. (c) 当該義務の金額について信頼性のある見積りができること。

(b)(c)は日本基準（企業会計原則注解18）の第3・第4要件に対応し、第2要件「当期以前の事象に起因」は「過去の事象の結果」に織り込まれる。最大の違いは「現在の義務か」から入る点にあり、資産負債アプローチと収益費用アプローチの対比がここに現れる。

入れる語過去の事象の結果／現在の義務／法的または推定的／資源の流出の可能性が高い／信頼性のある見積り／満たさなければ認識してはならない。
A-2　日本基準との差異（リストラクチャリング引当金を例に）平30
問引当金の認識要件に関する日本基準とIFRSの最も大きな差異を、リストラクチャリング引当金を例にとって説明しなさい。
解答例

結論　IFRSは「過去の事象の結果としての現在の義務」の存在という負債性を出発点とする資産負債アプローチをとり、日本基準（注解18）は「将来の特定の費用・損失で当期以前の事象に起因するもの」という費用の期間帰属を出発点とする収益費用アプローチをとる点が最大の差異である。

  1. 日本基準には引当金の包括的な会計基準がなく根拠は企業会計原則注解18のみである。IFRSはIAS第37号が引当金・偶発負債・偶発資産を一括して規定する。
  2. IFRSの現在の義務は法的義務に限らず推定的義務を含む。リストラクチャリングは、①対象事業・事業所・従業員・負担する支出・実施時期を明示した詳細な公式の計画を有し、②計画の実施の開始または主要な特徴の公表により、実行するであろうという妥当な期待を影響を受ける人々に惹起している場合に推定的義務が生じ、リストラに必然的に伴い継続的活動と関連のない直接支出について引当金を認識する。
  3. 日本基準にはリストラクチャリング引当金の規定がなく、注解18の4要件により判断されるにとどまる。
  4. 逆に日本基準では修繕引当金のような債務性のない引当金も計上されるが、IFRSでは現在の義務がない以上これを認識できない。

私見を求められたら、負債の定義に立ち返って認識範囲を画するIFRSの考え方が整合的である、と結ぶ。

入れる語資産負債アプローチ／収益費用アプローチ／現在の義務／推定的義務／詳細な公式の計画／妥当な期待の惹起／債務性のない引当金は不可。
A-3　引当金の計上要件のあてはめ（火災事例）令7
問3月決算のX社の工場で20X1年3月1日に火災が発生した。甲生産ライン設備は損壊し廃棄する以外に選択肢がなく、生産再開のためその撤去と現場整理が必要であるが、撤去の完了は翌期となる。乙生産ライン設備については、20X1年3月25日の取締役会で、火災前より生産能力が向上し経済的使用可能予測期間も長くなる改良を行う方針が決議された。丙生産ライン設備には火災による被害はないが、火災前から検討していた他県工場への移設（20X1年12月以降開始予定）を火災を契機に前倒しすることとした。いずれの支出も発生の可能性が高く金額は合理的に見積もることができる。20X1年3月期において甲・乙・丙それぞれについて引当金を計上すべきか、企業会計原則注解18の要件に照らして述べなさい。
解答例

結論　甲は計上する。乙・丙は計上しない。

要件　引当金は①将来の特定の費用または損失であること、②その発生が当期以前の事象に起因すること、③発生の可能性が高いこと、④金額を合理的に見積もることができること、の4要件を満たす場合に必ず計上しなければならない。本問は①③④が前提条件で満たされており、勝負は②火災との因果関係のみである。

甲　当期の火災により損壊し廃棄以外に選択肢がなく、生産再開のため撤去が必要となったのだから、撤去支出は当期以前の事象である火災に起因し②を満たす。よって計上する。撤去の完了が翌期になることは要件の充足に影響しない。

乙　改良は取締役会決議に基づく企業の将来の意思決定による支出で、生産能力の向上・使用可能期間の延長を伴い原状回復を意図したものではない。火災と直接の因果関係を有する損失とはいえず②を満たさないので計上せず、支出時に資本的支出として取得原価に加算する。

丙　火災による被害がなく、移設は火災前から検討され時期を前倒ししたにすぎない。将来の生産体制に関する企業自身の意思決定に基づく将来の支出であり②を満たさないので計上しない。

入れる語4要件／必ず計上／当期以前の事象に起因／因果関係／廃棄以外に選択肢がない／将来の意思決定に基づく支出／資本的支出。
A-4　法令上の定期修繕とIFRSの「現在の義務」令7
問X社は法令により3年ごとの定期修繕が義務付けられた有形固定資産を保有している。IFRS（IAS第37号）の認識要件に照らし、将来の定期修繕支出について引当金を認識すべきか、理由を付して述べなさい。
解答例

結論　認識しない。

  1. IAS第37号は(a)現在の義務、(b)資源流出の可能性が高い、(c)信頼性のある見積り、のすべてを満たす場合に引当金を認識する。本件は(b)(c)を満たしうるとしても、(a)の現在の義務が存在しない。
  2. 現在の義務とは、その決済を回避する現実的な選択肢を企業が有しない義務をいう。法令で修繕が義務付けられていても、当該資産を売却または除却すれば修繕は不要となり、企業は将来の支出を回避できる。
  3. 修繕支出は将来の設備の稼働という将来の企業の行動に依存するものであり、報告期間の末日に過去の事象から生じた現在の義務ではない。よって引当金を認識せず、修繕の実施時点で費用処理する。

日本基準では修繕引当金として計上され得るものであり、「義務とは回避できないもの」という一点が両者の分岐である。

入れる語現在の義務／回避する現実的な選択肢／売却・除却すれば不要／将来の企業の行動に依存／修繕実施時に費用処理。

重要度B聞かれたら説明できるレベル（骨子が書ければよい5論点）

B-1　保証類似行為と債務保証の注記平28
問(1) P社の連結財務諸表において債務保証に関する記載が現れる箇所を挙げなさい。(2) 保証類似行為とは何か説明しなさい。
解答例

(1) 記載箇所　前提として、連結会社相互間の債務保証は連結手続上相殺消去され注記の対象とならず、対象は連結会社以外の者（非連結子会社・持分法適用関連会社・第三者等）に対する保証である。

  1. 連結貸借対照表に関する注記としての偶発債務（債務保証）の注記。保証類似行為も原則として通常の債務保証に含めて記載する。
  2. 関連当事者との取引に関する注記（関連会社等に対する債務保証の取引金額）。
  3. 損失発生の可能性が高い場合等の追加情報の注記（債務保証損失引当金の計上、主たる債務者の財政状態等）。

(2) 保証類似行為　法形式上は債務保証契約ではないが、実質的に債務保証と同様の効果を有する行為をいい、保証予約と経営指導念書等の差入れが該当する。保証予約には、一定事由を停止条件に自動的に保証契約が発効する停止条件付保証契約、債権者の予約完結権行使で成立する予約完結権行使型、請求を受けたら保証契約を締結する義務を負う締結義務型がある。経営指導念書等は、子会社等の借入に際し親会社等が監督責任を認め経営指導を行うことを約して金融機関に差し入れる文書である。いずれも実質は最後に尻ぬぐいする約束で保証と変わらないため、対象債務の額につき原則として通常の債務保証に含めて注記する。

入れる語連結会社相互間は消去／偶発債務の注記／関連当事者／追加情報／保証予約／経営指導念書／通常の債務保証に含めて注記。
B-2　債務保証損失引当金の計上と注記の関係
問他社の借入金について債務保証を行っている場合、損失の発生可能性と金額の見積可能性に応じて、引当金の計上と注記はどのように使い分けられるか説明しなさい。
解答例

結論　引当金の4要件のうち第3要件（発生の可能性が高い）と第4要件（合理的に見積可能）の充足で分岐し、1つでも欠ければ引当金は計上できず注記にとどまる。

  1. 債務保証をしている時点で、過去の取引に基づき将来損失が生じるかもしれないという第1・第2要件は満たされている。判断すべきは第3・第4要件だけである。
  2. 発生の可能性が高く、金額を合理的に見積もれる → 債務保証損失引当金を計上する。
  3. 発生の可能性は高いが金額を見積もれない → 債務保証の注記に加え追加情報として注記する。単なる金額の注記では足りないためであるが、実際は極めて稀で、主債務者が経営破綻状態なら必要額を引当計上する。
  4. 損失がある程度予想される → 保証金額の注記に加え、その旨を追加情報として注記する。
  5. 発生の可能性が低い → 保証金額の注記のみ。
入れる語第3・第4要件で分岐／債務保証損失引当金／追加情報／1つでも欠ければ注記どまり。
B-3　債務保証損失引当金の段階と計上額
問当社が金融機関借入について債務保証をしているA社の財政状態が悪化した。債務保証の開始から保証債務の履行後までの各段階における会計処理と、債務保証損失引当金の計上額の算定方法を説明しなさい。
解答例

結論　注記のみ → 債務保証損失引当金 → （履行後）貸倒引当金と段階的に移行し、計上額は保証総額から回収見積額を控除した額である。

  1. A社が通常どおり弁済している段階では、偶発債務として債務保証の注記のみを行う。
  2. 財政悪化により代位弁済を求められ、かつ取得する求償債権が回収不能となる可能性が高まった段階で、損失見込額を債務保証損失引当金として計上する。
  3. 計上額は、保証債務の総額から主債務者の返済可能額・担保等による回収見積額を控除した額である。
  4. 実際に保証債務を履行し求償債権を取得した後は、求償債権に対する貸倒引当金へ移行する。銀行に返済できなかった主債務者が保証人に支払えるはずもなく、求償債権は通常回収できないためである。
入れる語注記のみ／代位弁済／求償債権の回収不能／回収見積額を控除／履行後は貸倒引当金。
B-4　賞与・役員賞与に係る負債の表示
問従業員賞与および役員賞与について、引当金として表示する場合と未払費用・未払金等として表示する場合の区別を説明しなさい。
解答例

結論　いずれも発生した会計期間の費用であり、支給額が確定しているかという軸で科目が分かれる。

  1. 従業員賞与　賞与は既に発生した費用だが、期中退職者に支給されないなど支給額が未確定のため賞与引当金とする。「金額が分からないから引当金」にすぎない。支給額が確定しており、支給対象期間に対応して算定される（年俸制等）なら未払費用、成功報酬的賞与のように期間以外の基準で算定されるなら未払金とする。
  2. 役員賞与　株主総会決議を前提とし支給が未確定なら原則として引当金に計上する。決議事項としない場合や、子会社役員賞与のように決議前でも実質的に確定債務である場合は未払役員報酬等でよい。
  3. 役員退職慰労引当金　内規に基づき支給見込額が合理的に算出でき、支給実績等の状況が将来も存続する場合は繰入が強制される。
入れる語確定しているか／賞与引当金／未払費用（期間対応）／未払金／役員賞与＝原則引当金／未払役員報酬。
B-5　偶発債務の意義とIFRSの偶発負債
問偶発債務とは何か。日本基準における注記の取扱いと、IFRSにおける偶発負債の取扱いとを対比して説明しなさい。
解答例
  1. 偶発事象とは、不確実な状況が貸借対照表日現在既に存在し、将来事象の発生・不発生により解消されるものをいう。うち偶発利得は未実現利益排除のため計上せず、偶発損失のうち債務性のあるもの（現実に発生していない債務）が偶発債務として内容及び金額を注記される。災害損失等は債務性がなく偶発債務ではない。
  2. 注記対象は通常の債務保証に加え保証予約・経営指導念書等の保証類似行為を含む。4要件を満たせば引当金となり、欠ければ注記どまりである。
  3. IFRSの偶発負債は、①現在の義務かどうか不確実なもの、②現在の義務だが流出可能性が高くない・信頼性ある測定ができないため認識されないもの、の2類型である。偶発負債は認識してはならず内容等を開示するという扱いで、計上せず注記する日本基準と実質的に大差ない。
入れる語貸借対照表日現在存在する不確実な状況／現実に発生していない債務／内容及び金額を注記／2類型／認識禁止＋開示。

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　引当金の測定に関する差異
問引当金の測定について、IFRSと日本基準の規定の違いを述べなさい。
解答例

IFRSは最善の見積り・リスクの考慮に加え、重要性があれば必要となる支出の現在価値への割引まで規定する。日本基準は包括的な基準がないため、退職給付等の個別基準を除き測定規定がない。将来の営業損失の引当禁止や不利な契約（足が出る契約。工事損失引当金はその一例）の包括規定の有無も差異であるが、日本基準でも将来の営業損失に引当金は計上できず、規定の有無の差にすぎない。

C-2　投資損失引当金
問投資損失引当金はどのような場合に計上できるか。取崩しの要件と併せて述べなさい。
解答例

通常は市場価格のない子会社株式・関連会社株式について、減損するまでもないが実質価額がある程度低下したとき、または回復可能性ありと判断し減損しなかったときに、健全性の観点から計上できる評価性引当金（資産のマイナス。貸倒引当金とこれの2つだけ）である。減損に移行したら取り崩し、実質価額の回復でも取り崩すが、一時的な改善では取り崩してはならない。

C-3　役員退職慰労金制度の廃止と準備金の表示
問(1) 役員退職慰労金制度を廃止した場合の役員退職慰労引当金の取扱い、(2) 特別法上の準備金および租税特別措置法上の準備金の表示を述べなさい。
解答例

(1)　株主総会承認済みで支払を留保しているものは、退任時に支払う条件付債務として長期未払金に振り替える。承認未了なら法律上の債務ではないため引当金のまま表示する。

(2)　準備金が引当金の4要件を満たすなら負債の部に引当金として表示する（一年基準）。満たさなければ、特別法上の準備金は固定負債の次に別区分を設けて表示し、租税特別措置法上の準備金は積立金方式により純資産の任意積立金とする（課税繰延という税務上の恩恵が目的のため）。
