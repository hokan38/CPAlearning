A-1　IFRSにおける引当金の認識要件平30
問IFRS（IAS第37号）における引当金の認識要件を述べなさい。
解答例

結論　3要件すべてを満たす場合に認識し、満たさなければ認識してはならない。

  1. (a) 過去の事象の結果として現在の義務（法的または推定的義務）を有する。
  2. (b) 決済のため経済的便益をもつ資源の流出の可能性が高い。
  3. (c) 義務の金額について信頼性のある見積りができる。
  4. (b)(c)は注解18の第3・第4要件に対応。IFRSは現在の義務かどうかから入る資産負債アプローチの点が最大の違い。
入れる語過去の事象の結果／現在の義務／法的または推定的／資源の流出の可能性が高い／信頼性のある見積り／満たさなければ認識してはならない。
A-2　日本基準との差異（リストラクチャリング引当金を例に）平30
問引当金の認識要件に関する日本基準とIFRSの最も大きな差異を、リストラクチャリング引当金を例にとって説明しなさい。
解答例

結論　IFRSは資産負債アプローチ、日本基準は収益費用アプローチをとる点。

  1. IFRS（IAS37）は現在の義務の存在から、日本基準（注解18）は費用の期間帰属から入る。
  2. 現在の義務は法的義務に限らず推定的義務を含む。
  3. リストラ：詳細な公式の計画があり、実施開始または公表で妥当な期待の惹起があれば推定的義務が生じ引当。
  4. 日本基準にリストラ引当金の規定はなく、4要件で判断するのみ。
  5. 日本基準は修繕引当金など債務性のない引当金も計上するが、IFRSは現在の義務がなく不可。
入れる語資産負債アプローチ／収益費用アプローチ／現在の義務／推定的義務／詳細な公式の計画／妥当な期待の惹起／債務性のない引当金。
A-3　引当金の計上要件のあてはめ（火災事例）令7
問3月決算のX社の工場で20X1年3月1日に火災が発生した。甲生産ライン設備は損壊し廃棄する以外に選択肢がなく、生産再開のためその撤去と現場整理が必要であるが、撤去の完了は翌期となる。乙生産ライン設備については、20X1年3月25日の取締役会で、火災前より生産能力が向上し経済的使用可能予測期間も長くなる改良を行う方針が決議された。丙生産ライン設備には火災による被害はないが、火災前から検討していた他県工場への移設（20X1年12月以降開始予定）を火災を契機に前倒しすることとした。いずれの支出も発生の可能性が高く金額は合理的に見積もることができる。20X1年3月期において甲・乙・丙それぞれについて引当金を計上すべきか、企業会計原則注解18の要件に照らして述べなさい。
解答例

結論　甲は計上する。乙・丙は計上しない。

  1. 要件：①将来の特定の費用・損失②当期以前の事象に起因③発生の可能性が高い④合理的に見積可能、の4要件。
  2. 満たせば必ず計上。①③④は前提で充足、争点は②火災との因果関係のみ。
  3. 甲：火災で損壊し廃棄以外に選択肢がないため撤去が必要。火災に起因し②を満たす→計上。完了が翌期でも影響なし。
  4. 乙：改良は取締役会決議による将来の意思決定に基づく支出で原状回復ではない。②を満たさず、資本的支出として取得原価に加算。
  5. 丙：被害なし。移設は火災前からの検討の前倒しで、企業自身の意思決定による将来支出。②を満たさず計上しない。
入れる語4要件／必ず計上／当期以前の事象に起因／因果関係／廃棄以外に選択肢がない／将来の意思決定に基づく支出／資本的支出。
A-4　法令上の定期修繕とIFRSの「現在の義務」令7
問X社は法令により3年ごとの定期修繕が義務付けられた有形固定資産を保有している。IFRS（IAS第37号）の認識要件に照らし、将来の定期修繕支出について引当金を認識すべきか、理由を付して述べなさい。
解答例

結論　認識しない。

  1. IAS37の要件(a)現在の義務(b)資源流出の可能性が高い(c)信頼性ある見積りのうち、(a)の現在の義務が存在しない。
  2. 現在の義務＝決済を回避する現実的な選択肢を企業が有しない義務。
  3. 法令上の修繕義務でも、資産を売却・除却すれば不要となり支出を回避できる。
  4. 修繕支出は設備の稼働という将来の企業の行動に依存し、過去の事象から生じた現在の義務ではない。修繕実施時に費用処理。
  5. 日本基準では修繕引当金として計上し得る。義務とは回避できないものという一点が分岐。
入れる語現在の義務／回避する現実的な選択肢／売却・除却すれば不要／将来の企業の行動に依存／修繕実施時に費用処理。

重要度B聞かれたら説明できるレベル（骨子が書ければよい5論点）

B-1　保証類似行為と債務保証の注記平28
問(1) P社の連結財務諸表において債務保証に関する記載が現れる箇所を挙げなさい。(2) 保証類似行為とは何か説明しなさい。
解答例

(1) 記載箇所　連結会社相互間は消去され、連結外の者への保証が対象。

  1. 偶発債務の注記（保証類似行為も含める）。
  2. 関連当事者との取引の注記。
  3. 損失の可能性が高い場合等の追加情報。

(2) 保証類似行為　法形式は債務保証でないが実質的に債務保証と同様の効果をもつ行為。保証予約・経営指導念書の差入れが該当し、原則通常の債務保証に含めて注記。

入れる語連結会社相互間は消去／偶発債務の注記／関連当事者／追加情報／保証予約／経営指導念書／通常の債務保証に含めて注記。
B-2　債務保証損失引当金の計上と注記の関係
問他社の借入金について債務保証を行っている場合、損失の発生可能性と金額の見積可能性に応じて、引当金の計上と注記はどのように使い分けられるか説明しなさい。
解答例

結論　第3・第4要件で分岐。1つでも欠ければ注記どまり。

  1. 保証時点で第1・第2要件は充足済み。第3（発生可能性が高い）・第4（合理的見積可）で判断。
  2. 可能性高＋見積可→債務保証損失引当金を計上。
  3. 可能性高＋見積不能→保証注記に加え追加情報を注記（稀。破綻状態なら引当）。
  4. ある程度予想→保証金額の注記＋追加情報。可能性低→保証金額の注記のみ。
入れる語第3・第4要件で分岐／債務保証損失引当金／追加情報／1つでも欠ければ注記どまり／保証金額の注記のみ。
B-3　債務保証損失引当金の段階と計上額
問当社が金融機関借入について債務保証をしているA社の財政状態が悪化した。債務保証の開始から保証債務の履行後までの各段階における会計処理と、債務保証損失引当金の計上額の算定方法を説明しなさい。
解答例

結論　注記のみ→債務保証損失引当金→履行後は貸倒引当金へ移行。

  1. 正常弁済中：偶発債務として注記のみ。
  2. 財政悪化で代位弁済を求められ、求償債権の回収不能の可能性が高まった段階で引当金計上。
  3. 計上額＝保証総額－返済可能額・担保等の回収見積額を控除。
  4. 履行後は求償債権に対する貸倒引当金へ移行。主債務者からの回収は通常不能。
入れる語注記のみ／代位弁済／求償債権の回収不能／回収見積額を控除／貸倒引当金へ移行。
B-4　賞与・役員賞与に係る負債の表示
問従業員賞与および役員賞与について、引当金として表示する場合と未払費用・未払金等として表示する場合の区別を説明しなさい。
解答例

結論　いずれも発生期間の費用。支給額が確定しているかで科目が分かれる。

  1. 従業員賞与：期中退職者等で支給額未確定→賞与引当金。
  2. 確定済みで支給対象期間に対応して算定→未払費用。成功報酬型など期間以外の基準→未払金。
  3. 役員賞与：株主総会決議が前提で未確定→原則引当金。
  4. 決議事項としない場合や子会社役員賞与のように実質的に確定債務→未払役員報酬等。
入れる語確定しているか／賞与引当金／未払費用／未払金／原則引当金／未払役員報酬。
B-5　偶発債務の意義とIFRSの偶発負債
問偶発債務とは何か。日本基準における注記の取扱いと、IFRSにおける偶発負債の取扱いとを対比して説明しなさい。
解答例
  1. 偶発事象＝貸借対照表日現在存在する不確実な状況。将来事象で解消される。
  2. 債務性ある偶発損失（現実に発生していない債務）が偶発債務。内容及び金額を注記。
  3. 保証類似行為も対象。4要件充足なら引当金、欠ければ注記。
  4. IFRSの偶発負債＝①現在の義務か不確実②義務はあるが流出可能性・測定要件を欠く、の2類型。
  5. 認識禁止＋開示で、計上せず注記の日本基準と実質大差なし。
入れる語貸借対照表日現在存在する不確実な状況／現実に発生していない債務／内容及び金額を注記／2類型／認識禁止＋開示。

重要度C結論と理由が1行で言えればよい（直前期に一読）

C-1　引当金の測定に関する差異
問引当金の測定について、IFRSと日本基準の規定の違いを述べなさい。
解答例

IFRSは最善の見積り・リスク考慮に加え現在価値への割引まで規定。日本基準は包括基準がなく測定規定がない。将来の営業損失の引当禁止・不利な契約の規定も日本基準にない。

C-2　投資損失引当金
問投資損失引当金はどのような場合に計上できるか。取崩しの要件と併せて述べなさい。
解答例

市場価格のない子会社・関連会社株式につき、減損するまでもないが実質価額がある程度低下したとき計上できる評価性引当金。減損移行・実質価額の回復で取崩し、一時的改善では不可。

C-3　役員退職慰労金制度の廃止と準備金の表示
問(1) 役員退職慰労金制度を廃止した場合の役員退職慰労引当金の取扱い、(2) 特別法上の準備金および租税特別措置法上の準備金の表示を述べなさい。
解答例

(1)　承認済みの留保分は長期未払金へ振替、未承認は引当金のまま。

(2)　4要件充足なら引当金。否なら特別法上は固定負債の次に別区分、租税特別措置法上は積立金方式。
