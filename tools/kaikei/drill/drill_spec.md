# 会計実務 論述ドリル 章別フラグメント作成仕様

## 目的
会計実務テキスト(修了考査対策編)の各章について、「何を覚えるべきか」を重要度A/B/Cに分け、
**問題文＋解答例文**のセットとして学習できる問題集を作る。全章を1つのPDFに綴じる。
`frag/ch07.html` が完成見本。**構造・クラス名・書き方をそのまま踏襲する。**

## 出力
`tools/kaikei/drill/frag/chNN.html`(NNは2桁)。HTML断片のみ(<html>/<head>/<style>は書かない)。
先頭と末尾は必ず:
```html
<section class="chap" id="chNN">
<h1 class="chap">第N章　章タイトル<small>重要度A x問／B y問／C z問｜出題実績：平26・令3…</small></h1>
<h2>重要度A<span>白紙に書けるレベルまで（記述で実際に問われた論点・講師が「復元できるように」と言った論点）</span></h2>
… .item …
<h2 class="b">重要度B<span>聞かれたら説明できるレベル（骨子が書ければよい）</span></h2>
… .item …
<h2 class="c">重要度C<span>結論と理由が1行で言えればよい（直前期に一読）</span></h2>
… .item …
</section>
```
該当する問がないランクは h2 ごと省略してよい。

## 1問(.item)の形
```html
<div class="item"><div class="th">A-1　論点名<span>平26・令3</span></div>
<div class="q"><b>問</b>問題文。修了考査の記述問題の文体(「〜を説明しなさい」「〜の当否を理由を付して述べなさい」)。事例形式なら前提(会社名・数値・日付)を書く。</div>
<div class="a"><span class="l">解答例</span>
<p><b>結論</b>　一文で結論。</p>
<ol>
<li>理由・処理を1項目1文〜2文で。答案に必ず入れる語だけ <k>…</k> で赤字にする(1項目に0〜2箇所)。</li>
<li>…</li>
</ol>
<p>補足があれば短い段落。</p>
</div>
<div class="pt"><b>入れる語</b>語1／語2／語3（採点キーワード。5〜8個）</div></div>
```
- 解答例は必ず **結論→箇条書きの理由** の構造にする。段落の塊は禁止。
- 事例問題(2ケース比較・判定)は `<p><b>①の場合</b>…</p><p><b>②の場合</b>…</p>` のように見出し段落で区切る。
- Cランクは `<p>` 2〜4文のみ。「入れる語」(.pt)は省略可。
- 出題年度は `<span>` に「平26・令3」形式(修了考査の年度)。不明なら省略。

## ランク分けの根拠(必ずこの順で判断)
1. プランファイル `tools/pdf注釈/plan2_chNN.json`(ch5〜24) / `plan_chN.json`(ch1〜4) の
   - `badge` の text: 「A・最優先で暗記」→A、「B・説明できるレベル」→B、「C・後回しOK」「知識整理・読むだけ」→C、「スキップOK」→出題しない
   - `margin` の「出題: 令和3年度」等 → 実際に問われた論点はランクを1つ上げてよい(最低B)
   - `comment` / `note` = 講師コメント。**解答例の中身はここから作る**(講師が「こう書け」と言った筋を優先)
2. 過去問解答例 `tools/過去問解答例/extra_qa_chNN.json`(JSONL: ref/q/a)。
   過去問そのものは言い換えてAに入れる。解答例(a)はそのまま使ってよいが、上の「結論→箇条書き」構造に組み替える。
3. 講義補足 `tools/講義補足/supp_comments_chNN.json`, `extra_chNN.json`(あれば参考)
4. 第1〜4章は `docs/会計実務_講義ノート/第N章_*.md` に整理済みノートがある(バッジ🅰🅱🅲付き)。最優先の素材。

## 問数の目安
- A: 3〜8問、B: 3〜6問、C: 2〜6問。小さい章(プラン項目60未満)は合計6〜9問でよい。
- 大きい章(金融商品・収益認識・連結・税効果・退職給付など)は合計15〜20問まで。
- 論点が薄い章を無理に増やさない。**根拠のない創作をしない**(プラン・過去問解答例・ノートに書いてあることだけで組む)。

## 文体・品質
- 問題文は1〜3文。解答例は結論1文＋理由2〜5項目。1項目は長くても2文。
- 数値例を使う事例は、プランやQAにある数値をそのまま使う(勝手に作らない)。
- 「講師メモ」「タイムスタンプ」「重要度A(最優先で暗記)」などのメタ表現は書かない。
- 基準名は本文中で使ってよい(「企業結合会計基準」等)。条番号は確実な場合のみ。
- 完成後、`python3 tools/kaikei/drill/check_frag.py frag/chNN.html` を実行し、エラー0を確認して報告する。
