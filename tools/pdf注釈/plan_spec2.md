# 注釈プラン作成仕様(直書き赤ペン版・講義3〜8用)

教科書PDFに書き込む注釈プラン(JSON)を作成する。出力は指定されたplan_chN.jsonに
1行1オブジェクト(JSONL)で書く。

## 注釈タイプ
```json
{"page": 110, "type": "highlight", "search": "回収可能性", "occurrence": 0}
{"page": 110, "type": "underline", "search": "収益力に基づく一時差異等加減算前課税所得"}
{"page": 110, "type": "badge", "search": "繰延税金資産の回収可能性", "text": "A・最優先で暗記"}
{"page": 110, "type": "margin", "search": "分類１", "text": "出題: 令和元・3年"}
{"page": 110, "type": "comment", "search": "企業の分類", "text": "分類1〜5は『課税所得が将来も安定して出るか』の序列。安定して黒字なら全額回収可能(分類1)、赤字続きなら原則ゼロ(分類5)。この序列の理屈で各分類の要件を覚えると、要件の文言を忘れても現場で復元できる。"}
```

- **highlight** = 赤マーカー(覚えるべき文言・定義・要件)
- **underline** = 赤下線(その節で最重要の一文)
- **badge** = 見出し横の赤文字ラベル(優先度)。テキストは「A・最優先で暗記」「B・説明できるレベル」「C・後回しOK」「知識整理・読むだけ」「スキップOK」のいずれか(【】は付けない。システムが配置)
- **margin** = 欄外の短い赤文字(20字以内。出題年・一言メモ)
- **comment** = ページ右の専用帯に赤文字で直接記載される解説。**今回の主役**

## commentの書き方(重要)
1. **「講師メモ」等の前置き・タイムスタンプは絶対に書かない**。内容だけを書く
2. 中身は次の2種類を優先:
   - **覚えるべきものの解説**: 何をどこまで覚えるか、覚え方(表の縦横どちらで覚えるか、
     序列・対比・語呂など)、記述で問われたときの書き方の骨子
   - **背景の考え方**: なぜその処理をするのか(趣旨・理屈)。講師が講義で説明した
     「そもそも論」「実務でどうなっているか」を優先。理屈が分かれば暗記が減る、という
     観点で書く
3. 文体は常体(だ・である/体言止め)。1件40〜150字。長くても200字まで
4. 1ページのcomment合計は4件以内・合計600字以内を目安(帯からあふれる)
5. 講義文字起こし・画面集(投影資料)・教科書にある内容のみ。創作しない

## アンカー(search)のルール(厳守)
1. search文字列は対象ページのダンプ(pNNN.txt)の**1行内に実在する連続文字列**を
   そのままコピー(改行をまたがない、8〜25文字)。grepで確認してから書く
2. 長い文へのライン(highlight)は行ごとに分割して複数エントリに
3. ページ内に複数回出る文字列はoccurrenceを指定(0始まり)
4. badge/marginは日本語プレーンテキストのみ(絵文字禁止)

## 素材の使い方
- 講義文字起こし: whisper自動転写で誤変換が多い(例: 税孔化/成功化=税効果、
  クリノブ税金資産=繰延税金資産、回収化膿性=回収可能性など)。教科書用語に正規化する
- 画面集(投影資料): 講師の図解・まとめスライド。教科書に無い整理(分類のフローチャート、
  対比表など)が載っていればcommentに要約して反映する
- 優先度バッジは教科書目次のアイコン(重要度A/B/C・知識整理)の指定に従う
