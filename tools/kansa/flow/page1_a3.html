② リスク評価手続何が間違っていそうかを見つける
315重要な虚偽表示リスクの識別と評価★7
  • 企業・企業環境・財務報告の枠組みの理解、内部統制システムの5構成要素（統制環境・リスク評価プロセス・監視プロセス・情報システムと伝達・統制活動）
  • 固有リスク要因：複雑性・主観性・変化・不確実性・経営者の偏向その他の不正リスク要因
  • 監査チーム内の討議
  • 財務諸表全体レベルとアサーション・レベルでリスクを識別・評価（固有リスク／統制リスクを別々に評価）
315実ガ1ITの理解★3（R5〜R7連続）
  • ITアプリ・ITインフラ・ITプロセス → IT全般統制／情報処理統制、インターフェース
240不正★4（不正リスク対応基準★6）
  • 不正リスク要因：動機・プレッシャー／機会／姿勢・正当化
  • 収益認識には不正リスクがあると推定（ないと判断したら理由を調書に）
  • 経営者による内部統制の無効化リスクは常にある
520分析的手続（リスク評価として）／550関連当事者★2／250法令／570継続企業の事象
特別な検討を必要とするリスクか

実証手続のみでは十分な証拠が得られないリスクか
  • 該当（自動処理で記録が電子のみ など）→ 内部統制の運用評価が必須

③ リスク対応手続評価したリスクに見合った証拠を集める
330評価したリスクに対応する手続★5
  • 財務諸表全体レベル → 全般的な対応（経験者の配置、予測困難性の付加 など）
  • アサーション・レベル → 運用評価手続＋実証手続（詳細テスト・分析的実証手続）
  • 重要な取引種類・勘定残高・注記事項には必ず実証手続
内部統制に依拠するか／運用評価の結果
  • 有効 → 統制リスクを低く評価、実証手続を絞れる（過年度証拠の利用は3年に1回まで。特別な検討リスクの統制は毎年）
  • 有効でない → 統制リスクを修正、実証手続を拡大
500監査証拠★7／手続の種類
  • 閲覧・実査・観察・質問・確認・再計算・再実施・分析的手続
  • 証拠の適合性と信頼性（外部・原本・文書は強い）。イメージ文書は500実指1
道具になる監基報
  • 505確認★4　◇経営者が送付に不同意 → 理由の合理性、代替手続／不合理なら監査役等へ。◇回答なし・差異 → 代替手続・原因調査
  • 501特定項目★5（棚卸立会・訴訟＝弁護士への質問書・セグメント）
  • 530サンプリング★3／520分析的実証手続
  • 540会計上の見積り★8：3アプローチ（報告書日までの事象／経営者の見積方法の検討／監査人の見積額・許容範囲）
  • 240無効化リスクへの対応（仕訳テスト・見積りの偏向・通例でない取引）は必須
  • 他者の利用：600グループ★5・620専門家★2・610内部監査人・402委託先
  • 項目別監査手続（勘定科目ごと）★10

④ 評価・完了集めた証拠で結論を出せるか
450虚偽表示の評価★4
  • 明らかに僅少なもの以外を集計 → 経営者に修正を依頼 → 未修正の影響を評価
計画を見直すか（450）
  • ほかにも虚偽表示がありそう（見つけた分と合算で重要に）
  • 集計額が重要性の基準値に近い → ①へ戻り手続追加
十分かつ適切な証拠を入手したか（330）
  • 影響要因：潜在的虚偽表示の重要性、内部統制の有効性、過年度の同様の虚偽表示、手続の結果、情報源の信頼性、心証の程度 など
  • 不足 → 追加手続、得られなければ⑤で除外事項（範囲の制約）
520全般的な結論のための分析的手続
560後発事象
  • 修正後発事象 → 財務諸表を修正／開示後発事象 → 注記
  • 報告書日後に知った事実 → 訂正（560実指2 訂正報告書）
570継続企業
  • 重要な不確実性あり＋注記適切 → 無限定＋「継続企業の前提に関する重要な不確実性」区分
  • 注記不適切 → 限定付／不適正、前提自体が不適切 → 不適正
580経営者確認書★3
  • 入手できない・誠実性に疑義 → 意見不表明

流れ全体を通じて
  • 200職業的懐疑心・合理的な保証
  • 230各段階で監査調書を作成
  • 260監査役等とは計画時と完了時の両方でコミュニケーション
戻りの矢印（試験で問われやすい）

事例問題での使い方

  • そこに書いてある監基報の「しなければならない」を答える
