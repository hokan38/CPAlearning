# 監査実務・職業倫理 赤ペン注釈プラン作成仕様

会計実務で確立した「書込済v3/完全版v2」と同じ流儀で、監査のテキスト5冊に
講義内容を反映する。1プラン=1行1オブジェクトのJSONL。**pageはPDFページ番号(1始まり)**。
印字ページ→PDFページ変換は kansa_structure.md の表を使う。

## 出力形式 (plan_kansa_<key>_<lecture>.json)
```json
{"page": 22, "type": "highlight", "search": "実在性", "occurrence": 0}
{"page": 22, "type": "underline", "search": "売掛金残高の確認を実施する"}
{"page": 22, "type": "margin", "search": "リスクとアサーション", "text": "出題: 令和2〜5年"}
{"page": 22, "type": "comment", "search": "回収可能性を検討", "text": "整理済みコメント本文"}
{"page": 22, "type": "comment", "text": "ページ全体に関わるコメントはsearch省略可"}
```

- **highlight** = 赤マーカー(覚えるべき文言・定義・要件・手続名)
- **underline** = 赤下線(その節で最重要の一文)
- **margin** = 欄外の短い赤文字(20字以内)
- **comment** = ページ右の帯に赤字で直接印字される解説。**主役**

## commentの書き方(会計実務v2で承認済みの流儀)
1. 講師の発言を**逐語で並べない**。同じページ・同じ論点の発言は統合し、論点ごとに
   整理した文章に書き直す。1ページ1〜3個、1個40〜220字、1ページ合計350字(最大450字)
2. 優先する内容:
   - 覚えるべきものの解説(何をどこまで覚えるか・覚え方・記述答案での書き方の骨子)
   - 背景の考え方(なぜその手続か。趣旨・理屈・実務での実際)
   - 出題予想・学習方針(飛ばしてよい/眺める程度/確実に暗記 等)
   - 講師の実務経験談・事例のうち理解を助けるもの
   - 例題(過去問)については講師の解き方・着眼点・答案骨子
3. 教科書に既に書いてあることの単純な言い換えはコメントにしない
4. 「講師メモ」前置き・タイムスタンプ・重要度A/B/Cランクの説明文は書かない。だ・である調
5. 教科書と講義にある内容のみ。創作しない
6. 講義全体の総論(試験概要・戦略)は対応する序章ページ(k3序章=PDF3-13, k5序章=PDF3-7)に付ける

## アンカー(search)のルール(厳守)
1. 対象ページのダンプ pages_<key>/pNNN.txt の**1行内に実在する連続文字列**(8〜25字)を
   そのままコピー。**出力前に必ずgrepで実在確認**
2. 長い文のhighlightは行単位に分割。複数回出る文字列はoccurrence(0始まり)
3. アンカーを特定できないcommentはsearch省略(ページ先頭に置かれる)

## whisper誤変換の正規化(監査系で頻出)
終了考査/終了交差=修了考査、関差/監差/カンサ=監査、監査保陣/監査法人、
公認会掲示/公認会計士、諸差/主査、アサーション類の崩れ、実在性/網羅性等は教科書用語に直す。
音声が壊れて意味が取れない箇所は無理に使わない。

## 禁止事項
- **badgeタイプは使わない**(重要度A/B/Cの説明メモは不要、というユーザー指示)
- 重要度ランクの説明をコメントに書かない(節見出しに重要度は印字済み)
